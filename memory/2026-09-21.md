- **Root cause**: Component used custom hardcoded styles instead of shared design system components

- **Solution implemented**:

  - Applied `rounded-button` class instead of `rounded-full` for consistency
  - Increased button touch targets to 44px (h-10 w-10)
  - Implemented proper Alert variant="warning" with `dark:` prefix support
  - Removed custom opacity values in favor of design tokens (`text-muted-foreground/80`)
