# Pipeline Integrity Check

**Purpose**: Track CSO pipeline health and lead response times.

## Required Fields

| Field | Description | Example |
|-------|-------------|---------|
| `activeDeals` | Number of active deals in pipeline | 42 |
| `dealValues` | Total pipeline value (CZK) | 12500000 |
| `newThisWeek` | Deals added this week | 5 |
| `lostThisWeek` | Deals lost this week | 2 |
| `avgResponseTimeHours` | Average lead response time (hours) | 24 |
| `criticalRisks` | Critical risks or blockers | ["key stakeholder unavailable"] |
