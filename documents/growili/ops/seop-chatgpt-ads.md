## 3. Strategy

### 3.1 Positioning

**Primary message:** Growili = POAS-driven CSS for ecommerce (profit-first, not ROAS)

**Why:** Differentiates from generic "AI marketing" claims. POAS is Growili's core metric and unique value prop.

### 3.2 Context Hints (Targeting) — Proposed

**Tier 1 — High intent (primary):**
- `ecommerce analytics platform`
- `AI marketing for ecommerce`
- `profit on ad spend tool`
- `CSS e-commerce`
- `Google Merchant Center optimization`

**Tier 2 — Consideration (secondary):**
- `marketing automation ecommerce`
- `improve ROAS ecommerce`
- `ad spend optimization`
- `ecommerce growth tools`

**Tier 3 — Brand/competitive (defensive):**
- `Growili` (defensive)
- `AI marketing analytics` (category capture)

**CZ-specific (test once EU confirmed):**
- `AI marketing ČR`
- `e-commerce analyzování`
- `optimalizace reklam`

### 3.3 Geo Sequencing

**Phase 1 (Month 1):** Test in lower-competition EU market (e.g., Nordics or DACH)
**Phase 2 (Month 2):** Expand to CZ if Phase 1 validates CPL benchmark
**Phase 3 (Month 3):** Scale winning market, maintain others at baseline budget

### 4.2 Campaign Structure

| Element | Detail |
|---------|--------|
| Campaign type | Context Hints (topic-based) |
| Target markets | Phase 1: 1 EU market; Phase 2: CZ |
| Daily budget | €15–35/day (adjust after Week 1 data) |
| Bid strategy | Start conservative (maximize clicks) → optimize for leads after 2 weeks data |
| Creative | Headline + description + landing link (exact specs TBD by platform) |
| Landing page | Dedicated `/chatgpt-ads` or `/ai-marketing` page matching Context Hint |

### 4.3 Landing Page Requirements

Must mirror the Context Hint that triggered the ad:

**Example:** If user sees hint "ecommerce analytics platform" → landing page headline must say "ecommerce analytics platform" (or close match), not generic homepage.

Minimum landing page elements:
- Matching H1 to Context Hint
- 30-second value prop (what + why + how)
- Demo/trial CTA
- Social proof (customer logos, POAS metric)
- Trust signals (GDPR, Czech/EU company, case study)

## 5. Measurement Framework

### 5.1 Baseline Metrics (Pilot)

| Metric | Target | How to measure |
|--------|--------|----------------|
| CPL (cost per lead) | TBD after Week 1 data | ChatGPT Ads dashboard + CRM |
| Lead → first response | <15 min (per Lead Response SOP) | Onboarding flow timestamps |
| Lead → complete intake | <24h | Onboarding flow |
| Lead → first value milestone | <7 days | Onboarding flow |
| Lead quality score | Manual review Week 2 | COO/CSO assessment |
| Click-through rate (CTR) | Benchmark after Week 1 | ChatGPT Ads dashboard |

### 5.2 Reporting Cadence

- **Daily:** Spend, impressions, CTR, CPL (first 2 weeks)
- **Weekly:** Lead quality review, Context Hint performance ranking
- **Monthly:** Full pilot report — scale/hold/pause decisions

### 5.3 Success Criteria (Pilot End)

- CPL benchmark established and documented
- Lead quality acceptable (≥30% reach activation/activation_ready stage)
- At least 1 Context Hint cluster shows CPL below target
- Competitor emergence monitoring in place

## 7. Risks & Bottlenecks

| Risk | Impact | Mitigation |
|------|--------|------------|
| Platform pricing higher than budget allows | Pilot fails to deliver sample size | Set minimum CPL threshold in Week 1; pause if >3x target |
| No conversion API/pixel | Cannot track leads accurately | Use UTM + CRM match; flag as blocker for platform evaluation |
| CZ not available in Phase 1 | Delays CZ-specific targeting | Use proxy EU market; test CZ only when confirmed available |
| Low lead quality (curiosity vs. intent) | Wastes founder/team time | Manual qualification in first 2 weeks; add qualification questions to landing page |
| Platform changes specs/pricing mid-pilot | Invalidates benchmarks | Monthly review; document all changes |
| Landing page not ready (P2 dependency) | Cannot launch | P2-ACQUISITION-TO-LEAD must approve before launch; no workaround |
