# Codex 历史会话连接兼容评审与验证

基线：`cb90a2440d1a771d67f46b65b2e0f2ea5106ce85`（本次获取的上游 main）。需求及设计沿用仓库 `docs/` 根目录技术文档的放置方式。

## 需求与设计评审

| 维度 | 收敛结果 |
|---|---|
| 用户价值 | 一次性处理受管旧标识，后续切换仅更新共享连接，不反复全量改历史 |
| 事实与范围 | 配置兼容属于既有缺口，不依赖多供应商计费；不更改用量或账单 |
| 可信度 | 文件可读、配置可载入与真实推理分开验收，不能互相代替 |
| 演进 | 自定义来源须有卡片连接定义，旧完成标记不屏蔽用户再次手动迁入的新历史 |
| 效能 | 修改仅在有旧标识时发生，扩展补迁须在设置中确认，启动和切换不自动扩大迁移范围 |
| 变更成本 | 复用备份、压缩和索引定位模块，不增加配置系统或外部运行时 |
| 可维护 | 迁移与恢复共用等长 JSON 补丁，避免两个不同安全实现 |
| 数据安全 | 不改正文/模型/凭据；目标增长无法保持偏移时跳过并计数，不假装全部成功 |
| 并发与恢复 | 普通文件局部比较写入、保留追加；跨文件部分成功用原件和幂等重试收口 |
| 可观测 | 致命失败不写完成标记；文件级跳过记录数量及后端日志，手动界面报告处理结果 |

评审结论：可以实现；已明确外部客户端配置缓存、跨后端加密内容和过长 provider ID 的能力边界。此评审是多维度自审，不是外部独立验收。

## PR 评审后修正

| 问题 | 修正与验证 |
|---|---|
| 单个短 ID 或歧义文件中止整批 | 按文件跳过并统计，安全文件和已验证索引继续；本批跳过路径禁止推进索引；启动扫描完成后不再反复重试，手动入口仍可重试 |
| Windows 创建时间不能判断替换 | 保留原文件句柄，使用卷序列号和 128 位文件 ID 比较身份；查询失败则拒绝写入；替换回归同时断言旧文件和新路径都没有被补丁修改 |
| 手动迁移错误无后端日志 | 命令层记录任务及迁移错误，跳过文件、索引行记录路径及原因 |
| Bedrock 内置连接被当作自定义来源 | 复用连接投影的 `BUILT_IN_IDS`，回归覆盖全部内置 ID |
| 案例命名不通用 | 测试夹具和文档统一使用中性的合成连接名称 |
