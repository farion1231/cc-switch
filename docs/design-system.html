基础 / 05

动效

快、短、只改颜色和位置。默认 150ms；菜单 / 弹层 / 提示淡入 + 轻微放大（tailwindcss-animate 的 animate-in fade-in-0 zoom-in-95），关闭时反向；分段选中块、页签下划线 200ms 滑动；打开菜单的触发器按下不缩放；按下按钮缩到 scale .96；系统开了「减少动态效果」时 framer-motion 位移全部跳过； 切换明暗主题期间暂停所有过渡（.theme-switching），避免整页闪一下。

组件 / 02 · src/components/ui/hover-tip.tsx

图标按钮 · HoverTip

工具栏、卡片操作、模式行右侧一律用纯图标按钮，文字放进 HoverTip：鼠标移上去立即出现深色胶囊，说清楚这一下会做什么。 按钮本身仍要 aria-label。

规格

胶囊圆角 · inverse 底 · 12px / 500 · 内边距 6×12 · 距触发元素 6px · shadow-md · 默认在下方，碰边自动翻转。延迟 0，相邻按钮之间移动不再等待。

写法

<HoverTip content="切换到路由"><button aria-label="路由"…/></HoverTip>。内容写动作（动词开头）或「名字 + 状态」，一句话，不放链接和按钮。

HoverTip 与 HelpTip 分工：HoverTip 只报「这个按钮是什么 / 做什么」；规则和术语解释放 HelpTip 的「?」说明卡（见通知条一节）。

CC Switch / 01 · providers/mode/ModeTabs.tsx

连接模式

每个应用有三种连接方式：直连（直接写配置文件）、 路由（本地代理按队列 / 故障转移）、聚合（多家模型合并）。 模式 tab 保留图标 + 文字、不挂提示；同一行右侧的故障转移、路由设置是纯图标 + HoverTip。

三种模式的区别直连：直接写入应用配置。
路由：经本地代理转发，可故障转移。
聚合：把多家的模型合并给一个应用。 路由生效中 · 按队列 · Anthropic 官方

看 ≠ 生效

白底凸起 = 正在看的那段；模式色文字 + 圆点 = 生效中的那段。两者可以不同。

切换要确认

看另一个模式时，底部出现模式色实心按钮「改为路由」，点了才生效。

颜色只在这几处

模式 tab、侧栏模式标签、当前卡片、切换按钮。别处出现模式名用中性文字。

规约 / 01

交互原则

一个主操作

每个视图只有一个实心主题色按钮；卡片上一律描边或图标。

图标 + HoverTip

重复出现的操作（编辑、复制、删除、设置、模式）只放图标，悬停立即显示操作内容，键盘聚焦同样显示。

状态写在原处

额度、延迟、需要登录写在卡片副行；后果（丢失、需重启）写在按钮、确认框或 toast，不藏进说明卡。

明暗一致

所有颜色走 token；浅色 / 深色两套值一一对应，切换时暂停过渡。

键盘可达

焦点环 2px 主题色；⌘K 打开命令面板；Escape 关闭浮层；禁用按钮用 aria-disabled 保留悬停说明原因。

文案

动词开头、说结果（「已切换到 X」），不写「操作成功」；按钮写具体动作，不写「确定」。

规约 / 02

Do / Don't

Do

主题橙只放在能点的东西上：主按钮、开关、勾选、焦点、链接。

Don't

用橙色表达「注意 / 警告」状态，或给分段控件选中块、页签下划线上橙色。

Do

卡片操作、工具栏用纯图标按钮，配 HoverTip + aria-label；模式 tab 这种「选哪一个」的控件保留文字。

Don't

图标按钮只靠 title 属性提示——要等一秒多才出现，样式也和系统不一致。

Do

当前生效的供应商卡片用模式 soft 底 + fill 描边。

Don't

给当前卡片再加主题色描边或实心彩色块，和模式色打架。

Do

数字列右对齐、等宽数字；模型名、状态码、密钥用 mono。

Don't

新增 token 以外的颜色或字号（text-[15px]、#ff8800）。
