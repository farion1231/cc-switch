# Claude Desktop format provenance


Reference sources are CC Switch PR #5232 at
`142dd7eb6ad7f79cfbb3d731030a0b6b0a955ed5`, and the `caezium/cc-tools`
working-tree snapshot based on `02353ada59e9e1ed48dd692b8cb0d5d97323f38b`,
including its unpublished `cc-routines` files. The related Desktop modules reuse their format observations while integrating
with current CC Switch. Only the behavior included in this branch is implemented.

Limited static inspection of JavaScript distributed in the installed Claude
Desktop 1.46388.4 app informed pre-clear transcript linkage, task schemas, and
the missed-run boundary. This is not represented as clean-room work. No
Anthropic application source, binaries, credentials, or real user data are
included in the repository or fixtures. Claude is an Anthropic product.
