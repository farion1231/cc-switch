# CC Switch v4.0.39

本版本以修复为主。**API Key 输入框**加了复制按钮；**备份**可以设置总大小上限，超过时从最旧的开始删；Claude Code 经 Codex OAuth 使用 **GPT-6.2 Sol / Astra** 时，系统提示的缓存命中率大幅提高。

另外修复了 Claude Code 和 Claude Desktop 的原生供应商卡住不出字时，要等最长 600 秒才故障转移；很长的流式响应让用量和日志收集占用的内存一直增长；一键导入链接合并配置失败后仍弹出确认框；只装了 Codex 桌面版时，插件页显示「未安装 Codex」；插件页给没装的应用建了空配置文件夹；OpenCode Go 的 DeepSeek V4.1 Flash 缺少 `max` 思考档位；快速点击时弹出层和下拉菜单闪烁等问题。

---

## 新增

### API Key 输入框可以一键复制

供应商表单的 API Key 输入框旁边多了复制按钮（[#9232](https://github.com/farion1231/cc-switch/pull/9232)），复制的是去掉首尾空格后的 Key，成功或失败都会提示。输入框为空或不可编辑时不显示。

### 备份总大小上限

备份设置里新增「备份总大小上限」（[#9011](https://github.com/farion1231/cc-switch/pull/9011)，相关 [#6706](https://github.com/farion1231/cc-switch/issues/6706)），默认「不限制」，升级后不会删任何备份。

- 设置上限后，备份文件夹超过这个大小时，会从最旧的备份开始删除。
- 最新的一份备份和恢复正在使用的备份始终保留，所以单份备份比上限还大时，文件夹仍可能超过上限。
- 上限在下次备份或每日维护时生效。每日维护还会清理备份中途崩溃留下、超过 24 小时的临时文件。

## 变更

- **Claude Code 经 Codex OAuth 使用 GPT-6.2 Sol / Astra 时缓存命中率更高**（[#9848](https://github.com/farion1231/cc-switch/pull/9848)，见 [#9847](https://github.com/farion1231/cc-switch/issues/9847)）：系统提示改放在第一条 developer 消息里，ChatGPT 后端会把它和对话一起缓存。实测从第二轮起命中率约 98%。其他模型和用 API Key 的路由不变。
- **隐私过滤器更快**（[#9826](https://github.com/farion1231/cc-switch/pull/9826)）：过滤结果不变。

## 修复

- **Claude Code 和 Claude Desktop 的原生供应商卡住不出字时，最长要等 600 秒才故障转移**（[#9754](https://github.com/farion1231/cc-switch/pull/9754)）：这类流式请求用的是非流式请求的超时，现在和其他流式请求一样用首字超时（默认 60 秒）。
- **很长或一直不结束的流式响应，让用量和日志收集占用的内存一直增长**（[#9846](https://github.com/farion1231/cc-switch/pull/9846)，见 [#9843](https://github.com/farion1231/cc-switch/issues/9843)）：缓冲现在最多 64 MiB，遇到超大的事件后也能继续解析后面的内容。
- **一键导入链接合并配置失败后，仍弹出确认框**（[#9844](https://github.com/farion1231/cc-switch/pull/9844)，见 [#9841](https://github.com/farion1231/cc-switch/issues/9841)）：现在只提示错误，不再弹确认框。
- **只装了 Codex 桌面版时，插件页显示「未安装 Codex」**（见 [#9850](https://github.com/farion1231/cc-switch/issues/9850)）：比如 Windows 上只装了 Codex 桌面版（MSIX）。现在找不到单独安装的 `codex` 时，插件页等用到 Codex 命令行的地方会改用桌面版自带的那份。「应用」页的安装、升级和卸载仍只管单独安装的 Codex CLI。
- **插件页给没装的应用建了空配置文件夹**（见 [#9852](https://github.com/farion1231/cc-switch/issues/9852)）：打开插件页时，没装 Codex、Grok Build、OpenClaw、Pi 或 MiniMax Code 也会建出 `~/.codex`、`~/.grok` 等空文件夹。现在找到命令行工具后才建，没装的照常显示「未安装」。
- **OpenCode Go 的 DeepSeek V4.1 Flash 缺少 `max` 思考档位**（见 [#9853](https://github.com/farion1231/cc-switch/issues/9853)）：预设现在按 OpenCode Go 的模型列表写明 `low`、`high`、`max` 三档，OpenCode 不再退回通用的 `low` / `medium` / `high`。
- **快速点击时，弹出层和下拉菜单闪烁**（[#9176](https://github.com/farion1231/cc-switch/pull/9176)，见 [#9175](https://github.com/farion1231/cc-switch/issues/9175)）：在打开或关闭的动画过程中再点一下，不会再连着切换两次。
