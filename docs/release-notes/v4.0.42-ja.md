# CC Switch v4.0.42

今回のリリースでは、**GitHub Copilot** のプロバイダーで Copilot の **Auto によるモデル自動選択**を使えるようになりました。Claude、Codex、Claude Desktop のモデル一覧で「GitHub Copilot 自動選択」を選ぶと、会話ごとにどのモデルを使うかを Copilot が決めます。Copilot Free のアカウントでも使えます。

このほか、4.0.41 で発生した問題を修正しました。すべてのアプリのプロバイダーカードに「agy で使用中」と表示され、サブタイトルも Antigravity のアカウントのメールアドレスに置き換わっていました。また、Antigravity の公式カードでアカウントを切り替えるとき、システムのキーチェーンからの最初の読み戻しに失敗しても、切り替え済みのアカウントの紐付けを取り消さなくなりました。

---

## 新機能

### GitHub Copilot の Auto によるモデル自動選択

（[#9564](https://github.com/farion1231/cc-switch/pull/9564)、[#8197](https://github.com/farion1231/cc-switch/issues/8197) を参照）

Copilot の上流で Auto の利用方法が変わり、これまでのモデル名を省略するやり方は使えなくなりました。現在の CC Switch は、まず Copilot の `/auto` に今回使うモデルを問い合わせ、Copilot から受け取ったセッショントークンを付けてそのモデルにリクエストを送ります。

- **使い方**：Copilot プロバイダーのフォームで「モデル一覧を取得」を押すと、アカウントが Auto に対応している場合は一覧に「GitHub Copilot 自動選択」（モデル ID `copilot-fusion-auto`）が加わるので、それを選びます。Claude Code、Codex、Claude Desktop のいずれでも選べます。Claude Desktop では 1 つの枠だけにこれを入れ、ほかの枠にはこれまでどおり具体的なモデルを入れることもできます。
- **Copilot Free でも使える**：Free アカウントのモデル一覧には Auto に対応しているかどうかが記載されていないため、CC Switch がそのアカウントに代わって `/auto` に 1 回だけ問い合わせ（モデルを選ばせるだけで、会話は送りません）、モデルを選べた場合に Auto の選択肢を表示します。
- **同じ会話ではなるべく同じモデルを使う**：Copilot が選んだモデルは、認可の有効期間中は引き続き使います。30 分を超えてアイドル状態だったとき、認可の期限が切れたとき、アカウントが変わったとき、またはコンテキストの圧縮に成功した後は、改めて問い合わせるため、別のモデルに変わることがあります。
- **モデルを選べないとき**：Copilot が拒否した場合や、選ばれたモデルが現在のプロトコルで使えない場合は、リクエストはエラーになり、フェイルオーバーをオンにしていれば次のプロバイダーに切り替わります。固定のモデルを選んだリクエストはこれまでと変わりません。

ローカルルーティングをオンにする必要があります。詳しくはユーザーマニュアルの [GitHub Copilot Auto](../user-manual/ja/2-providers/2.1-add.md#github-copilot-auto) をご覧ください。

## 修正

- **すべてのプロバイダーカードに「agy で使用中」と表示される**（[#9975](https://github.com/farion1231/cc-switch/pull/9975)、[#9981](https://github.com/farion1231/cc-switch/issues/9981) をクローズ）：4.0.41 では、Antigravity のページや「アカウント」ページを一度開くと、ほかのアプリのカードや Antigravity の中継カードにも「agy で使用中」の緑色のラベルが表示され、サブタイトルが Antigravity のアカウントのメールアドレスに置き換わっていました。現在は Antigravity の公式カードにだけアカウントを表示します。
- **Antigravity の公式カードでアカウントを切り替えた後に紐付けが取り消される**（[#9979](https://github.com/farion1231/cc-switch/pull/9979)）：システムのキーチェーンが新しいログインを書き込んだのに最初の読み戻しでエラーを返すことがあり、そのとき CC Switch はカードのアカウントの紐付けを取り消していましたが、実際には agy はすでに新しいアカウントに切り替わっていました。現在はもう一度読み直し、それでも読めない場合は、ログインは書き込み済みであることを伝え、まず「アカウント」ページで現在どのアカウントでログインしているかを確認してから再試行するよう案内します。
