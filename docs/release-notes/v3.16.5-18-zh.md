# CCSwitchMulti v3.16.5-18

## Codex official 图片输入能力修复

- 修复 MultiRouter 下 official GPT 模型被误判为不支持图片输入的问题。
- 根因是 Codex OAuth / 本地模型缓存里的 `input_modalities=["text","image"]` 与 `supports_image_detail_original=true` 在 CCSM 动态目录同步中丢失，随后 NativeResponses 的 text-only 模板把 official GPT 模型写成纯文本。
- 现在 official 模型目录会保留 `input_modalities`、`inputModalities`、`modalities.input`、`supportsImage`、`vision`、`supports_image_detail_original` 等能力字段，并在生成 `cc-switch-model-catalog.json` 时正确覆盖模板。
- 通用 OpenAI-compatible `/v1/models` 和火山 Plan 若明确返回图片能力字段，也会透传到 provider / route / 聚合 catalog；没有声明能力的第三方模型继续保持未知能力，由 route capability 或运行时错误降级处理。

## 使用边界

- official 模型不做额外图片探测，信任官方 catalog / cache。
- 第三方模型不会按模型名猜测图片能力；需要供应商模型列表明确声明，或由用户在 route 能力中手动声明。
- 安装后请刷新或重建 MultiRouter official catalog，并完全重启 Codex / ChatGPT app-server，使 Desktop 重新读取新的 `cc-switch-model-catalog.json`。
