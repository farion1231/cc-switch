# CCSwitchMulti v3.16.5-19

## 修复

- 修复 Codex MultiRouter 对官方 GPT 模型的多模态能力投影：最终 catalog 不再用 Native Responses 的 text-only 模板覆盖官方 `input_modalities`、图片详情支持和图像 Web Search 配置。
- 官方 `gpt-5.4`、`gpt-5.4-mini`、`gpt-5.5`、`gpt-5.6-luna`、`gpt-5.6-sol`、`gpt-5.6-terra` 会保留官方声明的图片输入能力。
- 修复“在新任务中继续”产生的共享 session ID 历史分支：每份独立 rollout 使用文件名 UUID 重建独立 thread-store 记录，避免不同进度打开同一个会话。

## 使用说明

安装后重新应用一次 Codex MultiRouter 配置，并重启 Codex Desktop，使其重新读取 `cc-switch-model-catalog.json`。
