# CC Switch v4.0.3

### 4.0 プレビュー版の 3 つ目の修正リリース

このバージョンでは、Claude Code を GPT や Grok にマッピングしたときに思考をオフにしても全力で推論してしまう問題と、Skill のインポート時にチェックした他のアプリに実際には Skill が届かない問題を修正しました。Claude Desktop でも OpenCode Go を問題なく使えるようになりました。Claude Code のクイックトグルに「auto mode のサーバー側チェックを無効化」が加わり、すべてのトグルに説明が付きました。MCP とプロンプトはページ全体で編集するようになり、離れる前に保存を促します。「バックアップと復元」ではすべてのバックアップが使っている容量を確認でき、ChatGPT サブスクリプションでは Codex Credits の残高が表示されます。プリセットに OpenCode Zen と MoArk を追加しました。4.0 の更新内容の全体は [v4.0 リリースノート](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.0-ja.md) をご覧ください。

> **プレビュー版は自動更新されません。** アプリ内の更新は正式版のみが対象です。4.0.0〜4.0.2 をインストール済みの場合は、このページから 4.0.3 をダウンロードして手動でインストールしてください。

---

## 新機能

**Claude Code のクイックトグル：auto mode のサーバー側チェックを無効化。** Claude Code 2.1.281 以降、auto mode はまず公式のサーバー側チェックを呼び出しますが、サードパーティのゲートウェイやローカルルーティングを経由するとチェックできず、セッションごとに一度「条件を満たしていない」という案内で止まっていました。Claude のプロバイダーエディターに「auto mode のサーバー側チェックを無効化」を追加しました。チェックを入れるとローカルのチェックだけを使い、この案内は出なくなります。新しく作成するサードパーティのプロバイダーではデフォルトでオン、公式やクラウドベンダーのプロバイダーではオフです。公式のエンドポイントでもオンにしないでください。また、これまでプロバイダーの設定に書いた `CLAUDE_CODE_AUTO_MODE_SERVER` は切り替え時に `settings.json` へ書き込まれていませんでしたが、プロバイダーと一緒に切り替わるようになりました。

**すべてのクイックトグルに説明を追加。** Claude の設定エディター上部にある各クイックトグルの後ろに「?」を付け、そのトグルが何をするのか、いつ使うのか、グローバル設定なのかプロバイダーごとに切り替わるのかを一文で説明します。

**MCP とプロンプトをページ全体で編集し、離れる前に保存を促すように。** MCP サーバーとプロンプトの編集はダイアログではなく、コンテンツ領域にページ全体で開くようになりました。サイドバーとウィンドウのドラッグ領域はそのまま使えます。プロバイダーの編集ページも幅の制限がなくなり、ウィンドウに合わせて広がります。未保存の変更があるときにサイドバーをクリックしたり、⌘, を押したり、トレイから切り替えたりすると、先に確認します。戻る、キャンセル、Esc はこれまでどおりそのまま閉じます。

**「バックアップと復元」ですべてのバックアップを確認できるように。** これまでここにはデータベースのバックアップしか表示されず、`~/.cc-switch` にある他のバックアップは気づかないうちに大きくなっていました。Codex セッションの移行バックアップは数 GB になることもあります。データベースの一覧の下に展開できる「その他のバックアップ」を追加し、Skill アンインストール時のバックアップ、Codex セッションの移行バックアップ、設定ファイル初回書き込みバックアップ、Hermes と OpenClaw の設定のバックアップ、旧バージョンが残したファイルなどを一覧にしました。各項目にパス、サイズ、件数を表示し、ファイルマネージャーで開くことも、種類ごとまとめて削除することもできます。削除する前に何が失われるかを説明します。たとえば Codex セッション統合の移行バックアップを削除すると、「Codex セッション履歴を統一」をオフにするときに「バックアップから復元」ができなくなります。

**ChatGPT サブスクリプションの Codex Credits 残高を表示。** Credits の残高があるときは、展開した上限の詳細と「アカウント」画面に「Credits」の行が加わり、残高と API 価格で換算したドル額（1 Credit は約 0.04 ドル）を表示します。Credits は上限に達した後にしか消費されないため、プロバイダーカードには普段は表示されず、いずれかの上限に達したときだけ表示されます。

**OpenCode 2.0 の新しいプロバイダー設定に対応。** OpenCode 2.0 では `providers` に新しい形式でプロバイダーを書けます。これまで CC Switch は従来の `provider` しか認識しなかったため、新しい形式のプロバイダーが見えず、書き込みも OpenCode が読まない場所に入っていました。現在はどちらの形式も読み書きでき、新しい形式のプロバイダーは JSON エディターで編集します。保存時にはコメントを残し、形式に誤りがあればどのフィールドかを具体的に示します。

**使用量の「モデル」タブに成功率と速度を追加。** 「プロバイダー」タブと同じく、モデルの統計にも「成功率」と「速度」の 2 列が加わりました。「平均コスト」列はなくなり、コストにマウスを重ねると確認できます。

**その他：**
- インストール済み Skill 一覧のヘッダーに全選択のチェックボックスを追加しました。現在の検索と絞り込みで表示されている行が対象です。
- プロバイダーの切り替えや、ルーティング・集約モードへの出入りのたびに、どこからどこへ切り替えたか、結果はどうだったかをログに記録するようになりました。「切り替えを押しても何も起きない」問題を調べやすくなります。
- 新しいプリセット：OpenCode Zen（Claude Code、Codex。OpenCode Go と 1 行にまとめています）、MoArk（Claude Code、Codex、Pi、OpenCode、OpenClaw）。

## 修正

- **Claude Code を GPT や Grok にマッピングすると、思考をオフにしても全力で推論していた問題。** Claude Code は思考をオフにしても `high` の推論強度を送るため、OpenAI 形式に変換した後も上流は全力で推論していました。現在は思考をオフにすると推論強度を `low` に下げます。変換先のモデルが対応していないレベルも、そのモデルが受け付けるレベルに自動で調整します。たとえば GPT-5.x pro は `low` を受け付けないため、これまでは `/effort low` を使うとそのまま 400 エラーになっていました。Fable や Opus 5.5 のように思考をオフにできないモデルは、マッピング後も思考を維持します。
- **Skill のインポート時にチェックした他のアプリに、実際にはその Skill が届いていなかった問題。** これまではチェック状態を記録するだけで、画面上は有効と表示されているのに、対応するアプリの Skills ディレクトリにはファイルがありませんでした。現在はインポート時に直接コピーします。コピーに失敗したアプリは有効としてマークせず、インポート結果に表示します。
- **Claude Desktop で OpenCode Go を使うと `400 MissingSessionID` になっていた問題。** OpenCode Go はリクエストごとにセッション ID を要求しますが、Claude Desktop は送りません。現在は、OpenCode へのリクエストにセッション ID がない場合、ローカルルーティングが自動で補い、同じ会話では常に同じ ID を使います。
- **一部の上流のストリーミング応答でツール呼び出しが失われていた問題。** ストリーミング応答の中で LF と CRLF の改行を混在させる上流があり、これまではイベントを誤って区切っていたため、Claude Code が OpenAI Chat 上流のツール呼び出しを受け取れませんでした。
- **使用量のプロバイダー表とモデル表がキャッシュ token を数えていなかった問題。** これまでの表は新規入力と出力しか合計しておらず、キャッシュヒット率が高いと、各行の合計が上部の総数のごく一部にしかなりませんでした。現在は上部の総 token 数と一致します。
- **ルーティングをオンにしていないときに取り込んだ使用量で、プロバイダー名が英語で表示されていた問題。** これまでは「Claude (Session)」のような英語の仮の名前が表示されていましたが、現在は「Claude Code · セッションログ」と表示され、マウスを重ねるとプロバイダーを区別できない理由が表示されます。リクエストログとリクエストの詳細では、すぐ横にアプリが書かれているため「セッションログ」とだけ表示します。
- **ディスクが遅いと、使用量の記録の書き込みがルーティングサービスを遅くしていた問題。** 使用量の記録は別スレッドで書き込むようになり、同時に届いた他のリクエストを止めなくなりました。
- **macOS で使用量ページのタブを切り替えると、グラフとアイコンががたついていた問題。**
- **Hermes と OpenClaw の Xiaomi MiMo プリセットが、デフォルトで画像に対応しないモデルを使っていた問題。** 現在は他のアプリと同じく、デフォルトで `mimo-v2.6-pro` を使います。
- **OpenCode Go プリセットの「API Key を取得」リンクを開くと、紹介キャンペーンが終了したという案内が表示されていた問題。** 紹介コードの付かないリンクに変更しました。

## 使い心地の改善

- **Claude の「Teammates モード」と「最大強度思考」の 2 つのクイックトグルを削除しました。** 現在はどの Claude Code セッションにもチーム機能が組み込まれており、Teammates のトグルに残っていたのは分割表示の役割だけでした。最大強度思考のトグルは、すべてのセッションを最も高価なレベルに固定し、`/effort` も効かなくしてしまいます。必要なときはセッション内で `/effort max` を使ってください。設定にすでに書かれているこの 2 つの変数は削除されません。

## アップグレードに関する注意

**データベースの構造は変わっていません。** バージョンは 20 のままなので、4.0.2 に戻しても問題ありません。

**プリセットの変更は、新しく追加するプロバイダーにだけ反映されます。** 既存の Claude プロバイダーに「auto mode のサーバー側チェックを無効化」が自動で付くことはありません。必要な場合はエディターでチェックを入れてください。既存の Hermes と OpenClaw の MiMo プロバイダーのモデルも変更されません。
