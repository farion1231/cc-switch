# CC Switch v4.0.30

本版本新增**隐私过滤器**：在路由和聚合模式下，本地路由转发请求前可以把用户输入和系统提示里的个人信息和密钥替换成占位符，不让它们发到上游。默认关闭，开关在「设置 → 数据」。

另外修复了 Codex 经路由连第三方原生 Responses 上游时，请求带上只有 OpenAI 认的字段被整条拒绝（报 400）；工具调用参数里出现重复的键后，Codex 对话每一轮都报 400；Windows 上主窗口打开在任务栏下面、按钮点不到；Antigravity 免费账号查额度报 403、锁区账号看不出原因；Antigravity 用量同步每分钟重读全部会话占满 CPU 等问题。

---

## 新增

### 隐私过滤器

开启后，本地路由在转发请求前，会把用户输入和系统提示中的个人信息和密钥替换为 `[邮箱]`、`[密钥]` 这样的占位符（[#8951](https://github.com/farion1231/cc-switch/pull/8951)）。开关在「设置 → 数据 → 隐私过滤器」，默认关闭。

- **会替换什么**：邮箱、中国大陆手机号、身份证号、银行卡号、IPv4 地址（127.0.0.1 这类回环地址除外），以及 API Key、Token、私钥、「密码是…」「api_key=…」这类口令。
- **不会动什么**：模型回复、思考内容、工具调用参数和图片。
- **工具结果**（文件内容、命令输出等）默认不处理，可以用「同时过滤工具结果」子开关打开。打开后模型只能看到占位符，改文件时可能因为对不上原文而失败，整文件重写时占位符可能被写回你的文件，请确认能接受再开。
- 只在路由和聚合模式下生效。直连模式下请求不经过 CC Switch，不会被过滤。
- 完全在本机按规则匹配，不调用任何模型；替换不可逆，占位符跟随界面语言（韩语、俄语界面暂用英文占位符）。规则移植自 [packyme/privacy-filter](https://github.com/packyme/privacy-filter)。

### 新模型价格

- 内置 Claude Fable 5.2（[#9426](https://github.com/farion1231/cc-switch/pull/9426)）和 Gemini 4 Carbon（[#9421](https://github.com/farion1231/cc-switch/pull/9421)，按截至 11 月 30 日的介绍价）的价格，用量统计里不再显示「未定价」。已经自己填过价格的不会被覆盖。

## 变更

- **打开供应商编辑页更快**（[#9357](https://github.com/farion1231/cc-switch/pull/9357)）：以前重启后第一次点编辑要等 1~2 秒，供应商多时打开、关闭编辑页也会卡一下，在名称框打字也不够跟手。现在启动后会在空闲时预先加载编辑页，打开、关闭和输入都不再拖慢整个列表。
- **Codex OAuth 卡片显示账号**（[#9300](https://github.com/farion1231/cc-switch/pull/9300)）：Claude Code 和 Claude Desktop 里的 Codex OAuth 供应商卡片，副标题从 ChatGPT 价格页网址改为「账号 · 套餐」，和其他官方账号卡片一致。
- **Copilot 官方登录卡片并入「已添加」**：不再单独占一组，排在已添加供应商的第一个。
- **手动改过 `SKILL.md` 后，Skills 页面的名称和描述会更新**（[#9316](https://github.com/farion1231/cc-switch/pull/9316)，相关 [#7848](https://github.com/farion1231/cc-switch/issues/7848)）：在后台检查，不再在打开 Skills 页面、切换开关时扫描全部技能目录。

## 修复

- **Codex 经路由连第三方原生 Responses 上游时，请求被整条拒绝，报 400**（[#9042](https://github.com/farion1231/cc-switch/issues/9042)、[#9077](https://github.com/farion1231/cc-switch/pull/9077)）。v4.0.28 起，有 ChatGPT 登录时第三方路由也写成 Codex 内置的 `openai`，Codex 因此会带上只有 OpenAI 自己认的字段，LM Studio、LiteLLM 和部分中转这类校验严格的上游会拒绝整个请求。现在发往第三方时按 Codex 自己对非 OpenAI 上游的处理把这些字段都去掉；官方卡和授权中心的 ChatGPT 账号不受影响。
- **工具调用参数里出现重复的键后，Codex 对话每一轮都报 400，再也继续不了**（[#9339](https://github.com/farion1231/cc-switch/issues/9339)、[#9341](https://github.com/farion1231/cc-switch/pull/9341)）。模型偶尔会在一次工具调用里把同一个参数写两遍，Codex 每一轮都会把历史原样再发一遍，校验严格的上游就一直拒绝。现在发往第三方原生 Responses 上游前，重复的键只保留最后一个；官方不受影响。
- **Windows 上主窗口打开时被任务栏挡住下半截，更新弹窗的按钮点不到，重启也一样**（[#9206](https://github.com/farion1231/cc-switch/issues/9206)、[#9336](https://github.com/farion1231/cc-switch/pull/9336)）。现在启动时会把窗口挪回屏幕可用区域内，太大就缩小；macOS 上被程序坞挡住同理。
- **Antigravity 免费账号查额度报「403 You do not have a valid license of this product」；锁区账号在授权中心照常显示额度，看不出为什么登录不了**（[#9413](https://github.com/farion1231/cc-switch/issues/9413)、[#9414](https://github.com/farion1231/cc-switch/pull/9414)）。现在查额度的方式与 `agy` 一致；Google 判定账号不可用（例如地区不支持）时，显示 Google 给出的原因。
- **`agy` 升级到 1.5 后，授权中心认不出正在用的 Antigravity 账号；切换账号后，没绑定账号的 Antigravity 官方卡片显示的还是上一个号的额度**（[#9318](https://github.com/farion1231/cc-switch/issues/9318)、[#9320](https://github.com/farion1231/cc-switch/pull/9320)）。
- **Antigravity 会话多时，CC Switch 在后台持续占满一个 CPU 核、大量读盘**（[#9346](https://github.com/farion1231/cc-switch/pull/9346)）。以前每分钟把所有会话记录完整读两遍，现在没变化的会话直接跳过。
- **经路由使用 Gemini 时，流式请求的用量记成请求里的模型名，不是实际回答的模型；Vertex AI 形式的上游成功请求在用量统计里没有记录**（[#7738](https://github.com/farion1231/cc-switch/issues/7738)、[#7740](https://github.com/farion1231/cc-switch/pull/7740)）。
- **Copilot 自带 Key 的供应商，填了「上下文窗口」和「最大输出 Token」、没填「最大输入 Token」的模型，输入仍被限制在 128K**：现在按「上下文窗口 − 最大输出 Token」写入最大输入，自己填过的值不变。
- **Windows 上没装 Copilot CLI、但装了 VS Code 时，Copilot CLI 显示为「已安装·无法运行」**：VS Code 自带的 Copilot 占位程序不再被当成 Copilot CLI，现在正确显示为未安装。
- **macOS 和 Linux 上升级后弹出的更新摘要被压扁，只露出一行**（[#9401](https://github.com/farion1231/cc-switch/pull/9401)）。
- **OpenCode 的 Oh My OpenCode Slim 表单所有按钮点了都没反应**（[#2067](https://github.com/farion1231/cc-switch/issues/2067)、[#3905](https://github.com/farion1231/cc-switch/pull/3905)）。
- **v3.7.0~v3.8.0 发布说明底部的 README / CHANGELOG 链接打不开**（[#7744](https://github.com/farion1231/cc-switch/issues/7744)、[#7750](https://github.com/farion1231/cc-switch/pull/7750)）。
