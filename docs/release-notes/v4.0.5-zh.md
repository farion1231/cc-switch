# CC Switch v4.0.5

### 4.0 正式版的第一个修复版本

Codex 现在可以用 GitHub Copilot 账号了。用量统计的「全部」热力图不再只显示最近一年，可以一直往前看到第一天的记录。这个版本还修复了 Claude Code 经 Responses 协议映射到 GPT 时子代理总被派去 worktree、Codex 聚合模式下 GLM 等模型在 `/model` 里消失的问题，Linux 的 deb、rpm 安装包也能应用内更新了。4.0 完整的更新内容请见 [v4.0 发布说明](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-zh.md)。

> **Linux deb、rpm 用户请手动安装这一版。** 已经装好的 deb、rpm 版本还带着旧的安装类型标记，应用内更新到这一版仍会提示权限不足。手动下载安装一次 4.0.5 之后，以后就能正常自动更新。

---

## 新增

**Codex 可以用 GitHub Copilot 账号。** 在 Codex 添加供应商时选「GitHub Copilot」预设，在「授权中心」登录 GitHub 账号即可；Claude Code 已经登录过的 Copilot 账号可以直接用。需要开启 Codex 的路由。Copilot 上不同模型支持的协议不一样，本地路由会按模型自动选择 Responses 或 Chat Completions，也可以在编辑器的「上游格式」里手动指定。不同账号等级的上下文窗口不同，预设默认取较保守的值，点「获取模型列表」会按你账号的实际窗口和推理档位填好模型目录。

**「全部」热力图可以看完整历史。** 以前时间范围选「全部」时，热力图只显示最近 53 周。现在默认仍是最近 53 周，点「显示更多」会每 53 周一段往前排，一直到有记录的第一天；每段标出日期范围、Token 数、请求数和花费，各段的颜色深浅可以直接对比。

## 修复

- **Claude Code 经 Responses 协议映射到 GPT 时，子代理总被派去 worktree。** Claude Code 调用子代理时，「隔离方式」和「模型」是可选参数，但 Responses 协议在没有明确说明时会把可选参数当成必填，模型每次都会填上。结果子代理被派到 worktree 里运行，不在 git 仓库里就直接失败，或者子代理自己配置的模型被覆盖。现在转换时会明确声明这些参数可选。用 Responses 协议的供应商和 ChatGPT 账号都受影响，现在都修好了。
- **Codex 聚合模式下，GLM 等模型在 `/model` 里看不到。** CC Switch 生成模型目录时会以官方的 gpt-5.5 条目为模板，官方把这个条目设为隐藏后，聚合里的第三方模型也跟着全被隐藏了，聚合计数却还在算它们。
- **Codex 的模力方舟预设在 `/model` 里只有一个模型。** 预设没有带模型目录，Codex 只列出默认模型。现在 5 个模型都会列出来，并带上上下文窗口、图片输入和推理档位。已经添加的模力方舟供应商不会自动更新，需要重新从预设添加一次。
- **Linux 上用 deb、rpm 安装的版本，应用内更新提示权限不足。** 以前更新器认不出 deb、rpm 安装，按 AppImage 的方式往 `/usr/bin` 里写文件。现在 deb、rpm 有了各自的更新包。已经装好的版本要先手动装一次这一版，见上方的提示。
- **Linux Wayland 下，标题栏的最小化、最大化、关闭按钮点了没反应。** 第一次打开窗口时，或者从托盘重新打开窗口后，按钮上会盖着一层看不见的区域。
- **Windows 用 MSI 升级后，任务栏上固定的图标在重启电脑后变成空白。** 快捷方式以前指向一个每次升级都会被删掉的图标缓存，现在直接用程序本身的图标。之前固定的图标在这次升级后可能还会变白一次，取消固定再重新固定一次就好，以后升级不会再出现。
- **用 npm 12 安装 Claude Code 后无法运行，Windows 上提示程序不兼容。** npm 12 默认不运行 Claude Code 的安装脚本，却照样提示安装成功，留下的只是一个占位文件。现在「应用」页的安装、升级，以及可以复制的安装命令都会允许这个安装脚本运行。
- **没开路由时，Grok Build 的用量要等 10 分钟才出现在用量统计里**，现在 1 分钟左右。

**其他：**
- 用户手册和 README 更新到 4.0 的界面。

## 升级说明

**数据库结构没有变化**，仍然是 20。

**Linux deb、rpm 用户请手动安装这一版**，之后就能正常自动更新。

**Windows 用户**：如果升级后任务栏上固定的图标变成空白，取消固定再重新固定一次即可。
