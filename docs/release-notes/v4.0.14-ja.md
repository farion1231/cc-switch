# CC Switch v4.0.14

今回のリリースでは、使用量の統計パネルにカスタマイズ項目を数多く追加しました。使用量ページに「設定」タブを追加し、金額を人民元、ユーロ、日本円などの通貨で表示できるようになりました（為替レートは自分で変更できます）。サイドバーの「今日」に金額、トークン、リクエスト数、キャッシュヒット率のどれを表示するかを選べ、リクエストログでは表示する列を選べるようになり、キャッシュ書き込み、ヒット率、合計時間、ステータスコードの 4 列を追加しました。使用量ページを再び開くと、前回見ていたタブ、期間、グラフの指標に戻ります。Claude Code のカードの「ターミナルを開く」は、まずこのフォルダが何に使われるのかを説明し、最近使ったフォルダを記憶するようになりました。ほかにも、Codex がルーティング経由で Gemini に接続したときに 2 回目のツール呼び出しで 400 になる問題、ルーティングモードで Codex のリトライ回数の設定が効かない問題、128 MiB を超える Skills リポジトリをインストールできない問題、大文字を含むカスタム料金が反映されない問題、Hermes の開発版で新しいバージョンがあると表示され続ける問題、フェイルオーバーキューの並べ替えが反映されない問題などを修正しました。4.0 の更新内容の全体は [v4.0 リリースノート](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-ja.md) をご覧ください。

---

## 新機能

**使用量の金額をほかの通貨で表示できるようになりました。** 使用量ページの「料金」タブは「設定」に変わり、上に新しい「表示」セクション、下に従来どおりの料金設定があります。「通貨」では米ドル（デフォルト）、中国人民元、ユーロ、日本円、新台湾ドル、トルコリラを選べ、「為替レート」には参考値が入っていて、自分で変更できます。費用は引き続き米ドルで記録し、表示するときだけ換算するので、ホバーすると米ドルの元の値を確認できます。グラフは換算してから描画し、軸の目盛りは整数のままです。換算後の金額は小数点以下最大 2 桁まで（日本円は 2 桁少なく）で、金額が大きいときは 3 桁ごとに区切ります。

**サイドバーの「今日」に表示する内容を選べるようになりました。** サイドバーの使用量の行にはこれまで今日の金額が固定で表示されていましたが、現在は「サイドバーの「今日」」で金額、トークン、リクエスト数、キャッシュヒット率から最大 2 つまで選べ、何も選ばずに非表示にすることもできます。名前が後ろの数字に押されて狭くなることはなくなりました。2 つ選んだ場合、この行には数字が 2 つだけ表示され、詳しい説明はホバー時のツールチップに表示されます。

**リクエストログに表示する列を選べるようになりました。** 「リクエストログの列」で表示する列にチェックを入れます。新しい列を 4 つ追加し、いずれもデフォルトでは非表示です：

- **キャッシュ書き込み**：キャッシュに書き込んだトークン数です。Codex、Gemini、Grok はこの数を報告しないため、「—」と表示し、ホバー時に説明します。
- **ヒット率**：リクエストごとのキャッシュヒット率です（[#7298](https://github.com/farion1231/cc-switch/issues/7298)）。計算方法は全体のヒット率と同じです。小数点以下 1 桁に切り捨てるので、ほぼすべてヒットしていても 100% とは表示されません。
- **合計時間**：ストリーミング応答全体の時間です。セッションログから推定した値には前に「≈」が付きます。
- **ステータスコード**：この列を表示している間は、時刻の横のエラーマークは表示されません。

列が多いときは表を左右にスクロールでき、各列が狭く押しつぶされることはなくなりました。

**使用量ページが前回の表示を記憶するようになりました。** 使用量ページを再び開くと、前回見ていたタブ、プリセットの期間、推移グラフとヒートマップの指標に戻ります。カスタムの日付範囲は記憶したプリセットの期間を上書きせず、アプリ、プロバイダー、モデルの絞り込みは保持しません。

**「ターミナルを開く」は、フォルダを選ぶ前に説明するようになりました。** これまで Claude Code のカードの「ターミナルを開く」を押すと、すぐにシステムのフォルダ選択ウィンドウが開き、このフォルダが何に使われるのかわかりませんでした。現在はまず「どのフォルダでターミナルを開きますか？」を表示し、選んだフォルダでターミナルを開き、このカードの設定で Claude Code を起動することを説明します。通常はプロジェクトのフォルダを選びます。前回開けたフォルダが自動で入力され、「最近使ったフォルダ」には最大 5 つのフォルダが並び、クリックすると選べるほか、一覧から削除することもできます。カードに独自のアドレスと Key がある場合は、このターミナルが分離されていること、つまり後で CC Switch でプロバイダーを切り替えても影響しないことも説明します。

**料金：** Gemini 4 Argon の組み込み価格を追加しました（[#8356](https://github.com/farion1231/cc-switch/pull/8356)）。2026-11-30 までの導入価格です。すでに 0 と記録されていた過去のリクエストは、起動時に再計算されます。

## 改善

**Claude Desktop の 1M モデルが 1 行だけ表示されるようになりました。** Desktop はこれまで、1M を宣言したモデルをそれぞれ 2 回並べていました。通常の行と、「1M コンテキスト」の行です。現在は通常の行だけを残し、選んだ後も引き続き 1M ウィンドウで使われます。ルーティングと集約モードでは、次に CC Switch を起動したときかモードを切り替えた後に反映されます。直接接続モードでは、次にプロバイダーを切り替えるか、このカードを保存した後に反映されます。

**ルーティング中に直接接続側のプロバイダーを削除できない理由を説明するようになりました。** ルーティングまたは集約モードでは、直接接続が指しているカードは削除できません。ルーティングを終了するとそこに戻るためです（[#8277](https://github.com/farion1231/cc-switch/issues/8277)）。これまでのメッセージは「使用中のプロバイダーは削除できません」でしたが、ルーティングのページではこのカードは使用中と表示されていないため、わかりにくいものでした。現在はメッセージに理由と、先に直接接続ページでほかのプロバイダーの「直接接続に戻して使う」を押してから削除する手順を明記します。

**アップストリームへの接続に失敗したとき、ログに具体的な原因を記録するようになりました。** これまでルーティングの転送に失敗すると「error sending request」のような大まかな内容しか記録されず、DNS 解決、接続拒否、TLS、接続リセットのどれなのか区別できませんでした（[#8416](https://github.com/farion1231/cc-switch/issues/8416)）。現在はログに下層の原因も含めるので、複数のプロバイダーが同時に失敗したときに同じネットワーク経路の問題かどうかを判断しやすくなりました。記録する前に URL を取り除くため、クエリパラメーターに含まれる Key がログに残ることはありません。

**プリセット：** SiliconFlow（硅基流动）の中国国内サイトの Claude Code、Claude Desktop、Hermes、OpenClaw プリセットを DeepSeek-V4-Flash に変更しました（以前の MiniMax-M2.5 は提供終了）。TokenFactory は中国語の画面では「词元工厂」と表示されるようになりました。Pi は pi.dev の新しい 3 色のアイコンに変わりました。

## 修正

- **Codex がルーティング経由で Gemini に接続したとき、2 回目のツール呼び出しで 400「missing a thought_signature」になっていた問題**（[#8336](https://github.com/farion1231/cc-switch/issues/8336)）。Gemini はツール呼び出しに署名を付けて返し、次のターンでそのまま送り返すよう求めますが、CC Switch の形式変換がこれを落としていました。現在は保存して送り返します。ツール呼び出しの途中で CC Switch が再起動して署名が失われた場合は、Gemini のドキュメントのやり方に従ってプレースホルダーの署名を補うので、エラーになりません。ほかのアップストリームには影響しません。
- **ルーティングモードで、Codex の設定のリトライ回数が効かなかった問題**（[#8265](https://github.com/farion1231/cc-switch/issues/8265)）。ルーティングに入ると、プロバイダーで設定した `stream_max_retries`、`request_max_retries`、`stream_idle_timeout_ms` が失われ、たとえば 50 回に設定したリトライが Codex デフォルトの 5 回に戻っていました。現在は保持します。
- **128 MiB を超える Skills リポジトリをインストールできず、展開サイズの上限超過と誤って表示されていた問題**（[#8421](https://github.com/farion1231/cc-switch/issues/8421)）。リポジトリのアーカイブはこれまで丸ごとメモリに読み込んでおり、上限は 128 MiB でした。現在はダウンロードしながら一時ファイルに書き込み、上限を展開と同じ 512 MiB に引き上げました。ダウンロードが上限を超えた場合は別のメッセージで知らせます。
- **大文字を含むカスタムモデル料金が反映されず、コストがずっと 0 だった問題**（[#8413](https://github.com/farion1231/cc-switch/issues/8413)）。たとえば画面の表示名どおりに入力した `GLM-5.3-Flash-EXL3` です。現在は料金の照合で大文字と小文字を区別しないため、新しいリクエストにも、保存後の過去分の再計算にも反映されます。
- **OpenCode のセッションで、ツール呼び出しの多いターンの推定速度が低く出ていた問題**（[#8402](https://github.com/farion1231/cc-switch/issues/8402)）。所要時間はこれまでツールの実行が終わるまでを数えていましたが、現在はモデルの出力が終わるまでを数えます。
- **OpenCode のワンクリックインポートの 2 つの問題**：インポートに成功した後、カードの「追加済み」状態がすぐに更新されなかった問題（[#8380](https://github.com/farion1231/cc-switch/issues/8380)）と、名前が中国語のプロバイダーをインポートした後に編集ページで保存できなかった問題（[#8379](https://github.com/farion1231/cc-switch/issues/8379)）。
- **Hermes の開発版で、新しいバージョンがあると表示され続けていた問題**（[#8394](https://github.com/farion1231/cc-switch/issues/8394)）。`0.22.1+238.g<sha>` のような開発版のバージョン番号はこれまで正式版の `0.22.1` として比較されており、`hermes update` の後も表示が消えませんでした。現在は開発版では表示しません。
- **WSL にインストールされているのに実行時にエラーになるツールが「未インストール」と表示されていた問題**（[#8167](https://github.com/farion1231/cc-switch/pull/8167)）。これまでは出力に「not found」が含まれているだけで未インストールと判定しており、「module not found」なども該当していました。現在はシェルの「コマンドが見つからない」だけを認識します。
- **Codex の親セッションに文字化けしたレコードが 1 件あると、サブエージェントの使用量がいつまでも計上されなかった問題**（[#8360](https://github.com/farion1231/cc-switch/pull/8360)）。現在はそのレコードを飛ばし、残りは通常どおり集計します。
- **フェイルオーバーキューの並べ替えをしても変わらないのに、成功と表示されていた問題**（[#8297](https://github.com/farion1231/cc-switch/issues/8297)）。キューに並び順の値が同じプロバイダーが 2 つある場合や、新しく追加したプロバイダーに並び順の値がない場合、上へ・下へ移動すると同じ値が書き込まれていました。現在は並べ替えた順序が必ず反映されます。
- **Windows で同じプロジェクトが、ドライブ文字の大文字・小文字の違いによってセッション管理で 2 つのグループに分かれていた問題**（[#8233](https://github.com/farion1231/cc-switch/issues/8233)）。たとえば `D:\projects\demo` と `d:\projects\demo` です。現在は 1 つのグループにまとめます。
- **OpenClaw で設定 JSON のリクエストヘッダーを変更しても、「User-Agent を送信」スイッチが連動しなかった問題**（[#8256](https://github.com/farion1231/cc-switch/issues/8256)）。

## アップグレードに関する注意

**データベースの構造は変わっていません。** バージョンは 20 のままです。

- 使用量ページの「料金」タブは「設定」の中に移りました。通貨、サイドバーの「今日」、リクエストログの列の設定はこのマシンにだけ保存され、クラウド同期されません。
- Claude Desktop の直接接続モードでは、1M モデルの 2 行は、次にプロバイダーを切り替えるか、このカードを保存するまで 1 行にまとまりません。
- Gemini 4 Argon の組み込み価格は 2026-11-30 までの導入価格で、その後の正式価格は次回の価格更新で調整します。
