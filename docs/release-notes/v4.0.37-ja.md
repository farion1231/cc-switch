# CC Switch v4.0.37

今回のリリースは修正が中心です。読み取れないプロバイダーと MCP のエントリ（新しいバージョンが書き込み、WebDAV / S3 で同期されてきたものなど）は、空の設定として扱われて次回保存時に既定値で上書きされることはなくなり、別に一覧表示されて削除できるようになりました。Pi に **Mistral AI** プリセットを追加し、韓国語の UI 翻訳を全体的に改善しました。

このほか、ローカルルーティングの待ち受けアドレスに IPv6 を指定すると起動できない問題、「Claude Code 拡張に適用」が壊れた `~/.claude/config.json` を丸ごと空にしてしまう問題、回線が遅いときに大きなスキルリポジトリのダウンロードが途中で中断される問題、Finder から CC Switch を開くと Codex のモデルカタログの検出で Node が見つからない問題、ツール呼び出しの引数のうち `_` で始まるフィールドが削除されてから上流に送られる問題、フェイルオーバーキューから外して再度追加したプロバイダーが引き続きスキップされる問題、プラグインページで「再試行」をクリックしても反応がないように見える問題などを修正しました。

---

## 新機能

### Pi に Mistral AI プリセットを追加

Pi に Mistral AI プリセットを追加しました。Pi 自身の Mistral プロトコル（`mistral-conversations`）を使うため、ストリーミングの思考内容が失われません（要望：[#9343](https://github.com/farion1231/cc-switch/issues/9343)、[#9344](https://github.com/farion1231/cc-switch/pull/9344)）。

- Mistral Large 4 と Mistral Small 4 を同梱し、思考レベルは Pi に組み込まれた Mistral のカタログと同じです。
- プロバイダー名は `cc-switch-mistral` で、Pi に組み込まれた `mistral` を覆い隠しません。
- Pi のフォームのプロトコル一覧でも `mistral-conversations` を選べます。Oh My Pi と Kimi Code はこのプロトコルに対応していないため、このプリセットは表示されません。

## 変更

- **読み取れないプロバイダーと MCP のエントリをそのまま保持し、個別に削除できるように**（[#9767](https://github.com/farion1231/cc-switch/pull/9767)）：これまではデータを読み取れないと空の設定として扱われ、次回保存時に既定値が書き戻されて元のデータが失われていました。現在はこうしたエントリをプロバイダーページと MCP ページに別に一覧表示して読み取れない理由を示し、編集や有効化はできませんが削除はできます（CC Switch 内の記録だけを削除し、各アプリの設定ファイルには触れません）。ほかのエントリは通常どおり表示・使用でき、フェイルオーバーはこのエントリをスキップします。このエントリを変更する操作は拒否され、こうしたエントリがあるあいだは、累加型のアプリ（OpenCode など）ですべてのプロバイダーを設定ファイルに同期する操作もエラーになります。読み取れるバージョンにアップグレードすれば元に戻ります。
- **Claude Code の 1M マーカーを小文字の `[1m]` で書き込むように**（関連：[#9757](https://github.com/farion1231/cc-switch/issues/9757)）：Claude Code のドキュメントの表記に合わせました。Claude Code はもともと大文字と小文字を区別しないため、既存の `[1M]` も引き続き使えます。
- **韓国語の UI 翻訳を改善**（[#9395](https://github.com/farion1231/cc-switch/pull/9395)、[#9349](https://github.com/farion1231/cc-switch/pull/9349)）。
- **「アカウント」ページのアカウント行を読みやすく**（[#9369](https://github.com/farion1231/cc-switch/pull/9369)）：「N 件のプロバイダーが使用中」を独立した行にし、クォータ名の列幅を最も長い名前に合わせました。ウィンドウが狭いときにプラン、ドメイン、ログイン日が省略記号に押しつぶされることはなくなり、ドイツ語やロシア語など長い翻訳でもパーセンテージが見えます。

## 修正

- **ローカルルーティングの待ち受けアドレスに IPv6（`::1` など）を指定すると起動できない問題**（関連：[#9743](https://github.com/farion1231/cc-switch/issues/9743)）：これまでは「invalid socket address syntax」と報告されていましたが、現在は正常に待ち受けできます。
- **「Claude Code 拡張に適用」をオンにすると、壊れた `~/.claude/config.json` が空にされる問題**（関連：[#9744](https://github.com/farion1231/cc-switch/issues/9744)）：ファイルが正しい JSON でない場合、これまでは空のファイルとして扱って書き直していたため、中のほかの設定がすべて失われていました。現在はファイルパスを示してエラーを報告し、ファイルはそのまま残します。書き込みも一時ファイルに書いてから置き換える方式に変えたため、途中で中断しても書きかけのファイルが残りません。
- **回線が遅いときに、大きなスキルリポジトリのダウンロードが途中で中断される問題**：インストール、更新、更新の確認、スキルの発見では、これまでダウンロード全体を 60 秒に制限していました。現在は 60 秒間続けてデータを受信できなかったときだけ中止し、「データを受信していません」と表示します。ダウンロード全体の上限は 10 分です。
- **Finder から CC Switch を開くと、Codex のモデルカタログの検出で Node が見つからない問題**（関連：[#9764](https://github.com/farion1231/cc-switch/issues/9764)）：そのため npm でインストールした Codex が実行に失敗し、CC Switch は Codex デスクトップ版に同梱されている、古い可能性のある CLI を代わりに使っていたため、集約モードの GPT モデルから公式の情報（検索ツールなど）が欠けていました。現在は検出時にログインシェルの PATH を使います。CC Switch がほかのコマンドラインツールを実行するときと同じです。
- **ツール呼び出しの引数のうち `_` で始まるフィールドが削除されてから上流に送られる問題**（[#9753](https://github.com/farion1231/cc-switch/pull/9753)）：MCP、データベース、GraphQL 系のツールは `_id`、`_meta`、`__typename` といったフィールドをよく使いますが、これまではプライベートフィールドとして削除されていたため、モデルが見る呼び出しと実際に実行された呼び出しが食い違い、厳格なプロバイダーではリクエストがそのまま拒否されるおそれもありました。現在はツール呼び出しの引数をそのまま保持します。
- **フェイルオーバーキューから外して再度追加したプロバイダーが、カードでは正常と表示されるのにしばらくスキップされ続ける問題**（[#9750](https://github.com/farion1231/cc-switch/pull/9750)）：キューから外したときや、あるアプリのルーティングを終了したときに、実行中のサーキットブレーカーの状態も同時にクリアするようにしました。OMO / OMO Slim を有効にしたときにもう一方のバリアントの設定ファイルを削除できなかった場合も、個別に通知するようになりました。
- **プラグインページで読み込みがタイムアウトした後、「再試行」をクリックしても反応がないように見える問題**（関連：[#9758](https://github.com/farion1231/cc-switch/issues/9758)）：「インストール済み」「見つける」「マーケットプレイス」の 3 つのタブで、再試行中は読み込み中と表示するようにしました。
- **プラグインページのいくつかの問題**（[#9742](https://github.com/farion1231/cc-switch/pull/9742)）：ほかのアプリに切り替えて戻っても、進行中の操作はスピナーが表示されたままになります。Codex でプラグインの更新中にそれを有効にし直した場合、更新が終わった後に再び無効化されることはなくなりました。表示名でも検索できるようになりました（Pi で git またはローカルフォルダーからインストールしたパッケージ）。固定バージョンの Pi パッケージをアンインストールしてから「見つける」でインストールすると、「見つける」に残らなくなりました。Windows で WSL 内にインストールしたプラグインのバージョン、名前、説明が表示されるようになりました。
- **メモリとリソースの使用**（[#9773](https://github.com/farion1231/cc-switch/pull/9773)）：セッションリーダーを離れるときにキャッシュした画像を解放し、自動更新をオフにしたときにダウンロード済みのインストーラーを解放します。一部のネットワークリクエストは HTTP 接続を再利用し、毎回新しく作らなくなりました。ローカルルーティングが受け取るリクエストボディ（展開後を含む）の上限を 200 MiB とし、超えると 413 を返します。
- **コマンドラインツールのインストールやアップグレードの直後の操作で、ときどき「アプリの操作が実行中です」と表示される問題**（[#9775](https://github.com/farion1231/cc-switch/pull/9775)）。
