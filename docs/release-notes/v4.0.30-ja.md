# CC Switch v4.0.30

今回のリリースでは、**プライバシーフィルター**を追加しました。ルーティングモードと集約モードで、ローカルルーティングがリクエストを転送する前に、ユーザー入力とシステムプロンプト内の個人情報とシークレットをプレースホルダーに置き換え、上流に送られないようにできます。既定ではオフで、スイッチは「設定 → データ」にあります。

このほか、Codex がルーティング経由でサードパーティのネイティブ Responses 上流に接続すると、OpenAI だけが受け付けるフィールドがリクエストに含まれてリクエスト全体が拒否される（400 になる）問題、ツール呼び出しの引数に重複したキーが現れると Codex の会話が毎ターン 400 になる問題、Windows でメインウィンドウがタスクバーの下に開いてボタンをクリックできない問題、Antigravity の無料アカウントでクォータを確認すると 403 になり、地域制限のあるアカウントでは原因がわからない問題、Antigravity の使用量同期が毎分すべてのセッションを読み直して CPU を占有する問題などを修正しました。

---

## 新機能

### プライバシーフィルター

オンにすると、ローカルルーティングはリクエストを転送する前に、ユーザー入力とシステムプロンプト内の個人情報とシークレットを `[メール]`、`[シークレット]` のようなプレースホルダーに置き換えます（[#8951](https://github.com/farion1231/cc-switch/pull/8951)）。スイッチは「設定 → データ → プライバシーフィルター」にあり、既定ではオフです。

- **置き換えるもの**：メールアドレス、中国本土の携帯電話番号、身分証番号、銀行カード番号、IPv4 アドレス（127.0.0.1 のようなループバックアドレスを除く）、および API Key、Token、秘密鍵、「password: …」「api_key=…」のようなパスワード類。
- **変更しないもの**：モデルの応答、思考内容、ツール呼び出しの引数、画像。
- **ツールの実行結果**（ファイル内容、コマンド出力など）は既定では処理せず、「ツールの実行結果もフィルタする」サブスイッチでオンにできます。オンにするとモデルにはプレースホルダーしか見えないため、ファイルの編集が元のテキストと一致せずに失敗したり、ファイル全体を書き直すときにプレースホルダーがあなたのファイルに書き戻されたりすることがあります。許容できることを確認してからオンにしてください。
- ルーティングモードと集約モードでのみ有効です。直接接続モードではリクエストが CC Switch を経由しないため、フィルタされません。
- 処理はすべてこのパソコン上のルール照合で行い、モデルは一切呼び出しません。置き換えは元に戻せず、プレースホルダーは表示言語に合わせて切り替わります（韓国語・ロシア語の UI では当面英語のプレースホルダーを使います）。ルールは [packyme/privacy-filter](https://github.com/packyme/privacy-filter) から移植しました。

### 新しいモデルの価格

- Claude Fable 5.2（[#9426](https://github.com/farion1231/cc-switch/pull/9426)）と Gemini 4 Carbon（[#9421](https://github.com/farion1231/cc-switch/pull/9421)、11 月 30 日までの導入価格）の価格を組み込み、使用量統計に「価格未設定」と表示されなくなりました。自分で価格を入力済みの場合は上書きしません。

## 変更

- **プロバイダー編集画面の表示を高速化**（[#9357](https://github.com/farion1231/cc-switch/pull/9357)）：これまでは再起動後に初めて編集をクリックすると 1〜2 秒待たされ、プロバイダーが多いと編集画面の開閉でも一瞬引っかかり、名前欄への入力も反応が鈍いことがありました。現在は起動後のアイドル時に編集画面を事前に読み込み、開く・閉じる・入力のいずれでもリスト全体が遅くならなくなりました。
- **Codex OAuth カードにアカウントを表示**（[#9300](https://github.com/farion1231/cc-switch/pull/9300)）：Claude Code と Claude Desktop の Codex OAuth プロバイダーカードのサブタイトルを、ChatGPT の料金ページの URL から「アカウント · プラン」に変更し、ほかの公式アカウントカードとそろえました。
- **Copilot の公式ログインカードを「追加済み」に統合**：独立したグループではなくなり、追加済みプロバイダーの先頭に並びます。
- **`SKILL.md` を手動で編集した後、Skills ページの名前と説明が更新されるように**（[#9316](https://github.com/farion1231/cc-switch/pull/9316)、関連 [#7848](https://github.com/farion1231/cc-switch/issues/7848)）：確認はバックグラウンドで行い、Skills ページを開いたときやスイッチを切り替えたときにすべてのスキルフォルダーをスキャンすることはなくなりました。

## 修正

- **Codex がルーティング経由でサードパーティのネイティブ Responses 上流に接続すると、リクエスト全体が拒否されて 400 になる問題**（[#9042](https://github.com/farion1231/cc-switch/issues/9042)、[#9077](https://github.com/farion1231/cc-switch/pull/9077)）。v4.0.28 から、ChatGPT にログインしている場合はサードパーティのルーティングも Codex 組み込みの `openai` として書き込むようになったため、Codex は OpenAI 自身しか受け付けないフィールドを含めて送るようになり、LM Studio、LiteLLM や一部の中継サービスのような検証の厳しい上流がリクエスト全体を拒否していました。現在はサードパーティに送るとき、Codex 自身が OpenAI 以外の上流に対して行う処理に合わせて、これらのフィールドをすべて取り除きます。公式カードと「アカウント」ページの ChatGPT アカウントには影響しません。
- **ツール呼び出しの引数に重複したキーが現れると、Codex の会話が毎ターン 400 になり、続けられなくなる問題**（[#9339](https://github.com/farion1231/cc-switch/issues/9339)、[#9341](https://github.com/farion1231/cc-switch/pull/9341)）。モデルはまれに 1 回のツール呼び出しで同じ引数を 2 回書くことがあり、Codex は毎ターン履歴をそのまま再送するため、検証の厳しい上流が拒否し続けていました。現在はサードパーティのネイティブ Responses 上流に送る前に、重複したキーは最後の 1 つだけを残します。公式には影響しません。
- **Windows でメインウィンドウを開くと下半分がタスクバーに隠れ、更新ダイアログのボタンをクリックできず、再起動しても同じだった問題**（[#9206](https://github.com/farion1231/cc-switch/issues/9206)、[#9336](https://github.com/farion1231/cc-switch/pull/9336)）。現在は起動時にウィンドウを画面の作業領域内に戻し、大きすぎる場合は縮小します。macOS で Dock に隠れる場合も同様です。
- **Antigravity の無料アカウントでクォータを確認すると「403 You do not have a valid license of this product」になる問題、地域制限のあるアカウントが「アカウント」ページでは通常どおりクォータを表示し、ログインできない理由がわからない問題**（[#9413](https://github.com/farion1231/cc-switch/issues/9413)、[#9414](https://github.com/farion1231/cc-switch/pull/9414)）。現在はクォータの確認方法を `agy` と同じにしました。Google がアカウントを利用不可と判断した場合（たとえば地域が対象外の場合）は、Google が示した理由を表示します。
- **`agy` を 1.5 にアップグレードすると、「アカウント」ページが使用中の Antigravity アカウントを認識できない問題、アカウントを切り替えても、アカウントを紐付けていない Antigravity 公式カードのクォータが前のアカウントのままになる問題**（[#9318](https://github.com/farion1231/cc-switch/issues/9318)、[#9320](https://github.com/farion1231/cc-switch/pull/9320)）。
- **Antigravity のセッションが多いと、CC Switch がバックグラウンドで CPU コアを 1 つ使い切り、大量のディスク読み込みを続ける問題**（[#9346](https://github.com/farion1231/cc-switch/pull/9346)）。これまでは毎分すべてのセッション記録を 2 回丸ごと読み込んでいましたが、現在は変化のないセッションをスキップします。
- **ルーティング経由で Gemini を使うと、ストリーミングリクエストの使用量が実際に応答したモデルではなくリクエスト内のモデル名で記録される問題、Vertex AI 形式の上流で成功したリクエストが使用量統計に記録されない問題**（[#7738](https://github.com/farion1231/cc-switch/issues/7738)、[#7740](https://github.com/farion1231/cc-switch/pull/7740)）。
- **Copilot の自前の Key を使うプロバイダーで、「コンテキストウィンドウ」と「最大出力トークン」を入力し「最大入力トークン」を入力していないモデルの入力が 128K に制限されたままになる問題**：現在は「コンテキストウィンドウ − 最大出力トークン」を最大入力トークンとして書き込みます。自分で入力した値は変更しません。
- **Windows で Copilot CLI がインストールされておらず VS Code がインストールされているとき、Copilot CLI が「インストール済み・実行不可」と表示される問題**：VS Code に付属する Copilot のプレースホルダープログラムを Copilot CLI と見なさなくなり、正しく未インストールと表示されます。
- **macOS と Linux で、アップグレード後に表示される更新の概要が押しつぶされ、1 行しか見えない問題**（[#9401](https://github.com/farion1231/cc-switch/pull/9401)）。
- **OpenCode の Oh My OpenCode Slim フォームで、どのボタンをクリックしても反応しない問題**（[#2067](https://github.com/farion1231/cc-switch/issues/2067)、[#3905](https://github.com/farion1231/cc-switch/pull/3905)）。
- **v3.7.0〜v3.8.0 のリリースノート下部の README / CHANGELOG リンクが開けない問題**（[#7744](https://github.com/farion1231/cc-switch/issues/7744)、[#7750](https://github.com/farion1231/cc-switch/pull/7750)）。
