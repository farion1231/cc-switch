# CC Switch v4.0.18

本版本新增对 Antigravity CLI（agy）的支持，它是 CC Switch 管理的第 11 个应用。你可以为 agy 添加官方登录卡和第三方 API Key 卡。**注意：Antigravity 的供应商只在从 CC Switch 卡片「使用此供应商打开终端」启动的 agy 里生效**，在其他终端里直接运行 `agy` 不会用到它；MCP、Skills 和提示词同步给 agy，会话可以浏览和恢复，用量从会话日志导入；「应用」页可以安装、升级、卸载 agy。macOS 上，授权中心还能管理多个 Antigravity 账号：一键切换 agy 的登录，查看每个账号的额度，把官方卡绑定到某个账号。另外，Windows 上的应用内更新不会再因为文件被占用而重启电脑，MSI 安装时可以选择不创建桌面快捷方式；页头改为在应用名旁用小徽章显示实际的连接。还修复了 macOS 上并发请求多时路由因文件句柄耗尽而失败、从访达启动时「重启 Codex 守护进程」报 `env: node`、Claude Code 会话用 `/cd` 换目录后仍归在旧项目下、Windows 上打开终端后一直转圈直到关掉终端窗口、Codex 未使用的额度窗口显示倒计时、DeepSeek V4.1 Flash 没有计价等问题。4.0 完整的更新内容请见 [v4.0 发布说明](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-zh.md)。

## 新增

### Antigravity CLI（agy）

Google 的 Antigravity CLI（命令是 `agy`）现在是一个独立的应用，有自己的供应商、MCP、Skills、提示词、会话和用量，和 Gemini CLI 分开管理（[#8268](https://github.com/farion1231/cc-switch/pull/8268)、[#2959](https://github.com/farion1231/cc-switch/issues/2959)）。

> **⚠️ Antigravity 的供应商必须从 CC Switch 以终端启动才生效。** 和其他应用不同，CC Switch 不改 agy 自己的设置文件，所以 Antigravity 的卡片没有「切换」，也没有「使用中」。要用哪张卡，就点那张卡上的「使用此供应商打开终端」，在弹出的终端里运行的 agy 才会用这家供应商；在其他终端里直接运行 `agy`，用的仍是 agy 自己的 Google 登录和设置。（macOS 上在授权中心切换账号是例外：它改的是 agy 的全局登录，见下一节。）

- **两种供应商卡。** 官方登录卡用 agy 自己的 Google 登录，打开终端时用卡上选的模型启动 agy，只对这次会话生效；第三方卡填兼容 Gemini API 的地址和 Key，地址留空用 Google 默认的 API，Key 和地址只交给这个终端里的 agy，不写进 agy 的配置和 shell 启动文件（启动用的临时文件会自动删除）。模型列表来自 agy 自带的模型目录，填的是 agy 认得的显示名称。
- **MCP、Skills、提示词。** 同步到 `~/.gemini/config`，这是 agy 的全局定制目录，可能和同一台电脑上的 Antigravity IDE 共用。第三方卡启动的 agy 同样能用这些 MCP、Skills 和提示词。
- **会话。** 可以浏览 agy 和 Antigravity IDE 的会话，只显示你输入的内容，不显示 agy 自己附加的上下文；第三方卡启动的会话也能找到，并用同一张卡恢复。
- **用量。** 从会话日志导入（包括 Antigravity IDE 的会话），按每轮选择的模型记账，费用按价格表里对应模型的 API 价格估算。
- **官方额度。** 在官方卡上开启额度查询后，显示 Gemini 和 Claude/GPT 两组额度，每组有 5 小时和每周两个窗口；卡片上每组只显示剩得少的那个窗口，点开下拉可以看全部四个窗口和各自的重置时间。
- **「应用」页管理 agy。** 用官方安装脚本安装，用 `agy update` 升级（Homebrew 安装的也一样），可以卸载。
- 深链接也可以导入 agy 的供应商、MCP 和提示词。

### 授权中心管理多个 Antigravity 账号（macOS）

agy 同时只能登录一个账号。现在授权中心多了 Antigravity 一组：点「用 Google 登录」或「添加账号」，在浏览器里添加账号，agy 里已经登录的账号也会自动收进来。

- **切换。** 在账号的菜单里选「切换 agy 到这个账号」，之后新开的 agy 都用这个号。原来登录的号会先收回授权中心，切走也不会丢。如果 agy 正在运行，会提醒你：已经打开的 agy 还用原来的号，而且可能把原来的号写回去，最好先退出。
- **每个账号的额度。** 每一行都显示自己的额度，不用切过去才能看。查额度只读额度，不调用模型。不能使用 Antigravity 的账号（比如有年龄限制的）会显示 Google 给出的原因，而不是一句看不懂的 403。
- **把官方卡绑定到账号。** 官方卡的表单里可以选一个账号：打开终端前会先把 agy 的登录切到这个号，已经是它就不再写入；卡片上显示的也是这个号的额度。不选就跟随 agy 当前的登录。卡片同步到另一台电脑后，那台电脑上也添加了这个号才能用，否则打开终端时会提示，不会用别的号启动。
- **删除账号不会让 agy 退出登录。** CC Switch 只删掉自己保存的那一份。

## 改进

**Windows 上的应用内更新不会再重启电脑**（[#8628](https://github.com/farion1231/cc-switch/pull/8628)、[#8534](https://github.com/farion1231/cc-switch/issues/8534)）。应用内更新以不弹对话框的方式运行 MSI 安装包，以前只要安装目录里有文件还被占用，Windows Installer 就会不提示直接重启电脑。现在安装包本身禁止重启，从旧版本更新到这一版时也生效。

**MSI 安装时可以不创建桌面快捷方式**（[#8601](https://github.com/farion1231/cc-switch/pull/8601)、[#5667](https://github.com/farion1231/cc-switch/issues/5667)）。安装目录页多了「Create a desktop shortcut」选项，默认勾上；静默安装可以加 `CREATEDESKTOPSHORTCUT=0` 跳过。升级时保留现在的状态：你删掉的快捷方式不会被重新创建。桌面目录写不进去时也不会再让安装失败。

**页头显示实际的连接**（[#8634](https://github.com/farion1231/cc-switch/pull/8634)）。实际连到哪里，从模式标签旁挪到应用名旁，用当前模式（直连、路由、聚合）的颜色画成一个小徽章；切到别的模式标签看时也一直显示，名称太长会截断，鼠标悬停可以看到全部。

**精简界面上的说明文字**（[#8633](https://github.com/farion1231/cc-switch/pull/8633)）。供应商表单、OpenClaw、每日记忆、同步和整流器设置里，和旁边标签、标题重复的说明去掉了，补充说明挪进已有的帮助卡片；会影响结果的提示（费用、重启、同步、删除等）照常显示。

**用量页的应用筛选只列「应用」页里显示的应用。** 和会话管理一样：显示 Claude Desktop 时 Claude Code 也保留，当前选中的应用即使被隐藏也不会消失。

**预设：** 新增 DIT.ai、hao.ai。

## 修复

- **macOS 上并发请求多时路由失败**（[#8668](https://github.com/farion1231/cc-switch/issues/8668)）。从访达或登录项启动的应用，同时能打开的文件数只有 256 个。路由每个进行中的请求要占一个客户端连接和一个上游连接，并发一多就用完了：接不了新请求、连不上上游，连配置文件和数据库都打不开。现在启动时把这个上限调高到系统允许的值（最多 10240）。Linux 同样处理。
- **从访达启动时，「重启 Codex 守护进程」报 `env: node: No such file or directory`**（[#8653](https://github.com/farion1231/cc-switch/issues/8653)）。从访达启动时 CC Switch 只有系统目录的 PATH，npm 安装的 codex 要靠 node 运行，node 装在别的目录时就找不到。现在运行这类命令时会先加上登录 shell 的 PATH，和安装、升级工具时一样。OpenCode 获取模型列表也受这个问题影响，一并修复。
- **Claude Code 会话里用 `/cd` 换了目录，会话管理里仍归在旧项目下**（[#8643](https://github.com/farion1231/cc-switch/pull/8643)、[#6862](https://github.com/farion1231/cc-switch/issues/6862)）。复制的恢复命令也会先 `cd` 到旧目录，在那里 `claude --resume` 找不到这个会话。现在和 Claude Code 自己的规则一样，按最后一次换到的目录归类，进出 worktree 也一样。
- **Windows 上打开终端后，按钮一直转圈，直到关掉那个终端窗口**（[#6712](https://github.com/farion1231/cc-switch/issues/6712)）。现在终端打开后就会结束等待。
- **Codex 没用过的额度窗口也显示重置倒计时**（[#8631](https://github.com/farion1231/cc-switch/pull/8631)）。用量为 0 的窗口，Codex 返回的重置时间是「现在加一个窗口长度」，所以每次刷新倒计时都会跳回整个窗口（5 小时窗口跳回 5 小时）。现在用量为 0 的窗口不显示重置时间。
- **DeepSeek V4.1 Flash 的请求显示「未定价」、按 0 元计。** OpenCode Go、OpenRouter 和 Hermes 预设用的模型名是 `deepseek-v4.1-flash`，以前价格表里没有。现在按 DeepSeek Flash 的官方价格计算；已经记录的请求不会重新计价。
- **手册里「官方额度用完后 Codex 锁住发送键」的绕开办法已失效，已更正**（[#7962](https://github.com/farion1231/cc-switch/issues/7962)）。4.0.16 起聚合模式会保留 ChatGPT 登录，把第三方设为聚合的默认供应商已经绕不开。现在的办法是：切到直连，确认「设置 → 应用配置 → Codex」里的「非接管切换时保留官方登录」是关闭的，切到一家第三方供应商后彻底重启 Codex；额度重置后再切回聚合。

## 升级说明

**数据库版本从 20 升到 21**，为 MCP 和 Skills 增加 Antigravity 的开关。升级前会自动备份数据库；升级后再退回旧版本，旧版本会提示数据库版本过新，打不开。

- Antigravity 的供应商只在从卡片「使用此供应商打开终端」启动的 agy 里生效，在其他终端里直接运行 `agy` 不会用到它。
- Antigravity 默认显示在「应用」页，不用的话可以在那里隐藏。
- 在授权中心管理 Antigravity 账号目前只支持 macOS。其他平台不显示账号选择，官方卡跟随 agy 自己的登录；从 Mac 同步过来的绑定会被忽略。
