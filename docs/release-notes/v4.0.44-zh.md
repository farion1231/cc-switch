# CC Switch v4.0.44

本版本新增对 ZCode（智谱的编程客户端）的支持：可以管理它的供应商和模型上限、MCP、Skills、提示词，查看会话并导入用量。Antigravity 账号改为全部交给 agy 自己处理：添加账号会打开终端，在 agy 里登录；额度用 agy 的 `/usage` 查，CC Switch 不再替 agy 登录、续期或查询。Claude Desktop 新增 Command Code 预设。

修复包括：Codex 经 Chat Completions 中转调用 Gemini 时工具调用被拒，账号文件读不出时已保存的账号被覆盖，清理第三方 Key 残留时丢了暂存的 ChatGPT 登录，删除冲突的环境变量会删掉所有同名的行，获取模型列表混进图片、视频等非对话模型，skills.sh 装不上只放在 `.claude/skills` 下的技能，托盘面板过早出现滚动条，只显示 Grok Build 时授权中心没有 xAI 卡，本地路由转换流式响应时单个事件不限大小，以及几处报错和提示文字。

## 新增

### 支持 ZCode

（[#9824](https://github.com/farion1231/cc-switch/pull/9824)，接续 [#8076](https://github.com/farion1231/cc-switch/pull/8076)、[#5644](https://github.com/farion1231/cc-switch/pull/5644)）

ZCode 是第 18 个受管应用，和 OpenCode、Hermes 一样多个供应商可以同时添加。

- **供应商**：写进 `~/.zcode/v2/provider_config.json` 的个人供应商层；在 ZCode 里自己添加的供应商和登录的账号，CC Switch 不导入也不改动。ZCode 是桌面应用，保存后还要在 ZCode 的供应商选择器里切到这个供应商才生效。
- **模型**：可以点「获取模型列表」从供应商拉取，也可以手动填模型 ID。每个模型的上下文和输出上限留空时沿用 ZCode 的推荐值，填了的会和供应商一起写入、一起删除。ZCode 没有模型显示名，表单里也不提供。
- **MCP、Skills、提示词**：MCP 写进 `~/.zcode/cli/config.json`；提示词是 `AGENTS.md`。设置里可以改 ZCode 的配置目录。
- **会话和用量**：从 ZCode 的 `~/.zcode/cli/db/db.sqlite` 读取。会话不能在 CC Switch 里删除（历史和用量都存在 ZCode 自己的数据库里），会提示到 ZCode 里删。
- **深链接**：供应商和 MCP 链接都支持 `zcode`，供应商链接必须带模型。

用 GLM Coding Plan 的 ZCode 卡会自动显示套餐额度。「应用」页不提供 ZCode 的安装和升级，由它自己更新。

### Claude Desktop 的 Command Code 预设

（见 [#10045](https://github.com/farion1231/cc-switch/issues/10045)）

和 Claude Code 的 Command Code 预设一致：按 OpenAI Chat 格式经本地路由转发，三个模型档都用 `deepseek/deepseek-v4.1-flash`（1M 上下文）。

### 预设

新增 TeleAI（Xing4.1-Preview）、FastAIToken。

## 变更

### Antigravity 账号不再借用 agy 的登录客户端

谷歌最近明确声明，不允许第三方工具使用 Antigravity 自带的 OAuth 客户端，而 CC Switch 以前正是这样做的：用 agy 内置的客户端 ID 登录和续期，并以 agy 的身份直接向 Google 查额度。现在这些请求都去掉了，CC Switch 不再为 Antigravity 账号发出任何自己的请求。

- **添加账号**：会打开终端运行 `agy`，在 agy 里先 `/logout` 再 `/login`，新登录出现后授权中心自动收录。原来登着的号会先收进来，在 agy 里登出也不会丢。
- **额度**：只用 agy 自己的 `/usage` 查，所以只查得到 agy 当前登录的账号。其他账号显示切走前最后一次查到的额度。
- **套餐**：`/usage` 不返回套餐，授权中心不再显示 Antigravity 的套餐行。
- **令牌续期**交给 agy 自己。已保存的账号照常可以切换。

[#10004](https://github.com/farion1231/cc-switch/pull/10004) 修的额度查询并发和请求放大，以及 [#10047](https://github.com/farion1231/cc-switch/pull/10047) 修的 Windows 查额度时闪黑窗，都在这次去掉的代码里；改成 `/usage` 之后这两个问题也不会再出现。

## 修复

- **Codex 经 Chat Completions 中转调用 Gemini，每轮工具调用都报 400**（见 [#9168](https://github.com/farion1231/cc-switch/issues/9168)、[#10032](https://github.com/farion1231/cc-switch/issues/10032)）：Codex 的工具定义里有 Gemini 不认的两种写法，一是多代理工具参数上的 `"encrypted": true` 标记，二是 `{"type": "boolean", "enum": [true]}` 这类非字符串的枚举。现在转成 Chat 格式时一律去掉 `encrypted` 标记；非字符串枚举只在发给 Gemini 模型时改写，其他模型不受这一项影响。
- **账号文件读不出时，已保存的账号被覆盖**（[#10020](https://github.com/farion1231/cc-switch/pull/10020)）：WorkBuddy、Antigravity、CodeBuddy、Claude 的账号文件损坏或读不出时，以前当成空表，下次保存就把所有账号覆盖掉。现在会给原文件名加上 `.unreadable-` 和时间戳后缀，留在原处，再从空表开始。
- **Codex 清理第三方 Key 残留时丢了暂存的 ChatGPT 登录**（[#10027](https://github.com/farion1231/cc-switch/pull/10027)）：第三方的 Key 以 `OPENAI_API_KEY` 留在 `auth.json` 里时，清理它会被当成你主动退出了登录，暂存的 ChatGPT 登录随之作废，切回官方卡就登不上了。
- **删除冲突的环境变量会删掉所有同名的行**（[#10025](https://github.com/farion1231/cc-switch/pull/10025)）：现在只删列表里那一行；扫描之后文件被改过、那一行已不再设置这个变量时，拒绝删除。
- **获取模型列表混进图片、视频、向量和重排序模型**（见 [#10026](https://github.com/farion1231/cc-switch/issues/10026)）：new-api 一类的中转会在模型列表里列出 Nano Banana、Seedream、Seedance 等，「全选」后写进 Codex 的模型目录，选到它们当对话模型就每条都报错。现在按中转标注的接口类型去掉这些模型；没有标注的照常保留。
- **skills.sh 装不上只放在 `.claude/skills` 下的技能**（见 [#10040](https://github.com/farion1231/cc-switch/issues/10040)）：以前报「技能目录不存在」，现在找不到可见目录时会再到 `.` 开头的目录里找。
- **托盘面板过早出现滚动条**（见 [#10034](https://github.com/farion1231/cc-switch/issues/10034)）：每个应用都带额度条，五个应用就超过了原来 620 px 的上限，最后一个被挤进滚动区。现在上限提到 760 px，屏幕空间不够时仍会滚动。
- **只显示 Grok Build 时授权中心没有 xAI 卡**（[#10030](https://github.com/farion1231/cc-switch/pull/10030)，关闭 [#10029](https://github.com/farion1231/cc-switch/issues/10029)）：xAI、GitHub Copilot 卡的说明也补上了 Grok Build、Codex 和 Copilot CLI。
- **本地路由转换流式响应时，单个事件不限大小**（[#9938](https://github.com/farion1231/cc-switch/pull/9938)，关闭 [#9937](https://github.com/farion1231/cc-switch/issues/9937)）：上游一直不发分隔符时内存会一直涨。现在单个事件上限 64 MiB，超过就报错并结束这次响应。
- **插件「市场」读不出 CLI 输出时显示为空**（[#10024](https://github.com/farion1231/cc-switch/pull/10024)）：现在会显示读取失败。
- **Skill 拒绝覆盖的提示总写成 Pi**（[#10044](https://github.com/farion1231/cc-switch/pull/10044)）：在 Oh My Pi、MiniMax Code 等应用里更新或卸载 Skill 被拒时，提示里写的是当前应用。
