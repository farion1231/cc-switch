# CCSwitchMulti v3.16.5-17

## Codex Desktop 历史修复根修

- 重做 Codex Desktop 历史修复的事实来源：从 `sessions` 与 `archived_sessions` 的 rollout 重建 active `state_5.sqlite` 的 thread-store，而不是只同步 provider 桶和旧 `session_index.jsonl`。
- 修复新版 Desktop 因 `backfill_state=complete` 不再扫描 rollout 时，`has_user_event`、`preview`、`first_user_message`、recency 等索引字段陈旧导致历史短暂出现后消失的问题。
- 修复器识别当前 rollout 的真实用户事件结构 `event_msg.payload.type=user_message`，只使用真实用户消息或目标事件生成可见预览。
- 缺失会话会插入 `threads`，现有会话按 rollout 回填；完成后在同一 SQLite 事务更新 `backfill_state`。历史 provider、工作区 hint 和 `session_index` 保留为兼容性辅助修复。

## 使用边界

- 不能热修复。执行写入前必须完全退出 Codex / ChatGPT App 和 app-server；CCSwitchMulti 会拒绝运行中写入，避免 WAL 或 Desktop 同步覆盖结果。
- 写入前会备份 active state DB（含 WAL/SHM）及受影响的本地历史文件。修复完成后重新启动 Codex Desktop 验证历史稳定显示。
