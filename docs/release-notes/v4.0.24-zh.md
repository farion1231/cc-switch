# CC Switch v4.0.24

本版本在授权中心加了「登录时自动打开浏览器」开关，关掉后登录账号只复制登录链接，由你自己选浏览器打开，适合每个账号用独立浏览器环境的用户。另外修复了 Claude Code、Claude Desktop 经路由用 GPT 6.1 Sol / Terra 时 max 思考档位被降成 xhigh、DeepSeek Harness 选了支持 PDF 输入的模型后第三方供应商全部不显示、WSL 上 CC Switch 启动就退出、Codex 的 Chat 供应商重开「支持思考等级」后思考档位发不出去等问题。4.0 完整的更新内容请见 [v4.0 发布说明](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-zh.md)。

## 新增

### 登录账号时可以只复制链接

以前在授权中心登录账号，一律用系统默认浏览器打开登录页。用 AdsPower 这类工具给每个账号单独开浏览器环境的话，登录会落到错误的浏览器里。

现在授权中心顶部多了「登录时自动打开浏览器」开关，Claude、ChatGPT、Copilot、xAI、Antigravity、Kimi、DeepSeek 账号登录都受它控制，包括在添加供应商表单里发起的登录。关掉后：

- 点登录只把登录链接复制到剪贴板，在你要用的浏览器里打开、登录并同意授权，CC Switch 会自动更新。
- 需要输入验证码的登录不再自动复制验证码，免得把剪贴板里的链接顶掉。
- 等待登录时可以点「复制登录链接」再复制一次，打开登录页的按钮不显示。

Windows 上 Claude Code 会自己打开浏览器，开关关掉时 CC Switch 会让它只输出登录链接。

开关默认打开，只记在这台电脑上，不随云同步。

**预设：** A6API 改用新域名 a6api.vip。

## 修复

- **Claude Code、Claude Desktop 经路由连 OpenAI 格式的上游、模型是 gpt-6.1-sol 或 gpt-6.1-terra 时，max 思考档位被降成 xhigh 发出**（[#9122](https://github.com/farion1231/cc-switch/issues/9122)）。现在 GPT 5.6 及以后的版本，不带后缀或带 sol、terra、luna、astra 后缀的模型都保留 max；pro、codex、mini 等其他后缀仍按 xhigh 发。
- **DeepSeek Harness 从拉取到的模型列表里选了支持 PDF 输入的模型后，第三方供应商全部不显示**（[#9116](https://github.com/farion1231/cc-switch/issues/9116)）。DeepSeek Harness 的模型输入类型只认文字和图片，写进去一个 PDF 就会让这一条配置整体失效。现在只写文字和图片。
- **WSL 上 CC Switch 启动后直接退出，报托盘图标「Permission denied」**（[#9021](https://github.com/farion1231/cc-switch/pull/9021)、[#9020](https://github.com/farion1231/cc-switch/issues/9020)）。Linux 的托盘图标改为放在应用的缓存目录。
- **Codex 的 Chat 供应商关掉再打开「支持思考等级」后，选的思考档位不再发给上游**（[#8998](https://github.com/farion1231/cc-switch/pull/8998)、[#8954](https://github.com/farion1231/cc-switch/issues/8954)）。GitHub Copilot 等上游因此收不到任何思考档位。以前保存过的供应商不用重新编辑，也会恢复正常。
- **DeepSeek Harness 的「DeepSeek 官方登录」卡片写着「用 Claude 账号登录」**（[#9058](https://github.com/farion1231/cc-switch/pull/9058)）。现在是「用 DeepSeek 账号登录」。
