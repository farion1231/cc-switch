# CC Switch v4.0.33

本版本修复了从第三方供应商切回 Claude 官方后，已经开着的 Claude Code 会话仍把请求发给上一家、要重开会话才恢复的问题。套餐额度查询新增 **Ollama Cloud**；授权中心的 **Antigravity 账号切换**现在也支持 Windows。

另外修复了 Claude Code / Claude Desktop 的供应商选 Gemini Native 格式时获取模型列表总报「API Key 无效或无权限」；部分服务商获取模型列表被 Cloudflare 拦下；Antigravity Orchestrator 仍有部分请求显示未定价；WebDAV 同步在一些 NAS 上完全用不了；WebDAV / S3 上传失败只显示「请求构造失败」；查询 xAI 额度时遇到网络抖动就被要求重新登录；更新 Skill 中途失败把原来的 Skill 删掉等问题。

---

## 新增

### Ollama Cloud 套餐额度

地址是 `ollama.com` 的供应商现在可以查询 Token Plan 额度（需求见 [#9382](https://github.com/farion1231/cc-switch/issues/9382)）：现行套餐显示本期套餐内额度的剩余比例和重置时间，旧版套餐显示 5 小时和每周两个窗口的剩余比例。单独购买的额度不显示；按量付费的账号没有套餐额度，会说明原因。本机运行的 Ollama（`localhost:11434`）没有套餐，不会被识别。

- 新添加或一键导入的 Ollama Cloud 供应商默认开启额度查询；已有的供应商在卡片上点「配置用量查询」，Token Plan 模板会自动选好，打开「启用用量查询」后保存即可。

### Windows 上切换 Antigravity 账号

授权中心的 Antigravity 账号切换以前只支持 macOS，现在 Windows 也能用：切换后 agy 读到的是新账号，Antigravity 官方卡可以绑定账号、查看所绑账号的额度，打开终端前也会提示将切换到哪个账号。Linux 暂不支持。

## 修复

- **从第三方供应商切回 Claude 官方后，已经开着的 Claude Code 会话仍把请求发给上一家，要重开会话才恢复**（[#9247](https://github.com/farion1231/cc-switch/pull/9247)，见 [#7808](https://github.com/farion1231/cc-switch/issues/7808)、[#3057](https://github.com/farion1231/cc-switch/issues/3057)）：运行中的 Claude Code 只会读入 `settings.json` 里新增和改动的环境变量，被删掉的仍留在会话里。现在切换时先把要删的地址、凭据和模型映射写成空值，开着的会话下一条请求就不再用上一家，约 10 秒后再从文件里删掉。会话启动时就定下的主模型（`ANTHROPIC_MODEL`）不会跟着变：如果上一家设了它，切回后在模型菜单里选一次 Default，或者新开会话。
- **Claude Code / Claude Desktop 的供应商选 Gemini Native 格式时，「获取模型列表」总是报「API Key 无效或无权限」**：现在按 Google 要求的方式传 Key。经路由的实际请求本来就正常，只有获取模型列表受影响。另外，Pi、Oh My Pi、Kimi Code 选 Google 接口的供应商，获取模型列表以前最多只列出 50 个，现在能列全。
- **获取模型列表时，部分放在 Cloudflare 后面的服务商直接拒绝，被误报为「API Key 无效或无权限」**（[#7429](https://github.com/farion1231/cc-switch/pull/7429)，见 [#7427](https://github.com/farion1231/cc-switch/issues/7427)）：请求现在默认带上 User-Agent；供应商或请求头里设了 User-Agent 的，仍以设置的为准。
- **Antigravity 选 Orchestrator 时，仍有部分请求显示未定价**（[#9542](https://github.com/farion1231/cc-switch/pull/9542)，见 [#9493](https://github.com/farion1231/cc-switch/issues/9493)）：显示为「Gemini 4 Hydrogen (Orchestrator)」的步骤按 Gemini 4 Hydrogen 的价格计价，近 30 天内的历史也会补上费用。自定义价格仍然优先。
- **WebDAV 同步在部分 NAS 上完全用不了，测试连接、上传、下载都失败**（[#5623](https://github.com/farion1231/cc-switch/pull/5623)，见 [#5621](https://github.com/farion1231/cc-switch/issues/5621)）：这些 NAS 在共享文件夹已存在时仍对「建目录」回 400，以前会直接中止，现在会再查一次目录是否存在。
- **WebDAV / S3 上传被服务器中途断开时，只显示「请求构造失败」**（见 [#9559](https://github.com/farion1231/cc-switch/issues/9559)）：现在分清是请求没构造出来还是发送时失败，并附上具体原因，方便判断是网络、TLS 还是服务器的问题。地址里的密码和签名参数不会出现在报错里。
- **S3 自动同步在关掉之后仍可能再上传一次**（[#9528](https://github.com/farion1231/cc-switch/pull/9528)）：另一次同步进行中时排队的自动上传，现在开始前会重新读取设置，期间关掉了自动同步或 S3 同步就不再上传。WebDAV 本来就是这样。
- **查询 xAI 账号额度时，遇到网络抖动或 xAI 服务出错就提示需要重新登录**（[#9526](https://github.com/farion1231/cc-switch/pull/9526)，见 [#9522](https://github.com/farion1231/cc-switch/issues/9522)）：只有登录真的失效才这样提示，临时错误照常报错并保留上次查到的额度，下次查询再试。
- **一个非默认的 xAI 账号过期后，授权中心里选好的默认账号被换成了别的账号**（[#9548](https://github.com/farion1231/cc-switch/pull/9548)，见 [#9543](https://github.com/farion1231/cc-switch/issues/9543)）。
- **更新 Skill 时如果复制到一半失败，原来的 Skill 被删掉，列表里却仍显示已安装**（见 [#9521](https://github.com/farion1231/cc-switch/issues/9521)）：现在新版本完整复制好之后才替换，失败时保留原来的版本。
- **Codex 经路由转成 Chat 格式时，工具定义里的 `required: null` 被要求严格的上游拒绝**（[#7023](https://github.com/farion1231/cc-switch/pull/7023)，见 [#7019](https://github.com/farion1231/cc-switch/issues/7019)）。
- **macOS / Linux 上 shell 配置文件的路径里带冒号时，「检测到系统环境变量冲突」删除或恢复变量会失败**（[#7170](https://github.com/farion1231/cc-switch/pull/7170)，见 [#7169](https://github.com/farion1231/cc-switch/issues/7169)）。
- **PIPELLM、AICodeWith、E-FlowCode 的 Pi 预设在模型选择里显示成旧模型名**（[#9514](https://github.com/farion1231/cc-switch/pull/9514)）：比如 Claude Opus 5.5 显示成 claude-opus-5，实际请求的是新模型。用这几个预设生成的 DeepSeek Harness、Copilot CLI、Oh My Pi、MiniMax Code、Kimi Code 预设一起修正；已经添加的供应商保留原来保存的名字。
- **地址形如 `api.commandcode.ai/providers` 的供应商被当成 Command Code 套餐查询额度**（[#9518](https://github.com/farion1231/cc-switch/pull/9518)）。
