# CC Switch v4.0.39

This release is mostly fixes. The **API key input** gets a copy button; **backups** can now have a total size limit, with the oldest removed first once it is exceeded; and when Claude Code uses **GPT-6.2 Sol / Astra** through Codex OAuth, the system prompt's cache hit rate is much higher.

Fixes also cover Claude Code and Claude Desktop native providers waiting up to 600 seconds before failover when the upstream stalls without output; memory used by usage and log collection growing without limit on very long streaming responses; the deep link import confirmation dialog still opening after merging its config failed; the Plugins page saying Codex isn't installed when only the Codex desktop app is present; the Plugins page creating empty config folders for apps that aren't installed; OpenCode Go's DeepSeek V4.1 Flash missing the `max` reasoning effort; popovers and dropdown menus flickering on rapid clicks; and more.

---

## New

### Copy the API key in one click

The API key input in the provider form now has a copy button ([#9232](https://github.com/farion1231/cc-switch/pull/9232)). It copies the key with leading and trailing spaces removed and shows a notice whether it succeeds or fails. It is hidden while the input is empty or can't be edited.

### Backup size limit

The backup settings have a new "Backup Size Limit" ([#9011](https://github.com/farion1231/cc-switch/pull/9011), related [#6706](https://github.com/farion1231/cc-switch/issues/6706)). The default is "No limit", so upgrading deletes no backups.

- With a limit set, once the backups folder grows past it, backups are deleted starting from the oldest.
- The newest backup and any backup in use by a restore are always kept, so the folder can still exceed the limit when a single backup is larger than it.
- The limit takes effect at the next backup or daily maintenance. Daily maintenance also removes temporary files older than 24 hours left behind by a backup that crashed midway.

## Changes

- **Higher cache hit rate for GPT-6.2 Sol / Astra when Claude Code goes through Codex OAuth** ([#9848](https://github.com/farion1231/cc-switch/pull/9848), see [#9847](https://github.com/farion1231/cc-switch/issues/9847)): the system prompt now goes in the first developer message, so the ChatGPT backend caches it together with the conversation. In testing, the hit rate was about 98% from the second turn on. Other models and API key routes are unchanged.
- **Faster privacy filter** ([#9826](https://github.com/farion1231/cc-switch/pull/9826)): filtering results are unchanged.

---

## Fixes

- **Claude Code and Claude Desktop native providers waited up to 600 seconds before failover when the upstream stalled without output** ([#9754](https://github.com/farion1231/cc-switch/pull/9754)): these streaming requests used the non-streaming timeout. They now use the first-byte timeout (60 seconds by default), like other streaming requests.
- **Memory used by usage and log collection kept growing on very long or never-ending streaming responses** ([#9846](https://github.com/farion1231/cc-switch/pull/9846), see [#9843](https://github.com/farion1231/cc-switch/issues/9843)): the buffer is now capped at 64 MiB, and parsing continues with what follows after an oversized event.
- **The deep link import confirmation dialog still opened after merging its config failed** ([#9844](https://github.com/farion1231/cc-switch/pull/9844), see [#9841](https://github.com/farion1231/cc-switch/issues/9841)): now only the error is shown, without the confirmation dialog.
- **The Plugins page said Codex isn't installed when only the Codex desktop app was present** (see [#9850](https://github.com/farion1231/cc-switch/issues/9850)): for example, with only the Codex desktop app (MSIX) installed on Windows. When no separately installed `codex` is found, the Plugins page and other places that use the Codex CLI now use the copy bundled with the desktop app. Install, upgrade and uninstall on the Apps page still manage only the separately installed Codex CLI.
- **The Plugins page created empty config folders for apps that aren't installed** (see [#9852](https://github.com/farion1231/cc-switch/issues/9852)): opening the Plugins page created empty folders such as `~/.codex` and `~/.grok` even without Codex, Grok Build, OpenClaw, Pi or MiniMax Code installed. The folder is now created only after the CLI is found, and apps that aren't installed are still shown as not installed.
- **OpenCode Go's DeepSeek V4.1 Flash was missing the `max` reasoning effort** (see [#9853](https://github.com/farion1231/cc-switch/issues/9853)): the preset now lists the three efforts `low`, `high` and `max` from OpenCode Go's model list, so OpenCode no longer falls back to the generic `low` / `medium` / `high`.
- **Popovers and dropdown menus flickered on rapid clicks** ([#9176](https://github.com/farion1231/cc-switch/pull/9176), see [#9175](https://github.com/farion1231/cc-switch/issues/9175)): clicking again during the open or close animation no longer toggles it twice.
