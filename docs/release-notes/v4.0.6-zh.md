# CC Switch v4.0.6

### 4.0 正式版的第二个修复版本

供应商页的页头多了搜索按钮，还能按请求地址查找。Skills 检查到更新后可以一键全部更新，确认前会列出要更新的 Skill。额度数字的绿、橙、红三色回来了，剩余不足 20% 就会变色提醒。Codex 聚合模式下，主 agent 和子 agent 用不同供应商时子 agent 读不到任务，现在可以打开新开关改用经典子 agent 工具。这个版本还修复了 Claude Code 经路由转 OpenAI Chat 格式时最后一段回复丢失、Codex 聚合模式下官方模型消失、托盘看不到火山等 5 小时额度等问题。4.0 完整的更新内容请见 [v4.0 发布说明](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-zh.md)。

---

## 新增

**供应商页加了搜索按钮。** 以前只能按 ⌘F / Ctrl+F 打开搜索，很多人不知道有这个功能。现在「添加供应商」旁边有搜索按钮，除了名称、备注和官网，也能按请求地址查找。关掉搜索框后列表会恢复完整，不会再停在筛选结果上。不需要这个按钮的话，可以在「设置 → 通用 → 侧栏与页头」关掉「显示供应商搜索」，快捷键照样能用。

**Skills 一键更新全部。** 以前要先检查更新，再把列表筛到「可更新」，再到筛选栏里找「全部更新」。现在检查到更新后，「检查更新」按钮会直接变成「全部更新（N 个）」，确认框会列出每个要更新的 Skill 和它的来源仓库。确认后对话框马上关闭，按钮上显示更新进度。重新检查放到了「…」菜单里。

**额度数字的颜色回来了。** 4.0 把额度文字都改成了灰色，额度充足还是快用完很难一眼看出来。现在恢复 3.x 的绿、橙、红三色，只给数字上色，档位名称和「剩余」两个字仍是灰色。剩余不足 20% 就会变色提醒（以前是 10%），托盘里的「快用完」也按 20% 算。

**Codex 聚合模式可以让子 agent 用经典工具。** Codex 新版的子 agent 工具会把主 agent 交代的任务交给主 agent 所在的服务商加密，子 agent 换到另一家供应商就解不开，只能报错或拿到空任务。在「设置 → 应用配置 → Codex」打开「聚合模式下子 agent 用经典工具」后，聚合里的所有模型改用 Codex 经典的子 agent 工具，任务以明文传递；代价是没有 `followup_task`、`interrupt_agent` 等新版功能。开关默认关闭，只影响聚合模式，改完要重启 Codex。开关关闭时遇到这种情况，CC Switch 会直接返回错误说明原因并提示这个开关，不再让子 agent 带着空任务运行，也不再让 Codex 反复重试。

**Codex 切换账号后会提示重启后台服务。** Codex 的后台服务不一定会重新读取登录信息，切换账号后可能还在用切换前的账号。以前只有聚合模式下模型列表变了才会提示重启，现在直连、路由、聚合三种模式下切换了账号都会提示，点按钮确认后才会重启后台服务；用 Codex 桌面版或编辑器插件时，提示完全退出后重新打开。

**CC Switch 有新版本时，侧栏「设置」上的提示点改成绿色**，点「设置」会直接打开「关于」页。「应用」上的工具更新提示点保持原样。

## 修复

- **Claude Code 经路由转换到 OpenAI Chat 格式的供应商时，最后一段回复整段丢失。** 有的上游在结束时不发送结束原因，或者发完结束原因后又补了一段内容，转换后的最后一段文字或工具调用没有正确结束，Claude Code 会丢掉这段内容，还会触发重试。
- **Codex 聚合模式下，带有网页搜索记录的会话压缩上下文时报 502。** 压缩时 CC Switch 会删掉请求里的工具定义，但历史记录里还有网页搜索、函数调用这些工具调用，部分上游会直接拒绝这样的请求。现在压缩时保留工具定义，并要求模型这一轮不调用工具。
- **Codex 聚合模式下，官方账号设为默认后，`/model` 里只剩第三方模型。** CC Switch 按 PATH 里 `codex` 命令的版本去拉官方模型列表，官方对 0.140 及更早的版本只返回隐藏的模型。只用 Codex 桌面版的用户 PATH 里常常留着旧版命令行，官方模型就全被隐藏了。现在按本机实际在用的最新版本去拉（命令行、桌面版、编辑器插件都算）。如果拉到的列表里没有可显示的模型，会改用 CC Switch 自带的列表，并提示升级 Codex。
- **Codex 用路由转 Chat 格式的第三方供应商或 GitHub Copilot 时，模型目录会跟着官方条目的改动变化。** 以前 CC Switch 照着 Codex 本地缓存的官方 gpt-5.5 条目生成这类模型的目录，官方每次改这个条目（比如设为隐藏、换成新的工具形态）都会带到第三方模型上；缓存还写明 GPT-5.5 将在 10 月 14 日下线，下线后每次切换都要额外启动一次 Codex 命令行。现在一律使用 CC Switch 自带的模板。
- **删除托管的 ChatGPT 账号或全部登出后，绑定这个账号的 Codex 供应商无法切换。** 这些供应商还指着已删除的账号。现在删除或登出时会一起解除绑定，供应商改为跟随 Codex 自己的登录。供应商会随云同步，所以只解除本机账号的绑定，其他设备上的账号绑定不受影响。
- **用 npm 安装的 Claude Code，在 macOS、Linux 上通过「应用」页升级后无法运行。** 上一版修好了 npm 12 下的安装，但升级时调用的 `claude update` 仍会被 npm 12 拦下安装脚本，同时提示升级成功。现在升级时也允许安装脚本运行。Windows 和 WSL 的升级路径这次没有改。
- **Skills 导入对话框关不掉。** 打开过「发现」页的话，导入时要等「发现」列表从 GitHub 全部重新下载完，网络慢时对话框会一直卡住，无法取消或关闭。
- **托盘里火山、智谱、MiniMax 等有三档额度的供应商，看不到 5 小时额度。** 托盘只显示剩余最少的两档，5 小时额度重置最勤、通常剩得最多，几乎总被省掉。现在和 3.x 一样显示全部档位。
- **浅色模式下，「应用」页「显示」列的开关分不清开和关。** 打开时是深灰、关闭时是中灰，现在改用和其他开关一样的颜色。

**其他：**
- 新增中文版聚合模式指南，用户手册补充了获取模型列表、models.dev 补全参数和手动填写的区别。
- 三语用户手册更新了 Linux 应用级窗口按钮的设置路径。

## 升级说明

**数据库结构没有变化**，仍然是 20。

**Codex 经路由使用 Chat 格式第三方供应商或 GitHub Copilot 的会话**，升级后继续之前的会话时会自动压缩一次上下文。
