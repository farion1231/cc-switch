# CC Switch v4.0.22

今回のリリースでは DeepSeek Harness に対応しました。CC Switch が管理する 14 番目のアプリです。プロバイダーは DeepSeek Harness の Web 版と Desktop 版の設定にまとめて書き込まれ、MCP、Skills、プロンプトも同期されます。セッションを閲覧でき、「アプリ」ページでインストール、アップグレード、アンインストールもできます。さらに「アカウント」ページで DeepSeek アカウントにログインして残高を確認でき、使用量も集計されます。Oh My Pi の使用量も集計されるようになりました。「ターミナルを開く」では権限の確認をスキップしたり、起動引数を追加したりできるようになり、Codex のカードからもターミナルを開けるようになりました。WebDAV の設定をクリアできるようになり、Skills ではフォルダーを開いたり、「見つける」でドキュメントを確認したりできるようになりました。GitHub Copilot の Claude モデルはネイティブのインターフェースを使うようになり、プロンプトキャッシュのヒット率が大きく向上しました。このほか、macOS で OAuth のリモート MCP に接続していると Claude アカウントの切り替えに失敗する、グローバルプロキシを有効にしていると Claude アカウントの追加で 403 になる、Claude Desktop の新しい会話が既定で Fable を使う、MiniMax の週の利用枠を使い切ると表示されなくなる、使っていないプロバイダーの残高が自動で更新されない、リクエストがルーティング自身に転送されてメモリが急増する、Gemini のツール呼び出しで 400 になる、xAI が Codex 0.163 のリクエストを拒否する、リクエストログにエラーページ全体が保存されてデータベースが肥大化する、といった問題を修正しました。4.0 の更新内容の全体は [v4.0 リリースノート](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-ja.md) をご覧ください。

## 新機能

### DeepSeek Harness

DeepSeek Harness（コマンドは `dsh`）は独立したアプリになり、専用のプロバイダー、MCP、Skills、プロンプト、セッションを持つようになりました（[#8795](https://github.com/farion1231/cc-switch/pull/8795)、[#8986](https://github.com/farion1231/cc-switch/pull/8986)）。設定は `~/.dsh` にあり、`DSH_HOME` が設定されている場合はそちらが優先されます。

- **Web と Desktop をまとめて管理。** DeepSeek Harness の Web 版とデスクトップ版にはそれぞれ設定（profile）があり、CC Switch はプロバイダーと MCP を両方に同時に書き込み、足りないほうは自動で作成します。初期化済みの headless、acp にも一緒に書き込みます。サイドバーの DeepSeek Harness はひとつだけで、「追加済み」の見出しの横に、Web と Desktop でこの一覧を共有していることが示されます。一方の設定が手動で編集されてもう一方と食い違っている場合、編集は拒否されて通知が表示され、あなたの変更を上書きすることはありません。
- **プロバイダーを同時に追加できます。** OpenCode と同じく「追加」「削除」で、複数のプロバイダーを同時に書き込み、DeepSeek Harness の中でモデルを選びます。OpenAI Chat Completions、OpenAI Responses、Anthropic Messages のインターフェースに対応し、プリセットは Pi のカタログから取っています。API Key は DeepSeek Harness 自身の認証情報ファイル `.credentials.yaml` に書き込まれ、設定には参照だけを置きます。設定にあるほかのプラグイン設定はそのまま残し、書き込みに失敗した場合はロールバックします。
- **モデルの編集。** 思考と画像入力はスイッチで切り替え、コンテキスト長と最大出力は個別に入力します。Pi、Kimi Code のモデル行と同じです。DeepSeek Harness では、選択できる思考レベルと、モデルごとのインターフェース互換オプションも設定できます。OpenCode、MiniMax Code のモデル編集もこの形に変わりました。
- **DeepSeek アカウントでのログイン。** 「アカウント」ページの DeepSeek Harness グループで、ブラウザから DeepSeek アカウントにログインすると、残高とボーナスが表示されます。Web と Desktop はこのログインを共有し、どちらでログインまたはログアウトしても両方に反映されます。プロバイダーの追加時に「DeepSeek 公式ログイン」を選ぶと「アカウント」ページに移動します。ログイン後、アカウントは公式カードとして「追加済み」の先頭に表示され、アカウントのモデルは DeepSeek Harness 自身が提供します。このカードは編集できず、ログアウトすると自動で消えます。
- **MCP、Skills、プロンプト。** MCP は stdio と Streamable HTTP の両方に対応します。
- **セッションと使用量。** DeepSeek Harness のセッション（思考過程とツール呼び出しを含む）を閲覧できます。セッションの再開と削除は DeepSeek Harness で行ってください。使用量はセッション記録から取り込み、DeepSeek アカウントを使ったリクエストは「使用量」ページで「DeepSeek アカウント（OAuth）」として別に表示されます。
- **「アプリ」ページで DeepSeek Harness を管理。** npm で `@deepseek-ai/dsh` をインストール、アップグレード、アンインストールします。アンインストールしてもデータは削除されません。
- DeepSeek Harness はローカルルーティングを経由しません。

### Oh My Pi の使用量の集計

「使用量」ページで Oh My Pi の使用量を集計するようになり、専用のアプリ分類があります（[#9046](https://github.com/farion1231/cc-switch/pull/9046)、[#8939](https://github.com/farion1231/cc-switch/issues/8939)）。サブエージェントの使用量や、会話以外のモデル呼び出しも含まれ、初回の取り込みでは過去のサブエージェントのセッションも含みます。Oh My Pi と Pi が同じセッションディレクトリを使っている場合は、それぞれ自分のセッションだけを取り込みます。Pi の取り込み済みのデータを取り込み直す必要はありません。

### 「ターミナルを開く」で権限の確認のスキップと起動引数の追加が可能に

「ターミナルを開く」ダイアログに次の項目が増えました（[#9008](https://github.com/farion1231/cc-switch/issues/9008)）：

- **権限の確認をスキップ。** チェックを入れると、Claude Code と Antigravity は `--dangerously-skip-permissions` で、Codex は `--dangerously-bypass-approvals-and-sandbox` で起動します。既定ではオフです。
- **追加の引数（任意）。** `--debug`、`--append-system-prompt "Be concise"` のような引数を入力すると、起動コマンドの後ろに付けます。スペースで区切り、スペースを含む値は引用符で囲みます。最大 16 個です。引数はプログラムに引数として渡されるだけで、コマンドとして実行されることはありません。

どちらの項目も今回開くターミナルにだけ使われ、設定には書き込まれません。ターミナルが開けたら、CC Switch はアプリごとに選択内容を記憶します。

### Codex のカードからも「ターミナルを開く」

これまで Codex のカードにはこのボタンがありませんでした。現在、サードパーティのカードから開いたターミナルはそのカードだけを使います。`codex -c ...` で起動し、`config.toml` は変更せず、Key は環境変数で渡すのでコマンドラインには現れません。現在のプロバイダーが `config.toml` に残している設定は、できるだけこのカードに影響しない値に変えます。変えられないもの（リクエストヘッダーや指定された profile など）がある場合は、先にこのカードに切り替えてから開くよう通知し、現在のプロバイダーの Key が別の場所に送られるのを防ぎます。現在使用中のカードでは `codex` をそのまま起動します。

### WebDAV 設定のクリア

これまでは WebDAV 同期を設定すると、自動同期をオフにすることしかできず、アドレス、アカウント、パスワードはこのパソコンに残り続けていました（[#8977](https://github.com/farion1231/cc-switch/issues/8977)）。現在は WebDAV 同期の設定に「設定をクリア」ボタンがあり、確認するとこれらの情報をこのパソコンから削除して自動同期を停止します。クラウドにアップロード済みのデータは削除されません。

### Skills：フォルダーを開く、名前をコピー、ドキュメントを見る

- **インストール済みの Skill**（[#8993](https://github.com/farion1231/cc-switch/pull/8993)）：⋯ メニューから「フォルダーを開く」を選ぶと、この Skill のフォルダーをファイルマネージャーで開きます。Skill の名前をクリックすると名前をコピーできます。これまでの「フォルダー名をコピー」はなくなりました。
- **「見つける」ページ**（[#9039](https://github.com/farion1231/cc-switch/issues/9039)）：各行に「ドキュメントを開く」ボタンが追加され、インストール前に説明を確認できます。ドキュメントがない場合はリポジトリのトップページを開きます。

## 改善

**GitHub Copilot の Claude モデルでプロンプトキャッシュのヒット率が大きく向上しました**（[#8908](https://github.com/farion1231/cc-switch/pull/8908)）。これまでは Copilot の Claude モデルをすべて Chat Completions 形式に変換して送っていたため、キャッシュのマーカーが失われ、Claude Code が会話の途中に挿入するシステムメッセージもキャッシュを途切れさせていました。現在は、Copilot がネイティブの Anthropic インターフェースに対応しているモデルは、そのままネイティブのインターフェースを使います。Copilot Enterprise の長いセッションでのキャッシュヒット率は、実測で約 35% から約 95% に上がりました。

**Skill のリポジトリを追加、有効化、無効化、削除するときは、そのリポジトリだけを読み込み直すようにしました**（[#8907](https://github.com/farion1231/cc-switch/pull/8907)、[#1426](https://github.com/farion1231/cc-switch/issues/1426)）。すべてのリポジトリをダウンロードし直すことはなくなりました。更新ボタンを押した場合は、これまでどおりすべてを読み込み直します。

**アカウントを選んだ Claude 公式カードの利用枠を、トレイと使用量の設定でも確認できるように。** これまではカードにだけ表示され、トレイには表示されず、「使用量の設定」ダイアログでは未有効と表示されていました。

**Claude Desktop のルーティングサービスで、`x-api-key` によるトークンの受け渡しにも対応しました**（[#5123](https://github.com/farion1231/cc-switch/pull/5123)）。トークンの検証は、所要時間が一定の比較に変更しました（[#7488](https://github.com/farion1231/cc-switch/pull/7488)、[#7482](https://github.com/farion1231/cc-switch/issues/7482)）。

**Claude の設定フォルダーが WSL にある場合、「アカウント」ページで Claude アカウントにはまだ対応していないと直接説明するようにしました。**「アカウントを追加」「再ログイン」は使えません。これまでは「ターミナルを開く」を使うよう案内していましたが、この場合に開くのは Windows 側の Claude Code なので、やはり使えませんでした。

**MCP、Skills の一覧でチェックボックスにマウスを重ねたとき、ツールチップが二重に表示されなくなりました。** ハテナのヘルプカードは右側に表示されるようになってマウスカーソルを隠さなくなり、長い内容は折り返してカードの中でスクロールします（[#8593](https://github.com/farion1231/cc-switch/pull/8593)）。

**ほかの場所から「アカウント」ページの特定のグループに移動したとき、ページのほかの部分が一緒に動かなくなりました**（[#8964](https://github.com/farion1231/cc-switch/pull/8964)）。

**OpenCode、OpenClaw、Hermes の設定ファイルを読み込めないとき、プロバイダーのページにエラーを表示するように**（[#9044](https://github.com/farion1231/cc-switch/issues/9044)）。これまでは一度も設定していないかのようにページが空のままで、プロバイダーの追加に失敗して初めてエラーが表示され、余分なレコードも残っていました。

**マネージドの ChatGPT、xAI アカウントのログインが期限切れになったとき、通知を「「アカウント」でこのアカウントに再ログインしてください」に変更しました。** これまでは存在しないコマンドを実行するよう表示していました。

**プリセット：** OspreyAI、iFlytek Astron Coding Plan の Claude Code プリセットを追加しました（[#9036](https://github.com/farion1231/cc-switch/issues/9036)）。TokenFlux は新しいドメイン tokenflux.com に変更し、tokenflux.dev を予備のアドレスにしました。

## 修正

- **macOS で OAuth ログインが必要なリモート MCP に接続していると、Claude アカウントの切り替えで「Claude Code のログイン情報が大きすぎてキーチェーンに書き込めないため、切り替えませんでした」と表示される問題**（[#9002](https://github.com/farion1231/cc-switch/issues/9002)）。MCP のログイン情報とアカウントが同じキーチェーン項目に保存されており、一度に書き込める長さの上限を超えていました。現在は長すぎる場合に Claude Code と同じ書き込み方法を使います。
- **グローバルプロキシを有効にしているとき、「アカウント」ページで Claude アカウントを追加すると、ブラウザでのログインに成功した後に 403 になる問題**（[#9038](https://github.com/farion1231/cc-switch/issues/9038)）。トークンの交換は Claude Code 自身が行いますが、これまでは Claude Code がグローバルプロキシを使っていませんでした。現在は、CC Switch が Claude Code のログインや利用枠の照会を実行するとき、グローバルプロキシを渡します（SOCKS プロキシは Claude Code が対応していないため渡しません）。
- **Claude Desktop の新しい会話が既定で Fable を使い、しかも設定を有効にするたびにモデルの順序が変わる問題**（[#7491](https://github.com/farion1231/cc-switch/pull/7491)、[#7457](https://github.com/farion1231/cc-switch/issues/7457)、[#8973](https://github.com/farion1231/cc-switch/issues/8973)）。Claude Desktop はモデル一覧の最初のモデルを既定のモデルにしますが、これまではアルファベット順に書き込んでいました。現在は画面上の Sonnet、Opus、Fable、Haiku の順に書き込み、新しい会話では Sonnet クラスのモデルを既定で使います。
- **MiniMax の週の利用枠を使い切ると、カードとトレイに週の利用枠が表示されなくなり、5 時間の利用枠がリセットされた直後は利用枠が満タンのように見える問題**（[#8124](https://github.com/farion1231/cc-switch/pull/8124)、[#8123](https://github.com/farion1231/cc-switch/issues/8123)）。現在は赤い「使い切り」と、週の利用枠がリセットされるまでのカウントダウンを表示します。
- **使っていないプロバイダーでは、自動照会の間隔を設定しても残高が更新されない問題**（[#8342](https://github.com/farion1231/cc-switch/pull/8342)、[#8335](https://github.com/farion1231/cc-switch/issues/8335)）。
- **上流のアドレスにルーティング自身のアドレスを入力すると、リクエストが際限なくルーティングに戻され、メモリが増え続ける問題**（[#8598](https://github.com/farion1231/cc-switch/pull/8598)）。現在はすぐに設定エラーとして報告します。
- **Claude Code がルーティング経由で Gemini に接続するとき、ツール呼び出しの後に 400 になる問題**：署名の位置が誤っていて「Unknown name thoughtSignature」になる（[#6690](https://github.com/farion1231/cc-switch/pull/6690)）、CC Switch の再起動後や古いターンで署名が失われ、Gemini 3 以降がリクエストを拒否する（[#6833](https://github.com/farion1231/cc-switch/issues/6833)）、Vertex でツール結果の後にテキストが続くと「Requests ending with a model turn are not supported」になる（[#8988](https://github.com/farion1231/cc-switch/issues/8988)）。
- **Claude Code がルーティング経由で OpenAI Responses に変換するとき、WebSearch にブロックするドメインを指定するとすぐに 400 になる問題**（[#8979](https://github.com/farion1231/cc-switch/issues/8979)）。現在は API Key で接続した Responses の上流にはそのまま渡します。ChatGPT 公式ログインのルーティングはブロックするドメインに対応していないため、引き続き明確なエラーを返します。
- **Codex 0.163 以降がルーティング経由で xAI に接続すると 400 になる問題**（[#8997](https://github.com/farion1231/cc-switch/pull/8997)、[#8996](https://github.com/farion1231/cc-switch/issues/8996)）。
- **Codex の `config.toml` に `[[skills.config]]` のような配列テーブルがあると、サードパーティのプロバイダーのアドレスがそのテーブルの中に書き込まれていた問題**（[#9029](https://github.com/farion1231/cc-switch/pull/9029)、[#9023](https://github.com/farion1231/cc-switch/issues/9023)）。
- **OpenCode の新しい形式（V2）のプロバイダーで「接続チェック」を行うと、`options.baseURL` がないと報告される問題**（[#8969](https://github.com/farion1231/cc-switch/issues/8969)）。
- **上流がエラーを返したとき、リクエストログに HTML のエラーページ全体が保存され、データベースとバックアップがどんどん大きくなる問題**（[#9010](https://github.com/farion1231/cc-switch/pull/9010)、[#6706](https://github.com/farion1231/cc-switch/issues/6706)）。現在は各レコードに先頭の 4096 文字だけを保存します。すでに保存された古いレコードは今回は整理しません。
- **Windows で MyDockFinder のようなサードパーティのタスクバーを使っていると、トレイアイコンをクリックしても反応しない問題**（[#8729](https://github.com/farion1231/cc-switch/pull/8729)、[#8565](https://github.com/farion1231/cc-switch/issues/8565)）。
- **Kimi Code 0.43.0 より前のバージョンで、「アプリ」ページからアップグレードしてもバージョンが変わらない問題**（[#9032](https://github.com/farion1231/cc-switch/issues/9032)）。古いバージョンにはアップグレードを自動で確認するオプションがないため、現在はインストールに使ったパッケージマネージャーを使うか、公式のインストールスクリプトを実行し直します。
- **「アプリ」ページで、プログラムファイルはあるのに起動できないアプリが、「インストール済み」グループに入っているのに「未インストール」と表示される問題。** 現在は「実行できません」と表示し、理由も示します。
- **Antigravity の CLI と IDE の両方をインストールしているとき、IDE で続けた古いセッションの使用量が更新されず、セッションを開けない問題**（[#8941](https://github.com/farion1231/cc-switch/issues/8941)）。

## アップグレードに関する注意

**データベースのバージョンが 23 から 24 に上がります。** MCP と Skills に DeepSeek Harness のスイッチを追加するためです。アップグレード前にデータベースは自動でバックアップされます。アップグレード後に旧バージョンに戻すと、旧バージョンはデータベースのバージョンが新しすぎると表示し、開けません。

- DeepSeek Harness はデフォルトでサイドバーに表示されます。使わない場合は「アプリ」ページで「DeepSeek Harness をサイドバーに表示」をオフにできます。
