# CC Switch v4.0.24

今回のリリースでは、「アカウント」ページに「ログイン時にブラウザを自動で開く」スイッチを追加しました。オフにすると、アカウントのログインはログインリンクをコピーするだけになり、どのブラウザで開くかを自分で選べます。アカウントごとに独立したブラウザ環境を使っている方に便利です。このほか、Claude Code や Claude Desktop がルーティング経由で GPT 6.1 Sol / Terra を使うと max の思考レベルが xhigh に下げられる、DeepSeek Harness で PDF 入力に対応したモデルを選ぶとサードパーティのプロバイダーがすべて表示されなくなる、WSL で CC Switch が起動直後に終了する、Codex の Chat プロバイダーで「思考レベルに対応」をオンに戻した後に思考レベルが送られない、といった問題を修正しました。4.0 の更新内容の全体は [v4.0 リリースノート](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-ja.md) をご覧ください。

---

## 新機能

### アカウントのログイン時にリンクをコピーするだけにできるように

これまで「アカウント」ページでアカウントにログインすると、常にシステムの既定のブラウザでログインページが開いていました。AdsPower のようなツールでアカウントごとに別々のブラウザ環境を使っている場合、ログインが違うブラウザで行われてしまいました。

現在は「アカウント」ページの上部に「ログイン時にブラウザを自動で開く」スイッチがあり、Claude、ChatGPT、Copilot、xAI、Antigravity、Kimi、DeepSeek のアカウントのログインはすべてこのスイッチに従います。プロバイダー追加フォームから始めたログインも含みます。オフにすると次のようになります：

- ログインをクリックすると、ログインリンクがクリップボードにコピーされるだけになります。使いたいブラウザで開き、ログインしてアクセスを許可すると、CC Switch が自動で更新されます。
- コードの入力が必要なログインでは、コードを自動でコピーしなくなりました。クリップボードのリンクが上書きされないようにするためです。
- ログインを待っている間は「ログインリンクをコピー」をクリックしてもう一度コピーでき、ログインページを開くボタンは表示されません。

Windows では Claude Code が自分でブラウザを開くため、スイッチがオフのときは CC Switch が Claude Code にログインリンクの出力だけをさせます。

スイッチは既定でオンです。設定はこのパソコンにだけ保存され、クラウド同期の対象にはなりません。

**プリセット：** A6API は新しいドメイン a6api.vip に変更しました。

## 修正

- **Claude Code や Claude Desktop がルーティング経由で OpenAI 形式の上流に接続し、モデルが gpt-6.1-sol または gpt-6.1-terra のとき、max の思考レベルが xhigh に下げられて送信される問題**（[#9122](https://github.com/farion1231/cc-switch/issues/9122)）。現在は GPT 5.6 以降で、サフィックスなし、または sol、terra、luna、astra のサフィックスが付いたモデルはすべて max のまま送ります。pro、codex、mini などそれ以外のサフィックスは引き続き xhigh で送ります。
- **DeepSeek Harness で、取得したモデル一覧から PDF 入力に対応したモデルを選ぶと、サードパーティのプロバイダーがすべて表示されなくなる問題**（[#9116](https://github.com/farion1231/cc-switch/issues/9116)）。DeepSeek Harness のモデルの入力タイプはテキストと画像しか受け付けず、PDF が書き込まれると設定のそのエントリ全体が無効になっていました。現在はテキストと画像だけを書き込みます。
- **WSL で CC Switch が起動直後に終了し、トレイアイコンの「Permission denied」が報告される問題**（[#9021](https://github.com/farion1231/cc-switch/pull/9021)、[#9020](https://github.com/farion1231/cc-switch/issues/9020)）。Linux のトレイアイコンはアプリのキャッシュフォルダーに置くようにしました。
- **Codex の Chat プロバイダーで「思考レベルに対応」をオフにしてからオンに戻すと、選んだ思考レベルが上流に送られなくなる問題**（[#8998](https://github.com/farion1231/cc-switch/pull/8998)、[#8954](https://github.com/farion1231/cc-switch/issues/8954)）。このため GitHub Copilot などの上流に 思考レベルがまったく届いていませんでした。以前に保存したプロバイダーも、編集し直さなくても正常に戻ります。
- **DeepSeek Harness の「DeepSeek 公式ログイン」カードに「Claude アカウントでログイン」と表示される問題**（[#9058](https://github.com/farion1231/cc-switch/pull/9058)）。現在は「DeepSeek アカウントでログイン」と表示されます。
