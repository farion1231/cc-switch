# CC Switch v4.0.8

### 4.0 正式版の 4 回目の修正リリース

Codex のデスクトップ版だけをインストールし、Codex CLI を別にインストールしていない場合でも、Codex の集約モードを使えるようになりました。公式モデル一覧を読み込めないときは案内に原因が表示され、問題が解決すると案内も自動で消えます。プロバイダーの追加・編集時に「モデル一覧を取得」が設定済みのリクエストヘッダーを送るようになり、追加のリクエストヘッダーが必要なゲートウェイに拒否されなくなりました。「設定 → データ」に「ログを開く」ボタンを追加しました。ダークモードの文字を少し暗くし、まぶしさを抑えました。4.0 の更新内容の全体は [v4.0 リリースノート](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.0.4-ja.md) をご覧ください。

---

## 新機能

**「設定 → データ → アプリ診断ログ」に「ログを開く」ボタンを追加しました。** クリックすると、システムのファイルマネージャーで `cc-switch.log` が選択された状態になります。ログファイルがまだ作成されていない場合は、ログのあるフォルダーを開きます。問題を報告するときにそのまま添付でき、隠れた設定ディレクトリを探す必要がなくなります。

## 修正

- **Codex のデスクトップ版だけをインストールしていると、集約ページに「Codex のモデル一覧を読み込めないため、集約したモデルは現在使用できません」と表示され、集約モードを使えなかった問題。** 公式一覧をネットワーク経由で取得できなかったとき、CC Switch は Codex CLI に内蔵されたモデル一覧を代わりに使いますが、これまではシステムのパスからしか `codex` コマンドを探していませんでした。デスクトップ版だけをインストールしている場合はこのコマンドがないため、常に失敗していました。現在は見つからないとき、Codex のデスクトップ版に同梱された CLI も使います。macOS では「アプリケーション」フォルダーの ChatGPT.app と、名前が変わる前の Codex.app を探し、両方ある場合は ChatGPT.app を使います。古い Codex.app から古いモデル一覧が返されるのを避けるためです。Windows ではデスクトップ版のインストールディレクトリにある最新のバージョンを使います。別にインストールした Codex CLI が引き続き優先されます。
- **公式モデル一覧を読み込めないとき、案内から原因がわからず、問題が解決しても案内が消えなかった問題。** これまではどの原因でも同じ「Codex のモデル一覧を読み込めない」という表示でした。現在は案内の下に具体的な原因と対処方法を表示します。公式一覧では、Codex に使える ChatGPT ログインがない、ログインが 8 日以上更新されていない、ログイン情報が不完全、Codex のバージョンを読み取れない、ネットワーク経由での取得に失敗した、返されたデータが不完全、のいずれかです。Codex 内蔵の一覧では、Codex CLI が見つからない、CLI がモデル一覧を出力しなかった、一覧に使えるモデルがない、に分けて表示します。ネットワーク経由での取得と CLI の失敗の詳細はログに記録します。また、これまでは予備の一覧に切り替えた後、公式一覧が回復しても（期限切れのログインが Codex によって自動で更新された場合など）、次に手動で切り替えるまで案内が消えませんでした。現在は CC Switch が自動で公式一覧に戻し、案内も消えます。
- **「モデル一覧を取得」が設定済みのリクエストヘッダーを送らず、追加のリクエストヘッダーが必要なゲートウェイに拒否されていた問題。** たとえば Cloudflare AI Gateway は `cf-aig-authorization` リクエストヘッダーを必要とします。現在は OpenCode のプロバイダーでは設定済みのリクエストヘッダーを送り、Claude Code、Codex、Grok Build のプロバイダーでは「Header 上書き」に入力したリクエストヘッダーを送ります。形式が正しくない場合や空欄の場合は、通常どおり取得します。Codex と Grok Build のフォームで「Header 上書き」を変更すると、取得済みのモデル一覧はクリアされます。現在の認証情報では使えないモデルを選んでしまうのを防ぐためです。
- **ダークモードの文字が明るすぎて、長く見ているとまぶしかった問題。** 3 段階の文字色がどれも純白に近く、表やラベルが画面いっぱいにあると強すぎて、主従の区別もつきにくくなっていました。現在は 3 段階とも少し暗くし、補助的な文字もカードや選択中の背景の上で十分なコントラストを保ちます。ライトモードは変わっていません。

**その他：**
- v4.0.7 リリースノートの「Codex の古いセッションを圧縮」の節に、有効にする方法、圧縮されるタイミング、古いセッションを続ける方法、CC Switch での表示、注意点を追記しました。
- 英語版と日本語版の残量表示の説明、および英語版・日本語版・繁体字中国語版のバックアップの案内で、画面に実際に表示される名称を使うようにしました。
