# 在线接口转 MCP 实施计划

目标：实现 [设计方案](../../design/mcp/api-bridge-design-zh.md) 中的双入口、内置 stdio 运行时和现有 MCP 同步集成。

1. 在 `src-tauri/src/mcp_api/` 增加规范化定义、OpenAPI 编译和有界配置编码。先验证规范解析、内部引用、非法目标及参数映射失败，再实现。
2. 增加复用连接池的 HTTP 调用与 stdio 生命周期，`main.rs` 在 GUI 初始化前识别 `--mcp-api`。通过本机 HTTP 与真实子进程验证协议和边界。
3. 在 `commands/mcp.rs` 暴露预览、配置生成、已存配置解码；生成操作不写客户端，由现有 upsert 路径完成保存。
4. 在 MCP 页面增加 API 编辑页，涵盖文档 URL/文本、手工接口、工具选择、Header、目标应用；四语文案同步。前端测试验证用户流程和失败后不保存。
5. 执行相关前后端回归、类型/格式/构建检查，并记录可重现性能数据和未覆盖平台。

重点复核：远端规范改变不能自动新增工具；静态鉴权不能被模型覆盖；路径参数不能改变 origin；错误不泄露查询凭据；已有服务编辑保留未选应用的状态。

实现与本机验证已完成，检查结果、性能数据及未验证范围见 [验证记录](../../review/mcp/api-bridge-verification-zh.md)。
