# 2.3 编辑供应商

## 打开编辑面板

1. 找到要编辑的供应商卡片
2. 鼠标悬停在卡片上，显示操作按钮
3. 点击「编辑」按钮

## 可编辑内容

### 基本信息

| 字段 | 说明 |
|------|------|
| 名称 | 供应商显示名称 |
| 备注 | 附加说明信息 |
| 网站链接 | 供应商官网或控制台地址 |
| 图标 | 自定义图标和颜色 |

### 图标自定义

CC Switch 提供丰富的图标自定义功能：

#### 图标选择器

1. 点击图标区域打开图标选择器
2. 使用搜索框按名称搜索图标
3. 点击选择想要的图标

图标库包含常见的 AI 服务商和技术图标，支持：
- 按名称模糊搜索
- 显示图标名称提示
- 实时预览选中效果

## 配置编辑框

Claude Code、Codex、Gemini CLI、Grok Build 的编辑面板底部，显示的是**切到这个供应商之后，工具配置文件的样子**：

| 应用 | 编辑框 |
|------|--------|
| Claude Code | `~/.claude/settings.json` |
| Codex | `~/.codex/config.toml`（Key 在上方的 API Key 输入框里，不在编辑框中重复） |
| Gemini CLI | `~/.gemini/.env` 和 `~/.gemini/settings.json` |
| Grok Build | `~/.grok/config.toml` |

编辑框里的内容分两类，编辑框上方有一行说明列出这个应用的第一类包括哪些：

- **随供应商切换的**：请求地址、Key、模型名、接口协议等关键字段，以及少数跟着供应商走的兼容选项（如上下文窗口）。显示的是这个供应商自己的值，保存后存进这个供应商。
- **全局设置**：其余所有内容，比如插件、Hook、权限、MCP、你自己加的环境变量。显示的是工具配置文件里现在的内容，保存后直接写进配置文件，对所有供应商生效。

编辑当前供应商和编辑其他供应商，规则完全一样：不管编辑哪个供应商，改全局设置都会立即写进配置文件。开启本地路由时，编辑框里的关键字段显示的也是供应商自己的真实地址和 Key，不是本地路由地址。

### 在工具里改的设置

- **全局设置**：在工具里改了（比如装了插件），打开编辑面板就能看到，切换供应商也不会改动它们。
- **关键字段**：在工具里临时换的模型（比如 Claude Code 的 `/model`）不会存回供应商，切走再切回来会恢复成供应商保存的值。想长期修改，请在这里编辑供应商。

> 💡 旧版本编辑当前供应商时，会把配置文件整份读回供应商（「回填」）。新版本不再回填：共享设置本来就留在配置文件里，不需要存进某一个供应商。

### 编辑期间配置文件被改过

保存时，CC Switch 只提交你在编辑框里改过的设置，并逐条检查：打开编辑面板之后，这条设置在配置文件里有没有被工具或其他程序改过。

- 没被改过：直接写入。
- 被改过：弹出「配置文件在编辑期间被修改」，列出这些设置，由你选择「保留外部修改」或「用我的修改覆盖」。其余改动照常保存。

你没改过的设置不会提交，所以不会覆盖工具在这期间写入的内容。

### 不随切换生效的设置

旧版本的「回填」、深链导入或旧预设，可能让供应商里存着一些关键字段以外的设置。这些设置不会写进配置文件，编辑框下方会把它们列出来：

- **Claude Code、Gemini CLI**：点击某一项，把它加入上方编辑框，保存后作为全局设置写进配置文件。
- **Codex、Grok Build**：点击某一项复制它的 TOML，按需粘贴到上方编辑框。

供应商里保存的原值不会删除。

### 配置文件读不出来时

如果工具的配置文件格式有错误，编辑框会改为显示供应商里保存的内容，并在上方提示原因。修好配置文件后重新打开编辑面板即可。

## 自动获取模型

编辑供应商时，可以自动从供应商端点获取可用模型列表：

1. 确保已填写 API Key 和端点地址
2. 点击模型输入框旁的 **获取模型** 按钮（下载图标）
3. 从分组下拉菜单中选择模型

详细说明请参阅 [2.1 添加供应商 — 自动获取模型](./2.1-add.md#自动获取模型)。

## 快捷开关（Claude）

编辑 Claude 供应商时，JSON 编辑器上方提供常用设置的快捷开关，包括工具搜索、禁用自动更新、Teammates、最大强度思考等。其中「启用 Tool Search」和「禁用 Artifact 工具」跟随供应商，其余是全局设置。详见 [2.1 添加供应商 — Claude 快捷开关](./2.1-add.md#claude-快捷开关)。

## 修改 API Key

编辑供应商时，可以直接在 **API Key** 输入框中修改：

1. 点击供应商卡片的「编辑」按钮
2. 在「API Key」输入框中输入新的密钥
3. 点击「保存」

> 💡 **提示**：API Key 输入框支持显示/隐藏切换，点击右侧的眼睛图标可查看完整密钥。

## 修改端点地址

编辑供应商时，可以直接在 **端点地址** 输入框中修改：

1. 点击供应商卡片的「编辑」按钮
2. 在「端点地址」输入框中输入新的 URL
3. 点击「保存」

### 端点地址格式

| 应用 | 格式示例 |
|------|----------|
| Claude | `https://api.example.com` |
| Codex | `https://api.example.com/v1` |
| Gemini | `https://api.example.com` |

## 添加自定义端点

供应商可以配置多个端点，用于：

- 速度测试时测试多个地址
- 故障转移时的备用端点

### 自动收集

添加供应商时，CC Switch 会自动从配置中提取端点地址。

### 手动添加

编辑供应商时，在「端点管理」区域可以：

- 添加新端点
- 删除现有端点
- 设置默认端点

## JSON 编辑器

配置使用 JSON 格式，编辑器提供：

- 语法高亮
- 格式校验
- 错误提示

### 常见错误

**缺少引号**：
```json
// ❌ 错误
{ env: { KEY: "value" } }

// ✅ 正确
{ "env": { "KEY": "value" } }
```

**多余逗号**：
```json
// ❌ 错误
{ "env": { "KEY": "value", } }

// ✅ 正确
{ "env": { "KEY": "value" } }
```

**未闭合括号**：
```json
// ❌ 错误
{ "env": { "KEY": "value" }

// ✅ 正确
{ "env": { "KEY": "value" } }
```

## 保存与生效

1. 点击「保存」按钮
2. 如果表单检测到非阻塞问题，会出现「先存上再说」确认提示；确认后仍可保存
3. 全局设置的改动立即写入配置文件，不管编辑的是不是当前供应商
4. 关键字段的改动存进供应商。未开启本地路由时，如果编辑的是当前供应商，同时写入配置文件；开启本地路由时，如果编辑的是路由正在使用的供应商，而且改动影响本地路由写进配置文件的内容（比如模型名），配置文件也会一并更新
5. 是否需要重启工具，和切换供应商相同，见 [2.2 切换供应商](./2.2-switch.md)

## 取消编辑

点击「取消」或按 `Esc` 键关闭编辑面板，所有修改都不会保存。
