# 2.4 排序与复制

## 拖拽排序

通过拖拽调整供应商的显示顺序。

### 操作步骤

1. 将鼠标移到供应商卡片上，卡片最左侧会出现 **⋮⋮** 拖拽手柄（平时隐藏）
2. 按住鼠标左键
3. 上下拖动到目标位置
4. 松开鼠标完成排序，会提示「排序已更新」

### 排序用途

- **常用优先**：将常用的供应商放在列表顶部
- **故障转移顺序**：队列里的顺序就是供应商的排序。在「路由」标签的「队列 · 按优先级」里，也可以点卡片上的上移、下移按钮，或直接拖动，调整先发给谁；详见 [4.3 故障转移](../4-proxy/4.3-failover.md)
- 托盘菜单里的供应商顺序也跟着变

## 复制供应商

快速创建供应商的副本，适用于：

- 基于现有配置创建变体
- 备份当前配置
- 创建测试用配置

统一供应商列表（添加页里「统一供应商」分类下的「管理已有的统一供应商」）也提供复制按钮，可直接从现有统一供应商创建副本后再调整同步应用和模型。

### 操作步骤

1. 点击供应商卡片右侧的 **⋯**（更多）按钮
2. 选择「复制」
3. 自动创建副本，名称后缀 `copy`
4. 点卡片上的编辑按钮，修改副本的配置

### 复制内容

复制会创建一个副本，带上：

| 内容 | 是否复制 |
|------|----------|
| 名称 | ✅ 复制（添加 `copy` 后缀） |
| 配置 | ✅ 完整复制 |
| 备注 | ❌ 不复制，需要的话在副本里重新填写 |
| 网站链接 | ✅ 复制 |
| 图标 | ✅ 复制 |
| 端点列表 | ✅ 复制 |
| 排序位置 | ✅ 排在原供应商之后 |

### 复制后编辑

复制完成后，通常需要修改：

1. **名称**：改为有意义的名称
2. **API Key**：如果是不同账号
3. **端点**：如果是不同服务

## 删除供应商

### 操作步骤

1. 点击供应商卡片右侧的 **⋯**（更多）按钮
2. 选择「删除」（红色，在菜单最下面）
3. 在确认框里确认删除

### 删除确认

删除前会弹出确认对话框，显示：

- 供应商名称
- “此操作无法撤销”的提示

### 删除限制

- **正在使用的供应商**：不能删除，「删除」是灰的，说明里写着「正在用的这家不能删除，先切到别家」。切换式应用里，直连用的那家、路由或聚合模式下正在路由的那家都算；先切到别家再删
- **统一供应商**：删除后，关联的应用配置也会被删除
