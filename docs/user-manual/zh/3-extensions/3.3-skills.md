# 3.3 Skills 技能管理

## 功能说明

Skills 是可复用的能力扩展，让 AI 工具获得特定领域的专业能力。

技能以文件夹形式存在，包含：

- 提示词模板
- 工具定义
- 示例代码

## 支持的应用

Skills 功能支持以下应用：

- **Claude Code**（Claude Desktop 页面的 Skills 面板操作的也是 Claude Code）
- **Codex**
- **Gemini CLI**
- **Grok Build**
- **OpenCode**
- **Hermes**
- **Pi**
- **MiniMax Code**

OpenClaw 暂不支持 Skills 管理。

## 打开 Skills 页面

点击左侧栏的 **Skills**。它是全局页，不属于某个应用：不管当前选中哪个应用，打开的都是同一个页面（Claude Desktop 没有自己的 Skills，这里也不会出现它的列）。

页面顶部有两个视图可以切换：**已安装** 和 **发现**。

## 页面概览

「已安装」是一张矩阵表：**每行一个 Skill，每列一个应用**，格子里的开关就是「这个 Skill 在这个应用里启用」。

- 页头：「添加 Skill」按钮，以及 ⋯ 菜单（检查更新、从备份恢复、仓库管理、存储与同步）
- 搜索框：按名称、目录、描述或仓库搜索
- 筛选：全部 / 可更新 / 未在任何应用启用 / 在某个应用启用，另可按来源仓库筛选
- 只显示在侧栏「应用」页里设为显示的应用的列；隐藏只影响界面，已经启用的照常保留
- 勾选多行后可以批量「启用到」某个应用、「停用」、「更新」或「卸载」
- 点列头可以对一整列批量启用或关闭，只作用于当前列表里的条目
- Pi 没有独立开关数据，按 `~/.pi/agent/skills` 里有没有这个目录来判断是否启用

## 发现技能

切到「发现」视图，浏览和搜索可安装的 Skill。

### 预配置仓库

CC Switch 预配置了若干 GitHub 技能仓库，包括 Anthropic 官方（`anthropics/skills`）和 ComposioHQ（`ComposioHQ/awesome-claude-skills`）等。「发现」里的「仓库」按钮可以选择哪些仓库参与发现，「重新读取仓库」会重新扫描，获取最新技能。

### 搜索

- 「仓库」来源：按 Skill 名称或仓库名搜索，输入即过滤；可按状态过滤，「显示全部」和「只看未安装」之间切换
- 「skills.sh」来源：在 [skills.sh](https://skills.sh) 公共注册表里搜索，至少输入 2 个字，回车搜索，结果可以「加载更多」

## 安装技能

### 操作步骤

1. 在「发现」视图里找到要安装的 Skill
2. 先在「安装到」里选好要在哪些应用启用（会记住你上次的选择，默认用上次的）
3. 点击这一行的「安装」，等待完成

装好后会直接在所选应用里启用，之后可以在「已安装」里随时调整。除了从仓库安装，还可以用页头「添加 Skill」菜单里的：

- **在发现里浏览**：切到「发现」视图
- **从 ZIP 安装**：选一个含 `SKILL.md` 的 ZIP 包；ZIP 里目录名已被占用的 Skill 会被跳过，要换成 ZIP 里的版本，先卸载同名的再安装
- **导入本机已有**：把本机各应用目录里已有、但还不归 CC Switch 管理的 Skill 导入进来。导入会复制一份到 CC Switch 的目录，原文件不动

页面上方出现「本机有 N 个 Skill 不在 CC Switch 管理中」的提示时，可以点「查看并导入」。

### 安装位置

| 应用     | 安装目录              |
| -------- | --------------------- |
| Claude Code | `~/.claude/skills/`   |
| Codex    | `~/.codex/skills/`    |
| Gemini CLI | `~/.gemini/skills/`   |
| Grok Build | `~/.grok/skills/` |
| OpenCode | `~/.config/opencode/skills/` |
| Hermes | `~/.hermes/skills/` |
| Pi | `~/.pi/agent/skills/` |
| MiniMax Code | `~/.minimax/skills/` |

如果在设置中覆盖了配置目录，安装目录随之变化（MiniMax Code 的数据目录可用环境变量 `MINIMAX_DATA_DIR` 指定，Pi 另外识别 `PI_CODING_AGENT_DIR`）。技能的主副本存放在「存储与同步」里所选的目录（默认 `~/.cc-switch/skills/`，见下文 [存储与同步](#存储与同步)），再通过软链接或文件复制同步到各应用目录。

### 安装内容

安装会将技能文件夹复制到本地：

```
~/.claude/skills/
└── skill-name/
    ├── README.md
    ├── prompt.md
    └── tools/
        └── ...
```

## 卸载技能

### 操作步骤

1. 在「已安装」里找到这个 Skill，点这一行 ⋯ 菜单里的「卸载」（多选后也可以批量卸载）
2. 确认卸载

### 卸载效果

- **自动备份**：删除前，技能会被备份到 `~/.cc-switch/skill-backups/`
- 从所有应用的技能目录移除技能
- 从主副本所在的存储目录（默认 `~/.cc-switch/skills/`）移除技能
- 从数据库删除技能记录

### 从备份恢复

如需恢复之前卸载的技能：

1. 打开 Skills 页面
2. 点击页头 ⋯ 菜单里的 **从备份恢复**
3. 从列表中选择要恢复的备份（显示技能名称和备份时间），点「恢复」
4. 技能将被恢复，并在「发现」里「安装到」所选的应用启用

### 删除备份

如需删除旧的技能备份：

1. 在恢复对话框中，找到要删除的备份
2. 点击备份条目旁的 **删除** 按钮
3. 确认删除 — 此操作不可撤销

## 仓库管理

### 打开仓库管理

点击页头 ⋯ 菜单里的「仓库管理」（「发现」视图里的「仓库」按钮下也有「添加或管理仓库」入口）。

### 添加自定义仓库

1. 在「仓库 URL」里填 `owner/name` 或完整的 `https://github.com/owner/name`
2. 填写分支（默认 main）
3. 技能路径可选：技能所在的子目录，留空则扫描根目录
4. 点击「添加仓库」

添加成功后会提示识别到几个技能。

### 删除仓库

在「已添加的仓库」列表里点仓库右侧的删除按钮。

删除仓库后，已经安装的技能不会消失，但无法再从这个仓库更新。

## 技能行信息

「已安装」里每一行显示：

| 信息 | 说明 |
| ---- | ---- |
| 名称、描述 | 技能名称和功能说明 |
| 来源 | 所属仓库，本地导入的显示「本地」 |
| 各应用开关 | 在哪些应用里启用；写入失败的应用会标出，可点「改同步方式」去调整 |
| 有新版本 | 远端有更新时显示「可更新」 |

## 技能更新

Skills 支持**更新检测**和**批量更新**，不需要卸载后重新安装。

### 更新检测原理

CC Switch 基于 **SHA-256 内容哈希**比较本地已安装的 skill 与远端仓库版本。只要远端有任何文件内容变化，对应的 skill 就会标为「可更新」。

### 检查更新

点击页头 ⋯ 菜单里的「检查更新」，或「已安装」搜索框旁的「检查更新」，重新扫描远端仓库。页面会显示「上次检查」的时间；有仓库没读到时会提示，更新结果可能不完整。

### 单项更新与全部更新

- 有新版本的 Skill，点这一行的「更新」
- 有可更新的 Skill 时，页头会出现「N 个可更新」，点它可以只看可更新的；筛选栏里的「全部更新（N 个）」会批量更新，更新前会确认

> ⚠️ 更新会用仓库里的内容替换本地目录，本地改过的地方只保留在备份里。

## 存储与同步

点击页头 ⋯ 菜单里的「存储与同步」，可以设置两件事：

### 主副本放在哪

| 位置                     | 说明                                                     |
| ------------------------ | -------------------------------------------------------- |
| **CC Switch 目录**       | 默认位置 `~/.cc-switch/skills/`，由 CC Switch 统一管理    |
| **通用目录**（`~/.agents/skills`） | 符合社区 agent 工具约定的共享目录，便于与其他工具协同    |

切换时点「移动并切换」，CC Switch 会逐个移动主副本，再让各应用里的链接指向新位置，不会丢失 skill 状态。移动完成前请不要退出 CC Switch。

> ⚠️ 选「通用目录」后，Codex、Gemini CLI、OpenCode 等会直接读这个目录，各应用的开关对它们不再完全生效。

### 同步到各应用的方式

| 方式 | 说明 |
| ---- | ---- |
| 自动（推荐） | 优先用软链接，失败时复制 |
| 只用软链接 | Windows 需要开启开发者模式 |
| 只用复制 | 占用更多空间，更新后会重新复制 |

修改只对之后启用或更新的 Skill 生效；要让已启用的 Skill 也换成当前方式，点「立即重新同步」。

## 常见问题

### 技能列表为空

可能原因：

- 网络问题，无法访问 GitHub
- 仓库配置错误

解决方法：

- 检查网络连接
- 点击「重新读取仓库」重试
- 检查仓库配置

### 安装失败

可能原因：

- 网络问题
- 磁盘空间不足
- 权限问题

解决方法：

- 检查网络连接
- 检查磁盘空间
- 检查目录权限

### 更新按钮不出现

可能原因：

- 远端仓库没有新内容
- CC Switch 尚未完成最新扫描

解决方法：

- 点击「检查更新」重新扫描
- 确认仓库配置指向正确的分支和路径
