# 3.2 Prompts 提示词管理

## 功能说明

Prompts 功能用于管理系统提示词预设。系统提示词会影响 AI 的行为和回复风格。

通过 CC Switch，你可以：

- 创建多个提示词预设
- 快速切换不同场景的提示词
- 跨设备同步提示词配置

## 打开 Prompts 面板

点击左侧栏的 **提示词**。它是全局页，页头左侧的下拉框用来选应用：Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、Hermes、Pi、MiniMax Code（只列在「应用」页里设为显示的应用）。

- Claude Desktop 没有自己的提示词，从它的页面进入时操作的是 Claude Code 的提示词。
- OpenClaw 不在提示词页里，它的 AGENTS.md 等文件用[工作区编辑器](./3.5-workspace.md)管理。
- Hermes 在这里管理的是人设文件 `SOUL.md`；`MEMORY.md` 和 `USER.md` 在 Hermes 页面的「记忆」页里编辑。

## 创建预设

### 操作步骤

1. 点击页头的 **添加提示词**，右侧打开抽屉
2. 填写名称，可选填说明（只在 CC Switch 里显示）
3. 在正文框里用 Markdown 写提示词
4. 点击「添加」

文件里已有、但还不在 CC Switch 里的内容，可以用页头 ⋯ 菜单里的「导入当前的 xxx」存成一条，不会改动文件。

### 提示词编写建议

**结构化格式**：

```markdown
# 角色定义

你是一个专业的代码审查专家。

## 核心能力

- 代码质量分析
- 性能优化建议
- 安全漏洞检测

## 回复风格

- 简洁明了
- 提供具体示例
- 给出改进建议

## 注意事项

- 不要修改业务逻辑
- 保持代码风格一致
```

## 启用预设

### 操作方式

点击预设行上的「启用」按钮；启用中的那一行显示「已启用」，按钮变成「停用」。

### 同时只启用一条

同一时间每个应用只能启用一条。启用新的，之前启用的会自动停用。启用后，这一条的正文会覆盖目标文件；停用后文件被清空（Pi 的 `AGENTS.md` 会被删除）。

### 同步目标

启用后，提示词会写入对应应用的文件：

| 应用 | 文件路径 |
|------|----------|
| Claude Code | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| Gemini CLI | `~/.gemini/GEMINI.md` |
| Grok Build | `~/.grok/AGENTS.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |
| Hermes | `~/.hermes/SOUL.md`（Hermes 的人设，新开的会话生效） |
| Pi | `~/.pi/agent/AGENTS.md` |
| MiniMax Code | `~/.minimax/AGENTS.md`（内容不能超过 32 KiB） |

如果在设置中覆盖了配置目录，文件路径随之变化。MiniMax Code 没有目录覆盖设置，数据目录可用环境变量 `MINIMAX_DATA_DIR` 指定；Pi 另外识别 `PI_CODING_AGENT_DIR`。

### Pi 的额外内容

Pi 的提示词页分为三个标签：

| 标签 | 说明 |
|------|------|
| 提示库 | AGENTS.md 提示库，同时只启用一条，写入 Pi 的全局 `AGENTS.md` |
| 系统提示 | 编辑 `APPEND_SYSTEM.md`（追加在 Pi 内置基础提示之后，推荐）或 `SYSTEM.md`（替换 Pi 内置基础提示）；文件存在就生效，不用启用 |
| 模板 | 管理 Pi 的提示词模板，保存后在 Pi 里输入 `/命令名` 调用，不用启用 |

已经打开的 Pi 不会自动热更新，空闲时运行 `/reload`；新启动的 Pi 会自动读取。

## 编辑预设

1. 点击预设行的「编辑」按钮（或点这一行）
2. 在抽屉里修改名称、说明或正文
3. 点击「保存」

如果编辑的是启用中的预设，保存后会立即覆盖目标文件。

## 删除预设

1. 点击预设行 ⋯ 菜单里的「删除」
2. 确认删除

启用中的预设不允许删除，需先停用。删除只影响 CC Switch 里的这一条，目标文件不会被改动。

## 手动修改文件会怎样

你可以在 CLI 或外部编辑器里直接改目标文件，CC Switch 不会让这些修改丢失：

| 场景 | 处理方式 |
|------|----------|
| 在别处改了启用中那条对应的文件 | 下次打开本页时，改动会收进启用中的那一条 |
| 文件里有 CC Switch 里没有的内容 | 启用别的提示词之前，先把这些内容存成一条「原始提示词」，再覆盖 |
| 文件里已有内容、列表还是空的 | 用页头 ⋯ 菜单的「导入当前的 xxx」，或空列表页上的「导入现有内容」存成一条 |

## 跨应用使用

Prompts 是按应用分开管理的：在页头下拉框里换应用，列表就换成那个应用的预设。

如需在多个应用使用相同的提示词，不用重新输入：点预设行 ⋯ 菜单里的「复制到其他应用」，勾选目标应用，各自复制成独立的一条，不会自动启用，之后改动互不影响（Hermes 的 SOUL.md 是人设，默认不勾选）。

## 导入导出

### 通过深度链接分享

可以生成深度链接分享预设：

```
ccswitch://v1/import?resource=prompt&app=claude&name=<名称>&content=<Base64 编码的提示词内容>
```

参数说明与示例见 [5.3 深度链接协议](../5-faq/5.3-deeplink.md)。

### 通过配置导出

导出配置时会包含所有预设，导入后可恢复。
