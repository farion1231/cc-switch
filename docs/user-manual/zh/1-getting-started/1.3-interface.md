## 顶部导航栏

| 序号 | 元素 | 功能说明 |
|------|------|----------|
| ① | Logo | 点击访问官网 ccswitch.io |
| ② | 设置按钮 | 打开设置页面（快捷键 `Cmd/Ctrl + ,`） |
| ③ | 本地路由开关 | Claude Code / Codex / Gemini CLI / Grok Build 页面：开启/关闭当前应用的本地路由（需在「设置 → 路由 → 本地路由」中打开「在主页面显示本地路由开关」）；Claude Desktop 页面：始终显示，启停 Claude Desktop 使用的本地路由 |
| ④ | 应用切换器 | 在 10 个受管应用之间切换 |
| ⑤ | 功能区 | 当前应用支持的功能入口 |
| ⑥ | 添加按钮 | 添加新供应商 |

另外还有几个按条件出现的入口：

- **项目切换器**：默认显示（MiniMax Code 页面除外），可在「设置 → 通用 → 主页面显示」中关闭「显示项目切换」
- **故障转移开关**：在「设置 → 路由 → 自动故障转移」中打开「在主页面显示故障转移开关」后显示
- **使用统计按钮**：当前应用开启本地路由时显示

### 应用切换器

点击顶部的应用图标切换当前管理的应用（窗口较窄时，放不下的应用会收进「更多应用」菜单）：

- **Claude** - 管理 Claude Code 配置
- **Claude Desktop** - 管理 Claude Desktop 第三方供应商与官方模式
- **Codex** - 管理 Codex 配置
- **Gemini** - 管理 Gemini CLI 配置
- **OpenCode** - 管理 OpenCode 配置
- **OpenClaw** - 管理 OpenClaw 配置
- **Hermes** - 管理 Hermes Agent 供应商与 Memory
- **Grok Build** - 管理 Grok Build 配置
- **Pi** - 管理 Pi 的供应商与模型
- **MiniMax Code** - 管理 MiniMax Code 的自定义供应商

切换后，供应商列表会显示对应应用的配置。不常用的应用可以在「设置 → 通用 → 主页面显示」中隐藏。

### 功能区按钮

不同应用显示的功能按钮不同：

| 应用 | 功能区按钮 |
|------|------------|
| Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、MiniMax Code | Skills、Prompts、会话、MCP |
| Pi | Skills、Prompts、会话（Pi 没有 MCP） |
| Claude Desktop | 与 Claude Code 相同，操作的是 Claude Code 的数据 |
| Hermes | Skills、记忆管理、Hermes Web UI、MCP |
| OpenClaw | 工作区、环境变量、工具、Agents、会话 |

各应用的 MCP、Skills、Prompts 支持范围详见 [3.1 MCP](../3-extensions/3.1-mcp.md)、[3.2 Prompts](../3-extensions/3.2-prompts.md)、[3.3 Skills](../3-extensions/3.3-skills.md)。

## 供应商卡片

每个供应商以卡片形式展示，从左到右依次包含以下元素：

### 卡片元素（从左到右）

| 序号 | 元素 | 图标 | 功能说明 |
|------|------|------|----------|
| ① | 拖拽手柄 | ≡ | 按住上下拖动调整供应商顺序 |
| ② | 供应商图标 | 🔷 | 显示供应商品牌图标，可自定义颜色 |
| ③ | 供应商信息 | - | 名称、备注/端点地址（可点击打开官网） |
| ④ | 用量信息 | - | 显示剩余额度，多套餐时显示套餐数量 |
| ⑤ | 启用按钮 | ▶ | 切换为当前使用的供应商 |
| ⑥ | 编辑按钮 | ✏️ | 编辑供应商配置 |
| ⑦ | 复制按钮 | 📋 | 复制供应商（创建副本） |
| ⑧ | 检测连通 | 🧪 | 探测供应商地址是否可达，并显示延迟 |
| ⑨ | 用量查询 | 📊 | 配置用量查询脚本 |
| ⑩ | 打开终端 | ⌨️ | 选择工作目录后，用该供应商的配置打开一个终端（仅 Claude Code） |
| ⑪ | 删除按钮 | 🗑️ | 删除供应商（当前启用时禁用） |

> 💡 **提示**：操作按钮区域（⑤-⑪）在鼠标悬停时显示，平时隐藏以保持界面简洁。

部分供应商卡片会显示 **「需要路由」** 或 **「不支持路由」** 徽章：前者表示该供应商需要开启本地路由才能使用（例如接口格式需要转换），后者表示该供应商不能经本地路由转发（如 Claude Official）。

### 按钮详细说明

| 按钮 | 状态变化 | 说明 |
|------|----------|------|
| **启用** | 已启用时显示 ✓ 并禁用 | 故障转移模式下变为「加入/已加入」 |
| **编辑** | 始终可用 | 打开编辑面板修改配置 |
| **复制** | 始终可用 | 创建供应商副本，名称后缀 `copy` |
| **检测连通** | 检测中显示加载动画 | 只探测地址是否可达，不发送真实模型请求；官方供应商和 MiniMax Code 的供应商上为灰色不可用 |
| **用量查询** | 多数供应商可用 | 配置用量查询模板或脚本；Copilot、Codex OAuth、xAI OAuth 等配额自动显示的供应商上为灰色不可用 |
| **删除** | 当前启用时半透明禁用 | 需先切换到其他供应商才能删除 |

### 卡片状态

| 状态 | 边框颜色 | 说明 |
|------|----------|------|
| **当前启用** | 🔵 蓝色边框 | 普通模式下当前使用的供应商 |
| **路由活跃** | 🟢 绿色边框 | 开启本地路由时实际转发请求的供应商 |
| **普通状态** | 默认边框 | 未启用的供应商 |
| **故障转移中** | 显示优先级徽章 | 如 P1、P2 表示故障转移优先级 |

### 健康状态徽章

开启本地路由后，加入故障转移队列的供应商会显示健康状态：

| 徽章 | 颜色 | 说明 |
|------|------|------|
| 正常 | 🟢 绿色 | 连续失败 0 次 |
| 降级 | 🟡 黄色 | 有失败但未触发熔断 |
| 熔断 | 🔴 红色 | 已触发熔断，暂时跳过（阈值见 [4.3 故障转移](../4-proxy/4.3-failover.md#熔断器配置)） |


## 系统托盘

CC Switch 在系统托盘显示图标，提供快速操作入口。

### 托盘菜单结构

![image-20260108002153668](../../assets/image-20260108002153668.png)

### 菜单功能

| 菜单项 | 功能 |
|--------|------|
| 打开主界面 | 显示主窗口并聚焦 |
| 打开官方网站 | 在浏览器中打开 ccswitch.io |
| 项目 | 切换项目（整套供应商、MCP、Skills、提示词状态） |
| 应用子菜单 | 按 Claude / Codex / Gemini / Grok Build 分组的折叠子菜单（如 "Claude · PackyCode"），可显示当前供应商与缓存用量摘要 |
| 供应商列表 | 在每个子菜单内，点击切换，当前启用的显示勾选标记 |
| 轻量模式 | 勾选框切换，进入/退出仅托盘运行模式 |
| 退出 | 完全退出应用 |

> **注意**：每个托盘子菜单的标题会显示当前供应商名称（如 "Claude · PackyCode"）。没有配置供应商的应用会显示禁用的"(无供应商)"条目。托盘目前只包含 Claude Code、Codex、Gemini CLI、Grok Build 四个支持本地路由的应用；其他应用请在主界面切换；主界面显示哪些应用由设置中的「主页面显示」控制。

### 多语言支持

托盘菜单支持四种语言，根据设置自动切换：

| 语言 | 打开主界面 | 退出 |
|------|-----------|------|
| 简体中文 | 打开主界面 | 退出 |
| 繁體中文 | 開啟主介面 | 退出 |
| English | Open main window | Quit |
| 日本語 | メインウィンドウを開く | 終了 |

### 轻量模式

托盘菜单包含 **轻量模式** 切换开关（勾选框）。启用后：

- 主窗口关闭以释放资源
- 应用仅在系统托盘中运行
- 你仍可通过托盘子菜单切换供应商
- 在 macOS 上，Dock 图标也会隐藏

要退出轻量模式，取消勾选该选项或点击"打开主界面" — 主窗口将被重建并显示。

### 使用场景

托盘切换供应商无需打开主界面，适合：

- 频繁切换供应商
- 主窗口最小化时快速操作
- 后台运行时管理配置
- 使用轻量模式以最小化资源占用

## 设置页面

设置页面分为多个 Tab：

### 通用 Tab

- 语言设置（简体中文/繁體中文/English/日本語）
- 主题设置（跟随系统/浅色/深色）
- 主页面显示（应用与项目切换入口）
- Skills 存储位置与同步方式
- Codex 应用增强（保留官方登录、统一会话历史）
- 窗口行为（开机自启、关闭行为）
- 首选终端

### 路由 Tab

- 本地路由（路由总开关、按应用启用、监听地址与端口）
- 自动故障转移
- 整流器
- 全局出站代理

### 认证 Tab

- OAuth 认证中心（GitHub Copilot、ChatGPT、xAI 账号）

### 高级 Tab

- 配置文件目录
- 数据管理（导入导出）
- 备份与恢复
- 云同步
- 连通检测配置
- 应用诊断日志

### 使用统计 Tab

- 请求统计概览
- 趋势图表
- 请求日志
- 供应商/模型统计
- 成本定价

### 关于 Tab

- 版本信息与更新检查
- CLI 工具的版本检测、安装与升级

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd/Ctrl + ,` | 打开设置 |
| `Cmd/Ctrl + F` | 搜索供应商 |
| `Esc` | 关闭弹窗/搜索 |

## 搜索功能

按 `Cmd/Ctrl + F` 打开搜索框：

- 支持按名称、备注、URL 搜索
- 实时过滤供应商列表
- 按 `Esc` 关闭搜索
