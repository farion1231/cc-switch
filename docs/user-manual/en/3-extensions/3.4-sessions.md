# 3.4 Session Manager

The Session Manager lets you browse, search, and manage conversation sessions from all supported CLI tools in one place.

## Supported Applications

| Application | Session Storage Location |
|-------------|--------------------------|
| Claude Code | `~/.claude/projects/<project-dir>/*.jsonl` |
| Codex | `~/.codex/sessions/` and `~/.codex/archived_sessions/` |
| Gemini CLI | `~/.gemini/tmp/<project>/chats/` |
| Grok Build | `~/.grok/sessions/` and `~/.grok/archived_sessions/` |
| OpenCode | `~/.local/share/opencode/` (JSON or SQLite) |
| OpenClaw | `~/.openclaw/agents/<agent>/sessions/*.jsonl` |
| Hermes | `~/.hermes/state.db` or `~/.hermes/sessions/*.jsonl` |
| Pi | `~/.pi/agent/sessions/` |
| MiniMax Code | `~/.minimax/v2/sqlite/runtime-state.sqlite` |

If you override a configuration directory in Settings, the session directory changes accordingly (OpenCode's sessions live in the XDG data directory `~/.local/share/opencode` and are not affected by the configuration directory override). MiniMax Code's data directory can be set with the `MINIMAX_DATA_DIR` environment variable, and Pi additionally recognizes `PI_CODING_AGENT_DIR`.

## Opening the Session Manager

Click **Sessions** in the left sidebar. It is a global page: it opens showing the current app's sessions by default, and you can use the app dropdown at the top left of the page to switch to another app or to "All apps" (each item shows that app's session count).

> **Note**: Claude Desktop has no separate session records; entering from its page shows Claude Code's sessions. Hermes sessions are also chosen from the dropdown, and the page notes "Hermes shows only the latest 500 sessions".

## Interface Layout

The Session Manager has two levels:

- **Session list**: At the top are the app dropdown, the search box, and the "By time / By project" grouping switch, with the session list below
- **Session details**: Click any row to enter; the whole page shows this session's conversation, and "Back to sessions" returns to the list. You can also use "Previous / Next" to move between sessions

The ⋯ menu on the right of the page header contains: Refresh list, Select multiple…, Preferred terminal… (jumps to Settings), and Where sessions are stored… (lists each app's session storage location).

### Session List

Each session entry displays:
- App icon
- Session title
- Last active time and creation time
- A summary of the last message
- "Resume" and "Copy resume command" buttons on the right, and a ⋯ menu

### Session Details

Inside a session you can see:
- **Title and project directory**: The directory is clickable to copy the full path
- The **Resume** button and more ways to resume (such as copying the "enter directory and resume" command)
- **Conversation**: Shown in turns of question and reply; what the AI did (commands, file reads and writes, changes) is collected into one expandable "Steps" entry
- **View switch**: All / Chat / Changes, to see only the conversation or only file changes
- **Conversation outline**: Quickly jump to a particular question
- **Find**: Search within the current session
- **Copy / Export**: Copy the whole session as Markdown, or export it as a Markdown file

## Search & Filtering

### Full-Text Search

Use the search box at the top of the page to search across:
- Title
- Project directory
- First and last messages
- Session ID

The search filters results in real-time. Press **Esc** to clear the search.

### Filter by App

Click the app dropdown at the top left and choose:
- **All apps** — Show sessions from all apps (including Hermes)
- Claude Code, Codex, OpenCode, Hermes, Gemini CLI, Pi, Grok Build, OpenClaw, MiniMax Code

The session list can also switch between two groupings, "By time" (Today / Yesterday / This week / Earlier) and "By project", using the segmented control on the right.

The filter can be combined with search.

### Refresh

Click "Refresh list" in the page header's ⋯ menu to re-scan each app's directory for new or deleted sessions.

## Session Actions

### Resume Session

Click the **Resume** button on the session row (or in the session details) to continue the conversation.

**On macOS:**
- CC Switch launches your preferred terminal with the resume command
- The terminal opens in the session's project directory
- If terminal launch fails, the command is copied to your clipboard instead
- You can change the preferred terminal under "Preferred terminal…" in the page header's ⋯ menu

**Supported terminals (macOS):** Terminal.app, iTerm2, Ghostty, Otty, Kitty, WezTerm, Kaku, Alacritty, Warp

**On other platforms:**
- The resume command is copied to your clipboard
- Paste it into your terminal to resume

> The Resume button is disabled if the session has no resume command available. OpenClaw sessions are managed by the gateway and Hermes sessions don't support command-line resume yet, so neither can be resumed here. Codex stores history separately per provider, so after you switch providers, old sessions may not be able to continue.

When resuming, the terminal opens in the session's original project directory. To open a terminal with a particular Claude provider in a different directory, use the "Open Terminal" button on the Claude provider card, which asks you to choose a working directory first.

### Delete Session

Click "Delete" in the session row's ⋯ menu to permanently remove the session file. It is deleted directly from disk, skipping the Trash, and cannot be undone; a confirmation dialog explaining exactly what will be deleted is shown first.

> Sessions without a local source path cannot be deleted; delete MiniMax Code sessions in MiniMax Code.

### Batch Operations

For managing multiple sessions at once:

1. Click **Select multiple…** in the page header's ⋯ menu
2. Select sessions using the checkboxes that appear
3. Use **Select all matches** to select all filtered results, **Clear** to deselect, and **Done selecting** to leave batch mode
4. Click "Delete N sessions" to delete all selected sessions

A confirmation dialog shows the count before deletion. Results report the number of successful deletions and any failures.

## Conversation History

### Message Display

The conversation is shown in "question and reply" turns:
- Your questions and the AI's final replies are shown normally
- What the AI did (running commands, reading or modifying files, calling MCP, sub-agents, and so on) is collected into one "Steps · N" entry that you can expand to see each step's arguments, output, and file changes; failed steps are marked
- Thinking content is marked separately (some tools' thinking content is not visible)
- Longer content is collapsed by default and can be shown with "Expand full content"; for content over 2 MB, copy the source file path and view it locally

### Table of Contents

"Conversation outline" lists every question in the session (with step count and whether any failed or were interrupted); click any entry to jump to that position.

## Tips

- Sessions are sorted by last activity time (newest first)
- The session counts in the app dropdown update as you search
- OpenCode sessions may come from both JSON files and SQLite database — duplicates are automatically deduplicated
