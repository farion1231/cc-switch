# 2.4 Sort & Duplicate

## Drag to Reorder

Adjust the display order of providers by dragging.

### Steps

1. Move the mouse over the provider card; a **⋮⋮** drag handle appears at the far left of the card (hidden otherwise)
2. Hold the left mouse button
3. Drag up or down to the target position
4. Release the mouse to complete reordering; a "Sort order updated" notice appears

### Reorder Uses

- **Prioritize frequently used**: Place frequently used providers at the top of the list
- **Failover order**: The order in the queue is the providers' sort order. In "Queue · by priority" on the "Routing" tab, you can also use the move up / move down buttons on the cards, or drag them, to adjust who gets requests first; see [4.3 Failover](../4-proxy/4.3-failover.md)
- The provider order in the tray menu follows as well

## Duplicate Provider

Quickly create a copy of a provider, useful for:

- Creating variations based on existing configurations
- Backing up current configurations
- Creating test configurations

The universal provider list ("Manage existing universal providers" under the "Universal Provider" category on the add page) also has a duplicate action, so you can create a copy first and then adjust enabled apps and models.

### Steps

1. Click the **⋯** (More) button on the right side of the provider card
2. Choose "Duplicate"
3. A copy is automatically created with a `copy` name suffix
4. Click the edit button on the card to modify the copy's configuration

### Duplicated Content

Duplication creates a copy that carries over:

| Content | Duplicated |
|---------|------------|
| Name | Yes (with `copy` suffix) |
| Configuration | Fully duplicated |
| Notes | No; fill them in again in the copy if needed |
| Website Link | Yes |
| Icon | Yes |
| Endpoint List | Yes |
| Sort Position | Placed after the original provider |

### After Duplication

After duplication, you typically need to modify:

1. **Name**: Change to a meaningful name
2. **API Key**: If using a different account
3. **Endpoint**: If using a different service

## Delete Provider

### Steps

1. Click the **⋯** (More) button on the right side of the provider card
2. Choose "Delete" (in red, at the bottom of the menu)
3. Confirm deletion in the dialog

### Deletion Confirmation

A confirmation dialog appears before deletion, showing:

- Provider name
- The "This action cannot be undone" warning

### Deletion Restrictions

- **Provider in use**: Cannot be deleted; "Delete" is greyed out, with the note "The provider in use can't be deleted. Switch to another one first." For switch-style apps this covers the one used in Direct mode and the one being routed to in Routing or Aggregation mode; switch to another provider first, then delete
- **Universal provider**: Deleting will also remove linked app configurations
