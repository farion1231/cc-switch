# 1.2 Installation Guide

## Official Channels and System Requirements

Only download CC Switch from **[ccswitch.io](https://ccswitch.io)**, **[GitHub Releases](https://github.com/farion1231/cc-switch/releases)**, or the project source repository. Any "CC Switch" site or client that asks for payment, top-ups, or login credentials is not official.

| System | Minimum Version | Architecture |
|--------|-----------------|--------------|
| Windows | Windows 10 or later | x64 / ARM64 |
| macOS | macOS 12 (Monterey) or later | Intel (x64) / Apple Silicon (arm64) |
| Linux | glibc 2.35+ and WebKitGTK 4.1 (see the [Linux](#linux) section below) | x64 / ARM64 |

Installers are available from the [download page](https://ccswitch.io/download) on the official website or from [GitHub Releases](https://github.com/farion1231/cc-switch/releases); both offer the same files.

## Optional: Install the Tools to Manage

CC Switch itself does not need Node.js or any other runtime. It manages tools you have already installed, such as Claude Code and Codex. If a tool is not installed yet, you can install CC Switch first and then install the tool using either of the methods below.

### Method 1: One-Click Install in CC Switch (Recommended)

Open "Settings → About". The tool list shows the current and latest version of each tool. Tools that are not installed have an install button next to them; installed tools can be updated individually or with "Update All". Supported tools: Claude Code, Codex, Gemini CLI, Grok Build, OpenCode, OpenClaw, Hermes, and Pi. See [1.5 Personalization → About Page](./1.5-settings.md#about-page) for details.

### Method 2: Install Each Tool the Official Way

| Tool | Install Command (macOS / Linux) |
|------|---------------------------------|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` or `npm i -g @anthropic-ai/claude-code` |
| Codex | `npm i -g @openai/codex` or `brew install --cask codex` |
| Gemini CLI | `npm i -g @google/gemini-cli` |
| Grok Build | `curl -fsSL https://x.ai/cli/install.sh \| bash` or `npm i -g @xai-official/grok` |
| OpenCode | `curl -fsSL https://opencode.ai/install \| bash` or `npm i -g opencode-ai` |
| OpenClaw | `npm i -g openclaw` |
| Hermes | `curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh \| bash` |
| Pi | `npm i -g @earendil-works/pi-coding-agent` |

For Claude Desktop, MiniMax Code, and installation on Windows, refer to each tool's official documentation.

Installing with npm requires Node.js. Each tool requires a different version (for example, Claude Code needs 22 or later, and OpenClaw needs 24.x at 24.16 or later, or 26.1 or later). Installing the current LTS release is recommended; npm will tell you if your version is too old.

> 💡 **Tip**: If npm downloads are slow for you in mainland China, append `--registry=https://registry.npmmirror.com` to the command, or set the mirror globally:
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```
> The mirror occasionally lags behind. If you end up with a version older than the official one, temporarily switch back to the official registry `https://registry.npmjs.org`.

## Windows

### Installer

1. Download `CC-Switch-v{version}-Windows.msi` from the [download page](https://ccswitch.io/download) or the [Releases page](https://github.com/farion1231/cc-switch/releases) (for Windows on ARM, download `CC-Switch-v{version}-Windows-arm64.msi`)
2. Double-click to run the installer
3. Follow the prompts to complete installation

Note: If nothing happens when you run the installer, right-click the file, choose `Properties`, and on the `General` tab check `Unblock` under `Security`.

### Portable Version (No Installation Required)

1. Download `CC-Switch-v{version}-Windows-Portable.zip` (for ARM, `CC-Switch-v{version}-Windows-arm64-Portable.zip`)
2. Extract to any directory
3. Run `CC-Switch.exe`

## macOS

### Option 1: Homebrew (Recommended)

```bash
# Install
brew install --cask cc-switch
```

Update to the latest version:

```bash
brew upgrade --cask cc-switch
```

### Option 2: Manual Download

1. Download `CC-Switch-v{version}-macOS.dmg` (recommended) or `CC-Switch-v{version}-macOS.zip`. This is a Universal build that runs natively on both Apple Silicon and Intel Macs
2. Open the DMG, or extract the zip to get `CC Switch.app`
3. Drag it to the Applications folder

### Signed and Notarized

CC Switch for macOS is signed and notarized by Apple. You can install and open it directly — no extra steps needed.

## Linux

The Linux version of CC Switch requires **glibc 2.35+** and **WebKitGTK 4.1**, e.g. Ubuntu 22.04+, Debian 12+, and recent Fedora. RHEL / Rocky / Alma 8–9 ship system libraries that are too old and are not supported yet.

### ArchLinux

Install using an AUR helper:

```bash
# Using paru
paru -S cc-switch-bin

# Or using yay
yay -S cc-switch-bin
```

### Debian / Ubuntu

1. Download `CC-Switch-v{version}-Linux-x86_64.deb` or `CC-Switch-v{version}-Linux-arm64.deb` for your architecture
2. Install:

```bash
sudo dpkg -i CC-Switch-v{version}-Linux-*.deb

# If there are dependency issues
sudo apt-get install -f
```

### Fedora and Other RPM-Based Distributions

1. Download `CC-Switch-v{version}-Linux-x86_64.rpm` or `CC-Switch-v{version}-Linux-arm64.rpm` for your architecture
2. Install:

```bash
sudo dnf install ./CC-Switch-v{version}-Linux-*.rpm
```

### AppImage

For distributions that meet the system requirements above but have no matching package.

1. Download `CC-Switch-v{version}-Linux-x86_64.AppImage` or `CC-Switch-v{version}-Linux-arm64.AppImage` for your architecture
2. Add execute permission:

```bash
chmod +x CC-Switch-v{version}-Linux-*.AppImage
```

3. Run:

```bash
./CC-Switch-v{version}-Linux-*.AppImage
```

### Flatpak

Official releases do not include a Flatpak package. If you need one, you can build it yourself from the `.deb`; see [flatpak/README.md](https://github.com/farion1231/cc-switch/blob/main/flatpak/README.md) in the repository.

## Verify Installation

After installation, launch CC Switch:

1. The app window displays correctly
2. A CC Switch icon appears in the system tray
3. The app switcher shows enabled managed apps, and you can switch to the target app panel

## Auto Update

CC Switch includes built-in auto-update functionality:

- Automatically checks for updates on startup
- Displays an update prompt in the UI when a new version is available
- Click to download and install

You can also manually check for updates in "Settings → About".

## Uninstall

### Windows

- Uninstall via "Settings → Apps"
- Or run the uninstaller in the installation directory

### macOS

- If installed via Homebrew: `brew uninstall --cask cc-switch` (add `--zap` to also delete configuration data)
- If installed manually: move `CC Switch.app` to Trash
- Optional: Delete the configuration directory `~/.cc-switch/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-switch

# Fedora and other RPM-based distributions
sudo dnf remove cc-switch

# ArchLinux
paru -R cc-switch-bin
```
