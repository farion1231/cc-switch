# 2.4 並べ替えと複製

## ドラッグで並べ替え

ドラッグでプロバイダーの表示順序を調整します。

### 操作手順

1. マウスをプロバイダーカードの上に移動すると、カードの左端に **⋮⋮** ドラッグハンドルが表示される（普段は非表示）
2. マウスの左ボタンを押し続ける
3. 目的の位置まで上下にドラッグ
4. マウスを離して並べ替え完了。「並び順を更新しました」と通知される

### 並べ替えの用途

- **よく使うものを優先**：よく使うプロバイダーをリストの上部に配置
- **フェイルオーバーの順序**：キュー内の順序がそのままプロバイダーの並び順です。「ルーティング」タブの「キュー · 優先順」では、カード上の上へ・下へボタンや直接のドラッグでも、どれから先に送るかを調整できます。詳しくは [4.3 フェイルオーバー](../4-proxy/4.3-failover.md) を参照してください
- トレイメニューのプロバイダーの順序も連動して変わる

## プロバイダーの複製

プロバイダーのコピーを素早く作成します。以下のような場面に適しています：

- 既存の設定をベースにバリエーションを作成
- 現在の設定をバックアップ
- テスト用の設定を作成

統一プロバイダー一覧（追加ページの「統合プロバイダー」カテゴリにある「既存の統合プロバイダーを管理」）にも複製ボタンがあります。既存の統一プロバイダーをコピーしてから、有効化するアプリやモデルを調整できます。

### 操作手順

1. プロバイダーカード右側の **⋯**（その他）ボタンをクリック
2. 「複製」を選択
3. 名前に `copy` が付加されたコピーが自動作成
4. カードの編集ボタンをクリックして、コピーの設定を変更

### コピーされる内容

コピーでは次のものを引き継いだ複製が作成されます：

| 内容 | コピーされるか |
|------|----------|
| 名前 | コピーされる（`copy` が付加） |
| 設定 | 完全にコピー |
| メモ | コピーされない。必要ならコピー側で入力し直す |
| Web サイトリンク | コピーされる |
| アイコン | コピーされる |
| エンドポイントリスト | コピーされる |
| 並び順の位置 | 元のプロバイダーの直後に並ぶ |

### コピー後の編集

コピー完了後、通常は以下を変更します：

1. **名前**：意味のある名前に変更
2. **API Key**：異なるアカウントの場合
3. **エンドポイント**：異なるサービスの場合

## プロバイダーの削除

### 操作手順

1. プロバイダーカード右側の **⋯**（その他）ボタンをクリック
2. 「削除」を選択（赤色、メニューの一番下）
3. 確認ダイアログで削除を確認

### 削除の確認

削除前に確認ダイアログが表示され、以下が表示されます：

- プロバイダー名
- 「この操作は元に戻せません」という注意

### 削除の制限

- **使用中のプロバイダー**：削除できません。「削除」はグレー表示で、「使用中のプロバイダーは削除できません。先にほかへ切り替えてください。」と説明が表示されます。切り替え式のアプリでは、直接接続で使っているもののほか、ルーティングまたは集約モードで転送先になっているものも該当します。先に別のプロバイダーへ切り替えてから削除してください
- **統一プロバイダー**：削除すると、関連するアプリの設定も削除されます
