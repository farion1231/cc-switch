## 上部ナビゲーションバー

| 番号 | 要素 | 機能説明 |
|------|------|----------|
| ① | Logo | クリックで公式サイト ccswitch.io にアクセス |
| ② | 設定ボタン | 設定ページを開く（ショートカット `Cmd/Ctrl + ,`） |
| ③ | ローカルルーティングスイッチ | Claude Code / Codex / Gemini CLI / Grok Build のページ：現在のアプリのローカルルーティングをオン/オフ（「設定 → ルーティング → ローカルルーティング」で「メインページにルーティング切り替えを表示」をオンにする必要があります）。Claude Desktop のページ：常に表示され、Claude Desktop が使用するローカルルーティングを起動/停止 |
| ④ | アプリ切り替え | 10 個の管理対象アプリを切り替え |
| ⑤ | 機能エリア | 現在のアプリで利用できる機能入口 |
| ⑥ | 追加ボタン | 新しいプロバイダーを追加 |

このほか、条件に応じて表示される入口がいくつかあります：

- **プロジェクト切り替え**：デフォルトで表示されます（MiniMax Code のページを除く）。「設定 → 一般 → ホームページ表示」で「プロジェクト切り替えを表示」をオフにできます
- **フェイルオーバースイッチ**：「設定 → ルーティング → 自動フェイルオーバー」で「メインページにフェイルオーバー切り替えを表示」をオンにすると表示されます
- **利用統計ボタン**：現在のアプリでローカルルーティングが有効なときに表示されます

### アプリ切り替え

上部のアプリアイコンをクリックして、現在管理するアプリを切り替えます（ウィンドウが狭い場合、収まりきらないアプリは「その他のアプリ」メニューにまとめられます）：

- **Claude** - Claude Code の設定を管理
- **Claude Desktop** - Claude Desktop のサードパーティプロバイダーと公式モードを管理
- **Codex** - Codex の設定を管理
- **Gemini** - Gemini CLI の設定を管理
- **OpenCode** - OpenCode の設定を管理
- **OpenClaw** - OpenClaw の設定を管理
- **Hermes** - Hermes Agent のプロバイダーと Memory を管理
- **Grok Build** - Grok Build の設定を管理
- **Pi** - Pi のプロバイダーとモデルを管理
- **MiniMax Code** - MiniMax Code のカスタムプロバイダーを管理

切り替え後、プロバイダーリストに対応アプリの設定が表示されます。あまり使わないアプリは「設定 → 一般 → ホームページ表示」で非表示にできます。

### 機能エリアボタン

表示される機能ボタンはアプリによって異なります：

| アプリ | 機能エリアのボタン |
|------|------------|
| Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、MiniMax Code | Skills、Prompts、セッション、MCP |
| Pi | Skills、Prompts、セッション（Pi には MCP がありません） |
| Claude Desktop | Claude Code と同じ。操作対象は Claude Code のデータです |
| Hermes | Skills、メモリ、Hermes Web UI、MCP |
| OpenClaw | ワークスペース、環境変数、ツール、Agents、セッション |

各アプリの MCP、Skills、Prompts の対応範囲は [3.1 MCP](../3-extensions/3.1-mcp.md)、[3.2 Prompts](../3-extensions/3.2-prompts.md)、[3.3 Skills](../3-extensions/3.3-skills.md) を参照してください。

## プロバイダーカード

各プロバイダーはカード形式で表示されます。左から右へ以下の要素が含まれています：

### カード要素（左から右）

| 番号 | 要素 | アイコン | 機能説明 |
|------|------|------|----------|
| ① | ドラッグハンドル | ≡ | 長押しして上下にドラッグしてプロバイダーの順序を調整 |
| ② | プロバイダーアイコン | 🔷 | プロバイダーのブランドアイコンを表示、カラーのカスタマイズ可能 |
| ③ | プロバイダー情報 | - | 名前、メモ/エンドポイントアドレス（クリックで公式サイトを開く） |
| ④ | 使用量情報 | - | 残額を表示、複数プランの場合はプラン数を表示 |
| ⑤ | 有効化ボタン | ▶ | 現在使用中のプロバイダーに切り替え |
| ⑥ | 編集ボタン | ✏️ | プロバイダー設定を編集 |
| ⑦ | 複製ボタン | 📋 | プロバイダーを複製（コピーを作成） |
| ⑧ | 接続チェック | 🧪 | プロバイダーのアドレスに到達できるかを確認し、レイテンシを表示 |
| ⑨ | 使用量クエリ | 📊 | 使用量クエリスクリプトを設定 |
| ⑩ | ターミナルを開く | ⌨️ | 作業ディレクトリを選択し、そのプロバイダーの設定でターミナルを開く（Claude Code のみ） |
| ⑪ | 削除ボタン | 🗑️ | プロバイダーを削除（現在有効な場合は無効） |

> 💡 **ヒント**：操作ボタンエリア（⑤-⑪）はマウスホバー時に表示され、通常は非表示で画面をすっきり保ちます。

一部のプロバイダーカードには **「ルーティングが必要」** または **「ルーティング非対応」** バッジが表示されます。前者は、そのプロバイダーを使うにはローカルルーティングを有効にする必要があること（例：API フォーマットの変換が必要な場合）を、後者は、そのプロバイダーをローカルルーティング経由で転送できないこと（例：Claude Official）を示します。

### ボタンの詳細説明

| ボタン | 状態変化 | 説明 |
|------|----------|------|
| **有効化** | 有効化済みの場合は ✓ を表示して無効化 | フェイルオーバーモードでは「追加/キュー内」に変化 |
| **編集** | 常に使用可能 | 編集パネルを開いて設定を変更 |
| **複製** | 常に使用可能 | プロバイダーのコピーを作成、名前に `copy` が付加 |
| **接続チェック** | チェック中はローディングアニメーション | アドレスに到達できるかだけを確認し、実際のモデルリクエストは送信しません。公式プロバイダーと MiniMax Code のプロバイダーではグレーアウトして使用できません |
| **使用量クエリ** | ほとんどのプロバイダーで使用可能 | 使用量クエリのテンプレートまたはスクリプトを設定。Copilot、Codex OAuth、xAI OAuth などクォータが自動表示されるプロバイダーではグレーアウトして使用できません |
| **削除** | 現在有効な場合は半透明で無効 | 先に他のプロバイダーに切り替える必要あり |

### カードの状態

| 状態 | 枠の色 | 説明 |
|------|----------|------|
| **現在有効** | 🔵 青い枠 | 通常モードで現在使用中のプロバイダー |
| **ルーティングアクティブ** | 🟢 緑の枠 | ローカルルーティング有効時に実際にリクエストを転送しているプロバイダー |
| **通常状態** | デフォルトの枠 | 有効化されていないプロバイダー |
| **フェイルオーバー中** | 優先度バッジを表示 | P1、P2 などのフェイルオーバー優先度を表示 |

### ヘルスステータスバッジ

ローカルルーティングを有効にすると、フェイルオーバーキューに参加しているプロバイダーにヘルスステータスが表示されます：

| バッジ | 色 | 説明 |
|------|------|------|
| 正常 | 🟢 緑 | 連続失敗回数 0 |
| 低下 | 🟡 黄 | 失敗はあるが、サーキットブレーカーは発動していない |
| サーキットオープン | 🔴 赤 | サーキットブレーカーが発動し、一時的にスキップ中（しきい値は [4.3 フェイルオーバー](../4-proxy/4.3-failover.md#サーキットブレーカーの設定) を参照） |


## システムトレイ

CC Switch はシステムトレイにアイコンを表示し、クイック操作の入口を提供します。

### トレイメニュー構造

![image-20260108002153668](../../assets/image-20260108002153668.png)

### メニュー機能

| メニュー項目 | 機能 |
|--------|------|
| メインウィンドウを開く | メインウィンドウを表示してフォーカス |
| 公式サイトを開く | ブラウザで ccswitch.io を開く |
| プロジェクト | プロジェクト（プロバイダー、MCP、Skills、プロンプトの状態一式）を切り替え |
| アプリサブメニュー | Claude / Codex / Gemini / Grok Build ごとの折りたたみサブメニュー（例：「Claude · PackyCode」）。現在のプロバイダーとキャッシュ済み使用量サマリーを表示可能 |
| プロバイダーリスト | 各サブメニュー内でクリックして切り替え、現在有効なものにはチェックマークを表示 |
| 軽量モード | チェックボックスで切り替え、トレイ専用モードの開始/終了 |
| 終了 | アプリを完全に終了 |

> **注意**：各トレイサブメニューのタイトルには現在のプロバイダー名が表示されます（例：「Claude · PackyCode」）。プロバイダーが設定されていないアプリでは、無効化された「(プロバイダーなし)」エントリが表示されます。トレイに含まれるのは現在、ローカルルーティングに対応する Claude Code、Codex、Gemini CLI、Grok Build の 4 つのアプリだけです。その他のアプリはメイン画面で切り替えてください。メイン画面にどのアプリを表示するかは、設定の「ホームページ表示」で制御します。

### 多言語対応

トレイメニューは 4 つの言語に対応し、設定に応じて自動的に切り替わります：

| 言語 | メインウィンドウを開く | 終了 |
|------|-----------|------|
| 簡体中文 | 打开主界面 | 退出 |
| 繁體中文 | 開啟主介面 | 退出 |
| English | Open main window | Quit |
| 日本語 | メインウィンドウを開く | 終了 |

### 軽量モード

トレイメニューには **軽量モード** のトグル（チェックボックス）があります。有効にすると：

- メインウィンドウが閉じられ、リソースが解放される
- アプリはシステムトレイのみで動作を継続
- トレイのサブメニューからプロバイダーの切り替えが可能
- macOS では Dock アイコンも非表示になる

軽量モードを終了するには、トグルのチェックを外すか「メインウィンドウを開く」をクリックします。メインウィンドウが再構築されて表示されます。

### 使用シーン

トレイからのプロバイダー切り替えはメイン画面を開く必要がなく、以下の場面に適しています：

- 頻繁にプロバイダーを切り替える場合
- メインウィンドウが最小化されているときの素早い操作
- バックグラウンド実行中の設定管理
- 軽量モードでリソース使用量を最小化

## 設定ページ

設定ページは複数のタブに分かれています：

### 一般タブ

- 言語設定（簡体中文/繁體中文/English/日本語）
- テーマ設定（システムに合わせる/ライト/ダーク）
- ホームページ表示（アプリとプロジェクト切り替えの入口）
- スキル保存場所と同期方法
- Codex アプリ拡張（公式ログインの保持、セッション履歴の統一）
- ウィンドウ動作（起動時に自動実行、閉じる動作）
- 優先ターミナル

### ルーティングタブ

- ローカルルーティング（ルーティング総スイッチ、アプリごとの有効化、リッスンアドレスとポート）
- 自動フェイルオーバー
- 整流器
- グローバル送信プロキシ

### 認証タブ

- OAuth 認証センター（GitHub Copilot、ChatGPT、xAI アカウント）

### 詳細タブ

- 設定ディレクトリ
- データ管理（インポート/エクスポート）
- バックアップと復元
- クラウド同期
- 接続チェック設定
- アプリ診断ログ

### 利用統計タブ

- リクエスト統計の概要
- トレンドグラフ
- リクエストログ
- プロバイダー/モデル統計
- コスト計算

### バージョン情報タブ

- バージョン情報と更新の確認
- CLI ツールのバージョン検出、インストール、更新

## ショートカットキー

| ショートカット | 機能 |
|--------|------|
| `Cmd/Ctrl + ,` | 設定を開く |
| `Cmd/Ctrl + F` | プロバイダーを検索 |
| `Esc` | ダイアログ/検索を閉じる |

## 検索機能

`Cmd/Ctrl + F` で検索ボックスを開きます：

- 名前、メモ、URL で検索可能
- プロバイダーリストをリアルタイムでフィルタリング
- `Esc` で検索を閉じる
