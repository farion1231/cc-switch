# 1.3 インターフェース概要

## メイン画面のレイアウト

![CC Switch メイン画面](../../../../assets/release-notes/v4.0.0/main-en.png)

メインウィンドウは左のサイドバーと右のコンテンツエリアに分かれています：

- **左サイドバー**：管理するアプリを選ぶ、またはグローバル機能ページを開く
- **コンテンツエリア**：上部はページヘッダー（アプリ名、「プロバイダーを追加」ボタン、⋯ メニュー）、その下に現在のページの内容

## 左サイドバー

左サイドバーは上から順に 3 つのブロックに分かれています：

| 領域 | 内容 |
|------|------|
| アプリリスト | 表示することにした管理対象アプリ（最大 10 個）。アプリをクリックすると、右側にそのプロバイダーページが表示されます。アプリ名の横の小さなマークは、現在ルーティング・集約・モデルマッピングのどれを使っているかを示し、問題があると「対応が必要」と表示されます |
| グローバルページ | MCP、Skills、プロンプト、セッション、アカウント、使用量（今日の費用があるときは横に「今日 $xx」と表示）。これらのページは特定のアプリに属さず、入口はそれぞれ 1 つだけです |
| 下部 | 「アプリ」（インストール、アップグレード、サイドバーに表示するアプリの選択）と「設定」 |

サイドバー上部の折りたたみボタンをクリックするとアイコンだけに縮み、もう一度クリックすると展開します。「アプリ」や「設定」の横に点が出ているときは、コマンドラインツールまたは CC Switch 本体に新しいバージョンがあります。

> ショートカット `Cmd/Ctrl + ,` でいつでも設定を開けます。

### 管理対象アプリ

- **Claude Code** - Claude Code の設定を管理
- **Claude Desktop** - Claude Desktop のサードパーティプロバイダーと公式モードを管理
- **Codex** - Codex の設定を管理
- **Gemini** - Gemini CLI の設定を管理
- **Grok Build** - Grok Build の設定を管理
- **OpenCode** - OpenCode の設定を管理
- **OpenClaw** - OpenClaw の設定を管理
- **Hermes** - Hermes Agent のプロバイダーと Memory を管理
- **Pi** - Pi のプロバイダーとモデルを管理
- **MiniMax Code** - MiniMax Code のカスタムプロバイダーを管理

あまり使わないアプリは、サイドバーの「アプリ」ページで表示をオフにできます。オフにするとサイドバーに表示されなくなり、MCP / Skills のアプリ列や、プロンプト・セッションのアプリ選択にも出なくなりますが、既存の設定には影響しません。

### グローバルページ

| 入口 | 用途 |
|------|------|
| MCP | MCP サーバーを管理し、アプリごとに有効化します。[3.1 MCP](../3-extensions/3.1-mcp.md) を参照 |
| Skills | スキルのインストールと管理。[3.3 Skills](../3-extensions/3.3-skills.md) を参照 |
| プロンプト | システムプロンプトの管理。[3.2 Prompts](../3-extensions/3.2-prompts.md) を参照 |
| セッション | 各ツールのセッション履歴を閲覧・検索 |
| アカウント | ChatGPT（Codex）、GitHub Copilot、xAI などの OAuth アカウントを一元管理 |
| 使用量 | リクエスト統計の概要、トレンドグラフ、リクエストログ、プロバイダー/モデル統計、コストの料金設定 |

すべてのアプリがすべての機能に対応しているわけではありません。Claude Desktop と OpenClaw は MCP、Skills の対象外です。Claude Desktop のページでの MCP、Skills、プロンプト、セッションの操作は、Claude Code のデータが対象です。

## アプリページ

### アプリページのヘッダー

ヘッダーにはアプリ名とページ名（例：「Claude Code プロバイダー」）が表示され、右側には次のものがあります：

- **プロバイダーを追加**：新しいプロバイダーを追加
- **プロジェクト切り替え**：デフォルトでは非表示です。「設定 → 一般 → サイドバーとヘッダー」で「プロジェクト切り替えを表示」をオンにすると表示されます（MiniMax Code のページにはありません）
- **⋯ メニュー**：セッションを見る、設定ディレクトリ、インストールとアップグレード、サイドバーから隠す、このアプリの使用量を見る
- Hermes のヘッダーには「Web UI」ボタンもあります

OpenClaw と Hermes では、ヘッダーの下にタブが並び、プロバイダーページと専用ページを切り替えられます：

| アプリ | タブ |
|------|------|
| OpenClaw | プロバイダー、ワークスペース、設定 |
| Hermes | プロバイダー、メモリ |

### 接続モード

Claude Code、Codex、Gemini CLI、Grok Build のプロバイダーページ上部には **直接接続 / ルーティング / 集約** の 3 つのタブがあります（集約は Claude Code と Codex のみ。Claude Desktop は直接接続 / モデルマッピング）。タブ上の点は現在有効なモードを示し、横の文字は今どのプロバイダーに接続しているかを示します。

タブをクリックしても、そのモードでのリストを見るだけで設定は変わりません。実際に切り替えるには、下に表示される結果が明記されたボタン「ルーティングを開始」「集約に切り替え」「直接接続に戻す」を押します。ルーティングは [4.2 アプリケーションルーティング](../4-proxy/4.2-routing.md)、集約は [4.6 集約モード](../4-proxy/4.6-aggregation.md) を参照してください。

### プロバイダーカード

各プロバイダーは 1 枚のカードで、左から順に次の要素があります：

| 要素 | 機能説明 |
|------|----------|
| ドラッグハンドル | ドラッグしてプロバイダーの順序を調整（ホバー時に表示） |
| プロバイダーアイコン | ブランドアイコン |
| プロバイダー情報 | 名前、メモ/エンドポイントアドレス（クリックで公式サイトを開く）。名前の横に「公式」「ルーティングが必要」などのバッジが付くことがあります |
| 使用量情報 | 残りクォータまたは残額。複数プランの場合は複数行で表示 |
| 状態 / 主な操作 | 現在有効なカードには「使用中」（ルーティングモードでは「転送中」）と表示されます。それ以外のカードは再生ボタンで、直接接続では切り替え、ルーティングでは「ここへ転送」、集約ではデフォルトに設定または追加に使います |
| 編集ボタン | プロバイダー設定を編集 |
| ⋯ その他 | 複製、接続チェック、使用量クエリの設定、ターミナルを開く（Claude Code のみ）、削除 |

使用中のプロバイダーは削除できないため、先に他のプロバイダーへ切り替えてください。「接続チェック」はアドレスに到達できるかだけを確認し、実際のモデルリクエストは送信しません。公式プロバイダーと MiniMax Code のプロバイダーでは使用できません。Copilot、Codex OAuth、xAI OAuth などクォータが自動表示されるプロバイダーには「利用状況を設定」がありません。

**「ルーティングが必要」** バッジは、そのプロバイダーがローカルルーティング経由でしか使えない（例：API フォーマットの変換が必要）ことを示します。直接接続のまま切り替えても、クライアントはそのプロバイダーを使えません。**公式サブスクリプションはルーティングを経由せず**（Codex の OpenAI Official は例外）、ルーティングモードでは切り替えられません。

OpenCode、OpenClaw、Hermes、Pi、MiniMax Code は「共存」型アプリで、カードのボタンは「追加 / 削除」（Pi は「有効化 / 削除」）です。直接接続 / ルーティング / 集約のタブはありません。

### フェイルオーバーキューとヘルスステータス

ルーティングモードでは、プロバイダーページが「キュー · 優先順」と「キュー外」の 2 つに分かれます。キュー内のプロバイダーは順番にリクエストを受け、前のものが連続して失敗すると自動的に次へ切り替わります。上へ移動、下へ移動、またはドラッグで順序を調整できます。設定方法は [4.3 フェイルオーバー](../4-proxy/4.3-failover.md) を参照してください。

キュー内のプロバイダーにはヘルスステータスが表示されます：

| ステータス | 説明 |
|------|------|
| 正常 | 連続失敗回数 0 |
| 低下 | 失敗はあるが、サーキットブレーカーは発動していない |
| サーキットオープン | サーキットブレーカーが発動し、一時的にスキップ中（しきい値は [4.3 フェイルオーバー](../4-proxy/4.3-failover.md#サーキットブレーカーの設定) を参照） |

### アプリ管理ページ

サイドバー下部の「アプリ」ページでは、コマンドラインツールを管理します：

- 各ツールの現在のバージョンと最新バージョンを確認し、未インストールのものをインストール、インストール済みのものをアップグレード
- サイドバーに表示するアプリを選択
- 「手動インストールコマンド」で各ツールのインストールコマンドをコピー

Claude Desktop はデスクトップアプリのため、ここではインストールやアップグレードはできず、ページには接続済みかどうかだけが表示されます。起動時に新しいバージョンを確認するかどうかは、「設定 → 一般 → 各アプリの新しいバージョン」で制御します。

## システムトレイ

CC Switch はシステムトレイにアイコンを表示し、クイック操作の入口を提供します。

### トレイメニュー

| メニュー項目 | 機能 |
|--------|------|
| CC Switch を開く | メインウィンドウを表示してフォーカスし、常に最前面に出す |
| アプリサブメニュー | Claude Code、Claude Desktop、Codex、Gemini CLI、Grok Build の 5 つの切り替え型アプリにそれぞれサブメニューがあり、タイトルに現在のプロバイダーとモードを表示します。サブメニュー内でプロバイダーをクリックすると切り替わり、現在のものにはチェックマークが付きます。アプリのページを開く、プロバイダーを追加することもでき、アプリによってはクォータの概要も表示されます |
| プロジェクト | プロジェクト（プロバイダー、MCP、Skills、プロンプトの状態一式）を切り替え。「プロジェクト切り替えを表示」をオンにしたときのみ表示 |
| 軽量モード | チェックボックスで切り替え、トレイ専用モードの開始/終了 |
| 公式サイトを開く | ブラウザで ccswitch.io を開く |
| CC Switch を終了 | アプリを完全に終了。ルーティングまたは集約を使っているアプリがあるときは、メニュー項目に「ルーティングサービスが停止します」と表示されます |

ルーティングサービスが起動していない、あるアプリの切り替えに失敗したなどの問題はメニューの一番上に表示され、トレイアイコンにも小さな点が付きます。

> **注意**：共存型（累加式）アプリ（OpenCode、OpenClaw、Hermes、Pi、MiniMax Code）はトレイに含まれないため、メイン画面で操作してください。プロバイダーが設定されていないアプリは、サブメニューに該当する案内が表示されます。トレイにどのアプリを表示するかは、「アプリ」ページの表示スイッチで決まります。

### 多言語対応

トレイメニューはインターフェース言語に従い、簡体中文、繁體中文、English、日本語に対応しています。言語を設定していない場合はシステム言語が使われます。

### 軽量モード

トレイメニューには **軽量モード** のチェックボックスがあります。有効にすると：

- メインウィンドウが閉じられ、リソースが解放される
- アプリはシステムトレイのみで動作を継続
- トレイのサブメニューからプロバイダーの切り替えが可能
- macOS では Dock アイコンも非表示になる

軽量モードを終了するには、チェックを外すか「CC Switch を開く」をクリックします。メインウィンドウが再構築されて表示されます。

### 使用シーン

トレイからのプロバイダー切り替えはメイン画面を開く必要がなく、以下の場面に適しています：

- 頻繁にプロバイダーを切り替える場合
- メインウィンドウが最小化されているときの素早い操作
- バックグラウンド実行中の設定管理
- 軽量モードでリソース使用量を最小化

## 設定

サイドバー下部の「設定」をクリックすると、サイドバーが設定の目次に切り替わり、右側に現在のグループが表示されます。「戻る」をクリックするか `Esc` を押すとメイン画面に戻ります。設定は 6 つのグループに分かれています：

### 一般

- **外観**：表示言語（簡体中文/繁體中文/English/日本語）、ライト/ダークテーマ（システムに合わせる/ライト/ダーク）
- **サイドバーとヘッダー**：サイドバーに表示するアプリ（「アプリ」ページへ移動）、プロジェクト切り替えを表示
- **各アプリの新しいバージョン**：起動時に各アプリの新しいバージョンを確認
- **ウィンドウとターミナル**：起動時に自動実行、閉じるボタンの動作（トレイへ隠す/終了）、優先ターミナル

### アプリ設定

- 各アプリの設定ディレクトリの上書き（Claude Desktop と MiniMax Code を除く）
- 各アプリ固有のオプション。例：Claude Code の「Claude Code 拡張に適用」「Claude Code の初回確認をスキップ」、Codex の直接切替時に公式ログインを保持

### ローカルルーティング

- サービス：待ち受けアドレスとポート、起動/停止
- ルーティングを使用中のアプリ
- 自動フェイルオーバー
- 整流器
- すべて直接接続に戻す

### ネットワーク

- グローバル送信プロキシ

### データ

- 保存場所（CC Switch 設定ディレクトリ）
- データ管理（SQL のインポート/エクスポート）
- バックアップと復元（「その他のバックアップ」の一覧を含む）
- クラウド同期
- アプリ診断ログ

### 情報

- バージョン情報、更新の確認
- GitHub、公式サイト、リリースノート

## ショートカットキー

| ショートカット | 機能 |
|--------|------|
| `Cmd/Ctrl + ,` | 設定を開く |
| `Cmd/Ctrl + F` | プロバイダーを検索（プロバイダーページで） |
| `Esc` | 検索を閉じる。設定ページではメイン画面に戻る |

## 検索機能

プロバイダーページで `Cmd/Ctrl + F` を押すと検索ボックスが開きます：

- 名前、メモ、URL で検索可能
- プロバイダーリストをリアルタイムでフィルタリング
- `Esc` で検索を閉じる
