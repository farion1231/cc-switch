# 1.2 インストールガイド

## 公式チャネルとシステム要件

CC Switch は **[ccswitch.io](https://ccswitch.io)**、**[GitHub Releases](https://github.com/farion1231/cc-switch/releases)**、またはプロジェクトのソースリポジトリからのみ入手してください。支払い、チャージ、ログイン情報の入力を求める「CC Switch」サイトやクライアントは公式ではありません。

| システム | 最低バージョン | アーキテクチャ |
|------|----------------|----------------|
| Windows | Windows 10 以上 | x64 / ARM64 |
| macOS | macOS 12 (Monterey) 以上 | Intel (x64) / Apple Silicon (arm64) |
| Linux | glibc 2.35+ と WebKitGTK 4.1（下記の [Linux](#linux) セクションを参照） | x64 / ARM64 |

インストールパッケージは公式サイトの [ダウンロードページ](https://ccswitch.io/download) または [GitHub Releases](https://github.com/farion1231/cc-switch/releases) から入手できます。どちらも同じファイルです。

## 任意：管理するツールのインストール

CC Switch 自体には Node.js などのランタイムは不要です。CC Switch が管理するのは、すでにインストール済みの Claude Code や Codex などのツールです。まだインストールしていないツールは、先に CC Switch をインストールしてから、次のいずれかの方法でインストールできます。

### 方法 1：CC Switch からワンクリックでインストール（推奨）

「設定 → バージョン情報」を開くと、ツール一覧に各ツールの現在のバージョンと最新バージョンが表示されます。未インストールのツールにはインストールボタンがあり、インストール済みのツールは個別に更新するか「すべて更新」で一括更新できます。対応ツールは Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes、Pi です。詳細は [1.5 個人設定 → バージョン情報ページ](./1.5-settings.md#バージョン情報ページ) を参照してください。

### 方法 2：各ツールの公式手順でインストール

| ツール | インストールコマンド（macOS / Linux） |
|------|---------------------------|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` または `npm i -g @anthropic-ai/claude-code` |
| Codex | `npm i -g @openai/codex` または `brew install --cask codex` |
| Gemini CLI | `npm i -g @google/gemini-cli` |
| Grok Build | `curl -fsSL https://x.ai/cli/install.sh \| bash` または `npm i -g @xai-official/grok` |
| OpenCode | `curl -fsSL https://opencode.ai/install \| bash` または `npm i -g opencode-ai` |
| OpenClaw | `npm i -g openclaw` |
| Hermes | `curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh \| bash` |
| Pi | `npm i -g @earendil-works/pi-coding-agent` |

Claude Desktop、MiniMax Code、および Windows でのインストール方法は、各ツールの公式ドキュメントを参照してください。

npm でインストールするには、先に Node.js が必要です。必要なバージョンはツールによって異なります（例：Claude Code は 22 以上、OpenClaw は 24.16 以上の 24.x または 26.1 以上）。現行の LTS 版をインストールすることをおすすめします。バージョンが足りない場合は npm が知らせてくれます。

> 💡 **ヒント**：中国国内で npm のダウンロードが遅い場合は、コマンドの末尾に `--registry=https://registry.npmmirror.com` を付けるか、ミラーをグローバルに設定してください：
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```
> ミラーの同期が遅れることがあります。公式より古いバージョンがインストールされた場合は、一時的に公式レジストリ `https://registry.npmjs.org` に戻してください。

## Windows

### インストーラー方式

1. [ダウンロードページ](https://ccswitch.io/download) または [Releases ページ](https://github.com/farion1231/cc-switch/releases) から `CC-Switch-v{バージョン}-Windows.msi` をダウンロード（ARM 版 Windows では `CC-Switch-v{バージョン}-Windows-arm64.msi`）
2. インストーラーをダブルクリックして実行
3. 指示に従ってインストール

注意：インストーラーを実行しても何も起こらない場合は、ファイルを右クリックしてメニューから `プロパティ` を開き、`全般` タブの `セキュリティ` で `許可する` にチェックを入れてください

### ポータブル版（インストール不要）

1. `CC-Switch-v{バージョン}-Windows-Portable.zip` をダウンロード（ARM 版は `CC-Switch-v{バージョン}-Windows-arm64-Portable.zip`）
2. 任意のディレクトリに展開
3. `CC-Switch.exe` を実行

## macOS

### 方法 1：Homebrew（推奨）

```bash
# インストール
brew install --cask cc-switch
```

最新バージョンに更新：

```bash
brew upgrade --cask cc-switch
```

### 方法 2：手動ダウンロード

1. `CC-Switch-v{バージョン}-macOS.dmg`（推奨）または `CC-Switch-v{バージョン}-macOS.zip` をダウンロード。Universal パッケージなので、Apple Silicon と Intel Mac のどちらでもネイティブに動作します
2. DMG を開く、または zip を展開して `CC Switch.app` を取得
3. 「アプリケーション」フォルダにドラッグ

### 署名・公証済み

CC Switch の macOS 版は Apple のコード署名と公証を受けています。追加の操作なしで直接インストールして開くことができます。

## Linux

CC Switch の Linux 版には **glibc 2.35+** と **WebKitGTK 4.1** が必要です（例：Ubuntu 22.04+、Debian 12+、比較的新しい Fedora）。RHEL / Rocky / Alma 8–9 はシステムライブラリのバージョンが足りないため、現在非対応です。

### ArchLinux

AUR ヘルパーを使用してインストール：

```bash
# paru を使用
paru -S cc-switch-bin

# または yay を使用
yay -S cc-switch-bin
```

### Debian / Ubuntu

1. アーキテクチャに合わせて `CC-Switch-v{バージョン}-Linux-x86_64.deb` または `CC-Switch-v{バージョン}-Linux-arm64.deb` をダウンロード
2. インストール：

```bash
sudo dpkg -i CC-Switch-v{バージョン}-Linux-*.deb

# 依存関係に問題がある場合
sudo apt-get install -f
```

### Fedora などの RPM 系ディストリビューション

1. アーキテクチャに合わせて `CC-Switch-v{バージョン}-Linux-x86_64.rpm` または `CC-Switch-v{バージョン}-Linux-arm64.rpm` をダウンロード
2. インストール：

```bash
sudo dnf install ./CC-Switch-v{バージョン}-Linux-*.rpm
```

### AppImage

上記のシステム要件を満たしているものの、対応するパッケージがないディストリビューション向けです。

1. アーキテクチャに合わせて `CC-Switch-v{バージョン}-Linux-x86_64.AppImage` または `CC-Switch-v{バージョン}-Linux-arm64.AppImage` をダウンロード
2. 実行権限を追加：

```bash
chmod +x CC-Switch-v{バージョン}-Linux-*.AppImage
```

3. 実行：

```bash
./CC-Switch-v{バージョン}-Linux-*.AppImage
```

### Flatpak

公式 Release には Flatpak パッケージは含まれていません。必要な場合は `.deb` から自分でビルドできます。リポジトリの [flatpak/README.md](https://github.com/farion1231/cc-switch/blob/main/flatpak/README.md) を参照してください。

## インストールの確認

インストール完了後、CC Switch を起動します：

1. アプリウィンドウが正常に表示される
2. システムトレイに CC Switch のアイコンが表示される
3. アプリ切り替えに有効化された管理対象アプリが表示され、目的のアプリパネルへ切り替えられる

## 自動更新

CC Switch には自動更新機能が内蔵されています：

- 起動時に自動で更新を確認
- 新しいバージョンがある場合、画面に更新通知を表示
- クリックするとダウンロードしてインストール

「設定 → バージョン情報」から手動で更新を確認することもできます。

## アンインストール

### Windows

- 「設定 → アプリ」からアンインストール
- またはインストールディレクトリのアンインストーラーを実行

### macOS

- Homebrew でインストールした場合：`brew uninstall --cask cc-switch`（`--zap` を付けると設定データも削除されます）
- 手動でインストールした場合：`CC Switch.app` をゴミ箱に移動
- オプション：設定ディレクトリ `~/.cc-switch/` を削除

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-switch

# Fedora などの RPM 系ディストリビューション
sudo dnf remove cc-switch

# ArchLinux
paru -R cc-switch-bin
```
