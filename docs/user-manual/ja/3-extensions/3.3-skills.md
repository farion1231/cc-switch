# 3.3 Skills スキル管理

## 機能説明

Skills は再利用可能な機能拡張で、AI ツールに特定分野の専門的な能力を与えます。

スキルはフォルダ形式で存在し、以下を含みます：

- プロンプトテンプレート
- ツール定義
- サンプルコード

## 対応アプリ

Skills 機能は以下のアプリに対応しています：

- **Claude Code**（Claude Desktop ページの Skills パネルで操作するのも Claude Code のスキルです）
- **Codex**
- **Gemini CLI**
- **Grok Build**
- **OpenCode**
- **Hermes**
- **Pi**
- **MiniMax Code**

OpenClaw は現在 Skills 管理に対応していません。

## Skills ページを開く

左サイドバーの **Skills** をクリックします。これはグローバルなページで、特定のアプリに属しません。どのアプリを選択していても同じページが開きます（Claude Desktop には独自の Skills がなく、ここにも列はありません）。

ページ上部で 2 つのビューを切り替えられます：**インストール済み** と **見つける**。

## ページ概要

<!-- TODO(v4 screenshot): Skills "Installed" view: one row per Skill, per-app toggle columns on the right, header with the "Add Skill" button and the ⋯ menu -->

「インストール済み」はマトリクス表です。**1 行が 1 つの Skill、1 列が 1 つのアプリ**で、セルのスイッチが「この Skill をこのアプリで有効にする」を表します。

- ヘッダー：「Skill を追加」ボタンと、⋯ メニュー（更新を確認、バックアップから復元、リポジトリの管理、保存と同期）
- 検索ボックス：名前・フォルダー・説明・リポジトリで検索
- 絞り込み：すべて / 更新あり / どのアプリでも無効 / いずれかのアプリで有効。取得元リポジトリでも絞り込めます
- サイドバーの「アプリ」ページで表示にしたアプリの列だけを表示します。非表示は画面にだけ影響し、すでに有効なものはそのまま残ります
- 複数行をチェックすると、あるアプリへの「有効にする先」、「オフにする」、「更新」、「アンインストール」を一括で実行できます
- 列ヘッダーをクリックすると、その列全体を一括で有効化・オフにできます。対象は現在の一覧にあるエントリーだけです
- Pi には独立したスイッチのデータがなく、`~/.pi/agent/skills` にそのフォルダーがあるかどうかで有効かどうかを判断します

## スキルの発見

「見つける」ビューに切り替えて、インストールできる Skill を閲覧・検索します。

### プリセットリポジトリ

CC Switch には、Anthropic 公式（`anthropics/skills`）や ComposioHQ（`ComposioHQ/awesome-claude-skills`）など、いくつかの GitHub スキルリポジトリがあらかじめ設定されています。「見つける」の「リポジトリ」ボタンで探索に使うリポジトリを選べ、「リポジトリを読み直す」で再スキャンして最新のスキルを取得します。

### 検索

- 「リポジトリ」ソース：Skill 名やリポジトリ名で検索でき、入力に合わせて絞り込まれます。状態で絞り込むこともでき、「すべて表示」と「未インストールのみ」を切り替えられます
- 「skills.sh」ソース：[skills.sh](https://skills.sh) の公開レジストリを検索します。2 文字以上入力して Enter で検索し、結果は「さらに読み込む」で続きを表示できます

## スキルのインストール

### 操作手順

1. 「見つける」ビューでインストールしたい Skill を見つける
2. 先に「インストール先」で有効にするアプリを選ぶ（前回の選択が記憶され、既定になります）
3. その行の「インストール」をクリックし、完了を待つ

インストール後は選んだアプリですぐに有効になり、あとから「インストール済み」でいつでも調整できます。リポジトリからのインストールのほかに、ヘッダーの「Skill を追加」メニューから次の方法も使えます：

- **「見つける」で探す**：「見つける」ビューに切り替えます
- **ZIP からインストール**：`SKILL.md` を含む ZIP ファイルを選びます。ZIP 内でフォルダー名がすでに使われている Skill はスキップされます。ZIP 内のバージョンに置き換えるには、先に同名のものをアンインストールしてからインストールしてください
- **このコンピューターから取り込む**：このコンピューターの各アプリのフォルダーにあるが CC Switch の管理下にない Skill を取り込みます。取り込みでは CC Switch のフォルダーにコピーされ、元のファイルは変更されません

ページ上部に「このコンピューターに CC Switch の管理外の Skill が N 件あります」と表示されたら、「確認して取り込む」をクリックできます。

### インストール先

| アプリ     | インストールディレクトリ              |
| -------- | --------------------- |
| Claude Code | `~/.claude/skills/`   |
| Codex    | `~/.codex/skills/`    |
| Gemini CLI | `~/.gemini/skills/`   |
| Grok Build | `~/.grok/skills/` |
| OpenCode | `~/.config/opencode/skills/` |
| Hermes | `~/.hermes/skills/` |
| Pi | `~/.pi/agent/skills/` |
| MiniMax Code | `~/.minimax/skills/` |

設定で設定ディレクトリを上書きしている場合、インストールディレクトリもそれに合わせて変わります（MiniMax Code のデータディレクトリは環境変数 `MINIMAX_DATA_DIR` で指定でき、Pi はさらに `PI_CODING_AGENT_DIR` も認識します）。スキルのマスターコピーは「保存と同期」で選択したディレクトリ（デフォルトは `~/.cc-switch/skills/`。下記の [保存と同期](#保存と同期) を参照）に保存され、シンボリックリンクまたはファイルのコピーで各アプリのディレクトリに同期されます。

### インストール内容

インストールによりスキルフォルダがローカルにコピーされます：

```
~/.claude/skills/
└── skill-name/
    ├── README.md
    ├── prompt.md
    └── tools/
        └── ...
```

## スキルのアンインストール

### 操作手順

1. 「インストール済み」でその Skill を見つけ、行の ⋯ メニューの「アンインストール」をクリック（複数選択して一括アンインストールもできます）
2. アンインストールを確認

### アンインストールの効果

- **自動バックアップ**：削除前にスキルが `~/.cc-switch/skill-backups/` にバックアップされる
- すべてのアプリのスキルディレクトリからスキルを削除
- マスターコピーのある保存ディレクトリ（デフォルトは `~/.cc-switch/skills/`）からスキルを削除
- データベースからスキルレコードを削除

### バックアップから復元

以前アンインストールしたスキルを復元する場合：

1. Skills ページを開く
2. ヘッダーの ⋯ メニューの **バックアップから復元** をクリック
3. リスト（スキル名とバックアップ日時が表示）から復元したいバックアップを選び、「復元」をクリック
4. スキルが復元され、「見つける」の「インストール先」で選んだアプリで有効になる

### バックアップの削除

古いスキルバックアップを削除するには：

1. 復元ダイアログで削除したいバックアップを見つける
2. バックアップエントリの横にある **削除** ボタンをクリック
3. 削除を確認（この操作は取り消せません）

## リポジトリ管理

### リポジトリ管理を開く

ヘッダーの ⋯ メニューの「リポジトリの管理」をクリックします（「見つける」ビューの「リポジトリ」ボタンの下にも「リポジトリの追加・管理」の入口があります）。

### カスタムリポジトリの追加

1. 「リポジトリ URL」に `owner/name` または完全な `https://github.com/owner/name` を入力
2. ブランチを入力（デフォルトは main）
3. スキルパスは任意：スキルがあるサブディレクトリ。空欄ならルートをスキャンします
4. 「リポジトリを追加」をクリック

追加に成功すると、検出したスキルの数が表示されます。

### リポジトリの削除

「追加済みリポジトリ」の一覧で、リポジトリの右側の削除ボタンをクリックします。

リポジトリを削除しても、インストール済みのスキルは消えませんが、そのリポジトリからの更新はできなくなります。

## スキル行の情報

「インストール済み」の各行には以下が表示されます：

| 情報 | 説明 |
| ---- | ---- |
| 名前、説明 | スキル名と機能の説明 |
| ソース | 所属リポジトリ。ローカルから取り込んだものは「ローカル」と表示 |
| 各アプリのスイッチ | どのアプリで有効か。書き込みに失敗したアプリは表示され、「同期方法を変更」から調整できます |
| 新しいバージョン | リモートに更新があると「更新あり」と表示 |

## スキルの更新

Skills は **更新検出** と **一括更新** に対応しており、アンインストールして再インストールする必要はありません。

### 更新検出の仕組み

CC Switch は **SHA-256 コンテンツハッシュ** によってローカルにインストールされた skill とリモートリポジトリのバージョンを比較します。リモートに何らかのファイル変更があれば、対応する skill に「更新あり」と表示されます。

### 更新の確認

ヘッダーの ⋯ メニューの「更新を確認」、または「インストール済み」の検索ボックス横の「更新を確認」をクリックして、リモートリポジトリを再スキャンします。ページに「前回の確認」の時刻が表示されます。読み込めなかったリポジトリがある場合はその旨が表示され、更新結果が不完全な可能性があります。

### 単体更新とすべて更新

- 新しいバージョンがある Skill は、その行の「更新」をクリック
- 更新できる Skill があると、ヘッダーに「N 件の更新」が表示され、クリックすると更新があるものだけを表示できます。絞り込みバーの「すべて更新（N 件）」で一括更新でき、更新前に確認が表示されます

> ⚠️ 更新するとローカルのフォルダーがリポジトリの内容で置き換えられ、ローカルで変更した部分はバックアップにだけ残ります。

## 保存と同期

ヘッダーの ⋯ メニューの「保存と同期」をクリックすると、次の 2 つを設定できます：

### マスターコピーの保存先

| 場所                     | 説明                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| **CC Switch フォルダ**   | デフォルト位置 `~/.cc-switch/skills/`、CC Switch が一元管理          |
| **共通フォルダ**（`~/.agents/skills`） | コミュニティの agent ツール規約に準拠した共有ディレクトリ、他ツールとの連携に適する |

切り替えるときは「移動して切り替え」をクリックします。CC Switch はマスターコピーを 1 つずつ移動し、各アプリのリンクを新しい場所に向け直すため、skill の状態は失われません。移動が終わるまで CC Switch を終了しないでください。

> ⚠️ 「共通フォルダ」を選ぶと、Codex、Gemini CLI、OpenCode などはこのディレクトリを直接読むため、各アプリのスイッチはそれらに対して完全には効かなくなります。

### 各アプリへの同期方法

| 方法 | 説明 |
| ---- | ---- |
| 自動（推奨） | シンボリックリンクを優先し、失敗したらコピー |
| シンボリックリンクのみ | Windows では開発者モードを有効にする必要があります |
| コピーのみ | ディスク容量を多く使い、更新のたびにコピーし直します |

変更はこの後に有効化または更新した Skill にのみ適用されます。すでに有効な Skill も現在の方式に切り替えるには、「今すぐ再同期」をクリックしてください。

## トラブルシューティング

### スキルリストが空の場合

考えられる原因：

- ネットワークの問題で GitHub にアクセスできない
- リポジトリ設定のエラー

解決方法：

- ネットワーク接続を確認
- 「リポジトリを読み直す」をクリックしてリトライ
- リポジトリ設定を確認

### インストールに失敗する場合

考えられる原因：

- ネットワークの問題
- ディスク容量不足
- 権限の問題

解決方法：

- ネットワーク接続を確認
- ディスク容量を確認
- ディレクトリの権限を確認

### 更新ボタンが表示されない場合

考えられる原因：

- リモートリポジトリに新しいコンテンツがない
- CC Switch が最新のスキャンを完了していない

解決方法：

- 「更新を確認」をクリックして再スキャン
- リポジトリ設定が正しいブランチとパスを指していることを確認
