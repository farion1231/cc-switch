# 4.6 集約モード

## 機能説明

集約モードは、複数のプロバイダーのモデルを Claude Code または Codex の同じモデル一覧にまとめます。クライアントの `/model` で選んだモデルに応じてリクエストが該当のプロバイダーに送られるため、CC Switch に戻ってプロバイダーを切り替える必要がありません。

集約モードは **Claude Code** と **Codex** のみに対応しています。プロバイダーと集約リストはアプリごとに設定してください。

![集約モード：既定のプロバイダー 1 社と、追加した複数のプロバイダー](../../../../assets/release-notes/v4.0.0/agg-en.png)

## ルーティングとの違い

| | ルーティング | 集約 |
|------|------|------|
| 同時に使うプロバイダー | 1 社（またはフェイルオーバーキューに従って交代） | 複数。選んだモデルに応じて振り分け |
| フェイルオーバー | 対応 | 非対応 |
| プロバイダーの切り替え方法 | CC Switch で切り替える | クライアントの `/model` でモデルを選ぶ |
| 対応アプリ | Claude Code / Codex / Gemini CLI / Grok Build | Claude Code / Codex のみ |

どちらもこのマシンのルーティングサービスを経由するため、CC Switch を起動し続ける必要があります。1 つのアプリは、同時に直接接続・ルーティング・集約のいずれか 1 つのモードにしかなれません。

## 集約モードに入る

### 操作場所

サイドバーで Claude Code または Codex を選択 → ページ上部の「集約」タブ

### 操作手順

1. 「集約」タブをクリックします。タブをクリックしても表示が切り替わるだけで、設定は変わりません
2. 各プロバイダーのモデル一覧を設定し、必要なプロバイダーを集約リストに追加して、既定のプロバイダーを確認します（後述）
3. 「集約に切り替え」をクリックします
4. 表示される確認ダイアログで、既定のプロバイダーと `/model` に表示されるモデルを確認し、「集約に切り替え」で確定します

切り替えると、ページに「集約が有効 · 既定」と、既定のプロバイダーおよびほかの何社・合計何モデルが追加されているかが表示されます。直接接続に戻すには「直接接続に戻す」をクリックします。ルーティングに切り替えるには、「ルーティング」タブの「ルーティングを開始」をクリックします。

## プロバイダーの追加と削除

### 追加

「集約」タブの「追加できるもの」リストには、まだ追加していないプロバイダーが並んでいます。カードの「追加」をクリックすると、そのプロバイダーのモデルがクライアントのモデル一覧に表示されます。

### 削除

「追加済み」リストで、カードの「削除」をクリックします。追加済みのプロバイダーは、クライアントの設定にも同時に書き込まれます。

> ⚠️ 既定のプロバイダーは削除できません。先に別のプロバイダーを既定にしてください。

### 各プロバイダーのモデルを設定する

プロバイダーの編集フォームにある「モデル一覧」で設定します。モデルの設定と集約への追加は別の操作です。保存後に「追加できるもの」リストで「追加」をクリックしてください。

#### モデル一覧を取得する

API の URL とキーを入力するか、アカウント設定を完了してから「モデル一覧を取得」をクリックします。CC Switch がプロバイダーに問い合わせ、対応するエンドポイントとレスポンス形式を処理します。取得後は検索して必要なモデルにチェックを入れ、「選択したモデルを追加」でまとめて追加できます。返されたモデルをすべて追加する必要はありません。

#### モデル情報を自動補完する

Codex では、モデルを選んで一覧に追加すると、models.dev から対応する情報を取得し、コンテキストウィンドウ、思考レベル、テキスト／画像の入力対応を補完します。プロバイダーの接続先に一致する組み込みプリセットが優先され、残りの空欄を models.dev のプロバイダー別情報やモデル開発元の情報で補います。

既存の値は保持し、空欄だけを補完します。情報源も表示されるので確認してください。同じモデルでもプロバイダーによって対応機能が異なる場合があるため、実際の提供内容を優先してください。一致する情報がない項目は手動で入力できます。

#### モデルを手動で追加する

プロバイダーにモデル一覧の API がない場合、新しいモデルが一覧にない場合、独自のモデル別名を使う場合は「手動で追加」を使います。実際に対応しているモデル ID を入力し、必要に応じて表示名や能力の設定を補ってください。名前やコンテキストウィンドウの設定を変えても、モデル自体の能力は変わりません。

#### 既定のモデル

- 設定したモデルがクライアントのモデル選択に表示され、選ぶと対応するプロバイダーにリクエストが送られます
- ★ はそのプロバイダーの既定モデルです。Claude Code では一覧の先頭にあり、そのプロバイダーが既定の場合に起動時とバックグラウンドタスクで使われます。Codex は設定で指定した既定モデルを使います
- Claude Code でモデル一覧もモデルマッピングも設定していないプロバイダーは、選択肢を追加しません。Codex は設定済みの既定モデルも利用できます
- 一覧を変更した後の反映方法は、下の「再起動が必要なとき」を参照してください

## 既定のプロバイダー

既定のプロバイダーは、プレフィックスのないすべてのリクエストを受けます。プロバイダーカードの「既定にする」で変更できます。

Codex の公式アカウントを使う場合は、**OpenAI Official を既定のプロバイダーに設定**してから、ほかのプロバイダーを追加します。OpenAI Official は既定のプロバイダー専用で、通常の集約メンバーには追加できません。

**集約モードは現在、Claude の公式サブスクリプションに対応していません。** 利用する場合は直接接続に戻し、Claude Code の公式ログイン手順でサインインしてください。この制限は公式サブスクリプションに関するもので、Claude Code でほかの対応プロバイダーを集約することは可能です。

公式アカウントに対応していることは、アカウントのリスクがゼロであるという保証ではありません。各プラットフォームの規則に従ってください。公式情報：[Codex の認証](https://learn.chatgpt.com/docs/auth#alternative-model-providers)、[Claude Code の認証と認証情報の利用](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)。

## `/model` の `ccs-` プレフィックス

既定のプロバイダー以外の追加済みプロバイダーのモデルは、`ccs-` プレフィックス付きで `/model` に表示されます。`ccs-` プレフィックス付きのモデルを選ぶと、リクエストは対応するプロバイダーに送られます。プレフィックスなしのモデルを選ぶと、既定のプロバイダーに送られます。

![Codex のモデル選択に複数のプロバイダーのモデルが並んでいる様子](../../../../assets/release-notes/v4.0.0/agg-codex-en.png)

> 同じセッションの途中でモデルを変えると、新しいモデルでプロンプトキャッシュを作り直すため、最初の 1 ターンは費用が高くなります。Claude Code は 2.1.243 以降が必要です。

## 再起動が必要なとき

| アプリ | 集約のモデル一覧が変わったとき |
|------|------------------|
| Claude Code | すぐに反映 |
| Codex | 完全な再起動が必要 |

Codex はモデル一覧を起動時にしか読み込みません。集約に入る・抜ける、プロバイダーを追加・削除する、プロバイダーのモデルを変更するといった操作の後、ページに「Codex が古いモデル一覧を使っているため、集約したモデルが表示されません」と表示されます。クライアントの形態に応じて次のように対処します：

- **CLI**：codex を開き直すだけでは足りません。案内にある「Codex デーモンを再起動」をクリックしてください。すべてのターミナルの codex がこのデーモンを共有しているため、実行中のタスクは中断されます
- **デスクトップ版**：完全に終了してから開き直します。macOS では ⌘Q を押します。ウィンドウを閉じるだけでは不十分です
- **エディター拡張**：エディターのウィンドウを開き直します

読み込み済みの一覧から別のモデルを選ぶだけなら、その都度再起動する必要はありません。Claude Code では、CC Switch がクライアント設定を書き換えた後、集約モデルを選択中の場合は案内に従って選び直してください。

## 制限事項

- **フェイルオーバーはしません**：集約モードの間もキューと設定は保持され、ルーティングモードに戻すと復元されます
- **Codex の OpenAI Official は既定のプロバイダー専用**で、通常の集約メンバーには追加できません
- **Claude の公式サブスクリプションには現在非対応**です。直接接続で利用してください
- **既定のプロバイダーは削除できません**
- **CC Switch を起動し続ける必要があります**：CC Switch を終了すると自動的に直接接続に戻り、次回の起動時に再び接続されます
- ルーティングモードに戻すと、集約したモデルは `/model` から外れます（リストは保持）。選択中の集約したモデルは通常のモデルに戻す必要があります
