# 4.5 接続チェック

## 機能説明

接続チェックは、プロバイダーのアドレスに接続できるかどうかをすばやく確認する機能です：

- CC Switch はプロバイダーのリクエスト先アドレス（base URL）に軽量なリクエストを送信し、何らかの HTTP レスポンス（401、403、404、5xx を含む）を受け取れば「到達可能」と判定します
- DNS の名前解決の失敗、接続拒否、TLS エラー、タイムアウトなど、ネットワークレベルのエラーの場合のみ「到達不可」と判定します
- レイテンシはレスポンスヘッダーを受け取るまでの時間です

> ⚠️ **接続チェックは実際のモデルリクエストを送信しません**。API Key やモデル名の検証も行いません。「到達可能」はアドレスに接続できることを示すだけで、認証やモデルの設定が正しいことを保証するものではありません。

> 💡 v3.16.3 より前は、この機能は「モデルテスト」（Stream Check）という名前で、プロバイダーに実際のストリーミングモデルリクエストを送信していました。多くのサードパーティゲートウェイがこの種のリクエストをブロックして誤判定を招いていたため、現在は接続チェックに変更され、テストモデルの設定も不要になりました。

MiniMax Code を除き、各アプリの非公式プロバイダーはすべてチェックできます。公式プロバイダー（Claude Official、Claude Desktop Official など）には探査できるアドレスがありません。公式プロバイダーと MiniMax Code のプロバイダーカードでは、チェックボタンがグレー表示になりクリックできません。

## チェックの実行

1. プロバイダーカードにマウスを合わせて、操作ボタンを表示
2. **接続チェック** ボタンをクリック
3. チェックの完了を待つと、結果が通知メッセージで表示されます

| 結果 | 説明 |
|------|------|
| 接続可能（xxx ms） | アドレスに到達でき、レイテンシが「低速判定しきい値」以内 |
| 接続可能だが低速（xxx ms） | アドレスに到達できるが、レイテンシが「低速判定しきい値」を超えている |
| 接続できません | 接続を確立できない（DNS / 接続 / TLS / タイムアウト）。リクエスト先アドレスとネットワークを確認してください |

## チェックパラメーター

設定 → 詳細 → 接続チェック設定

| パラメーター | 説明 | デフォルト値 | 範囲 |
|------|------|--------|------|
| タイムアウト（秒） | 1 回の探査の最大待機時間 | 8 | 2-60 |
| 最大リトライ回数 | タイムアウト系の失敗時のみリトライ。接続拒否や DNS の失敗などはすぐに結果を返す | 1 | 0-5 |
| 低速判定しきい値（ミリ秒） | 到達可能でもレイテンシがこの値を超えると「低速」とマーク | 6000 | 1000-30000 |

## フェイルオーバーとの関係

接続チェックはフェイルオーバーやサーキットブレーカーに**影響しません**。403 を返すプロバイダーは接続チェックでは「到達可能」ですが、実際のリクエストでは使用できません。フェイルオーバーとサーキットブレーカーは、ローカルルーティング経由で転送された実際のリクエストの成否だけに基づいて判断します。詳しくは [4.3 フェイルオーバー](./4.3-failover.md) を参照してください。

## よくある質問

### チェックでは到達可能なのに、実際のリクエストが失敗する

接続チェックは認証とモデルを検証しません。以下を確認してください：
- API Key が正しいか、プリセットと一致しているか
- モデル名がプロバイダーでサポートされているか
- 上流フォーマットがプロバイダーのインターフェースと一致しているか（[2.1 プロバイダーの追加](../2-providers/2.1-add.md) を参照）

### 「接続できません」と表示される

考えられる原因：
- リクエスト先アドレスの入力ミス
- ネットワークがつながっていない、またはプロキシ経由でないとアクセスできない（「設定 → ルーティング → グローバル送信プロキシ」で設定できます）
- ファイアウォールが接続をブロックしている

### レイテンシが高すぎる

考えられる原因：
- ネットワークレイテンシ
- プロバイダーのサーバー負荷が高い

解決方法：
- [エンドポイント速度テスト](../2-providers/2.1-add.md#エンドポイント速度テスト) でより高速なエンドポイントを選択
- 低速判定しきい値を調整
