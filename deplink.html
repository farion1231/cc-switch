深链接生成器

用量查询脚本示例

让用户导入后，直接在供应商卡片上看到余额。

  • 脚本是一段 JavaScript 表达式，返回 { request, extractor }：request 描述发什么请求，extractor(response) 从响应 JSON 里取数。请求由 CC Switch 代发，脚本本身没有网络能力。
  • 占位符：{{apiKey}}（usageApiKey，没给时用供应商 Key）、{{baseUrl}}（usageBaseUrl，没给时用供应商地址）、{{accessToken}}、{{userId}}。
  • 每次只发一个请求，必须是 HTTPS，且与 {{baseUrl}} 同源；响应必须是 JSON。余额接口在另一个域名时，用 usageBaseUrl 指过去。
  • extractor 返回对象或对象数组，字段都可选：remaining、used、total（数字）、unit、planName、extra（字符串）、isValid（布尔）、invalidMessage（字符串）。数字字段如果接口返回的是字符串，要先用 Number() 转。
  • 带了 usageScript 就默认启用（v4.0.10 起）；要兼容更早的版本，同时写上 usageEnabled=true。usageAutoInterval 是自动查询间隔（分钟），别设得太短。
Claude Code

常见问题

怎么做成我网站上的按钮
链接里有用户的 Key，不要直接写进按钮的 href。用户点击时，前端向你的后端要这个用户的链接，拿到后用 location.href = link 跳转；按钮旁写一句「点了没反应？先安装 CC Switch」并附上下载地址。一条链接只导入到一个应用，同时支持 Claude Code、Codex 等几个应用时，每个应用放一个按钮。后端接口和前端按钮的完整代码见 站长接入指南。
点了没反应
第一次点击时浏览器会询问是否打开 CC Switch，选「允许」或「打开」。macOS 上如果仍然打不开，到「系统设置 → 隐私与安全性」里允许 CC Switch。
导入时会发生什么
CC Switch 弹出确认框，API Key 打码显示。「导入后立即切换 / 添加 / 启用」由用户在确认框里的开关决定，链接只给初始值。
导入之后
可以在 CC Switch 里随时编辑或删除导入的内容。
iconUrl 的图标没显示
CC Switch 下载失败时不报错，直接退回内置图标或名称首字母。常见原因：地址要登录或开了防盗链、响应头 Content-Type 写成了 application/octet-stream、图片超过 256 KB、域名解析到内网地址。用 curl -I 看一下响应头，或者在 CC Switch 的日志里搜 Skipped deep link icon。
示例能直接用吗
不能。示例里的域名和 Key 都是假的，只用来演示格式。
